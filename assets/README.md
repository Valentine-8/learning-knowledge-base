# Assets

## 目录定位

全仓库公共图片、图表、截图与示例资源。技术文档引用图片应使用相对路径指向本目录，禁止将图片散落在各文档目录中。

## 推荐结构

```text
assets/
  images/       # 按技术域分子目录
  diagrams/     # Mermaid 导出图
  screenshots/  # 工具截图
  examples/     # 可运行示例代码
```

详见 [Repository-Specification.md](../00-Governance/01-Repository-Specification.md) 第 9 节。
