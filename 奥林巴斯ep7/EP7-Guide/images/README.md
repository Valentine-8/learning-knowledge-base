# EP7 教程图片说明

本目录的插图均为**精细矢量图（SVG）**，由脚本生成，可直接在 Markdown 与网页版中显示，缩放不失真。

## 图片来源

所有插图均为本教程用 SVG 绘制（`scripts/art.py` + `scripts/svgkit.py` 生成），采用统一的复古 PEN 纸感配色，包含渐变、投影、玻璃反光与引线标注：

| 类型 | 示例 |
|------|------|
| **机身 / 镜头示意** | 正背面、模式转盘、Profile 拨盘、开箱、装镜头、换镜头流程 |
| **教学图** | 焦段对比、光圈虚化、ISO 噪点、六步法、单点对焦、白平衡对比 |
| **菜单示意** | SCP、SCN、AP、必改设置、Live Composite（均标注「非官方截图」）|
| **样张示意** | 风景广角、日落、夜景手持 vs 三脚架、星空、人像用光 |

> 这些是**示意插图**，用于讲解原理与操作。若你想要更真实的效果，随时可用自己 EP7 拍摄的照片覆盖同名文件。

## 为什么之前没有图片？

1. **我没有你的实体相机**，无法替你拍机身按键、菜单的真实截图  
2. **菜单截图**必须用你自己的 EP7 拍摄才 100% 准确  
3. 第一版只预留了路径，没有填入文件——这是疏漏，现已补全

## 建议你用自己的相机替换的图片

以下用**真实照片**替换后，教程会更准确：

- 菜单截图（SCP、SCN、AP 子菜单）
- 你的 EP7 正面 / 背面 / 模式转盘特写
- 用本教程设置拍出的**实拍样张**

拍好后覆盖同名文件，或修改对应 Markdown 里的图片路径即可。

## 重新生成示意图

```bash
python EP7-Guide/scripts/generate_images.py
```

> 该命令会调用 `art.py` + `svgkit.py`，一次性重绘全部 34 张 SVG。
> 修改插图请编辑 `art.py`（各图一个函数）或共享工具 `svgkit.py`（相机/镜头/渐变），再重跑上面的命令。
