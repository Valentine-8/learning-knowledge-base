## STAR 写作要点

| 要素 | 要求 |
|------|------|
| Situation | 业务背景、规模（QPS、数据量、团队） |
| Task | 你的职责，别人做不到什么 |
| Action | **你**做了什么（技术细节 2～3 点） |
| Result | **量化**结果（耗时、成本、可用性、人效） |

**避免**：「我们团队做了…」→ 改成「我负责…我设计了…」
