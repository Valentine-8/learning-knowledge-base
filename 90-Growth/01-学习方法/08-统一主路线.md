# 统一主路线：Java 7 年 + AI 应用（24 个月）

> **默认假设**：在职，每周约 18～22 小时（工作日 2h×5 + 周末 1 天）。

---

## 时间分配原则

| 类型 | 占比 | 说明 |
|------|------|------|
| Java 主线 | 70% | Phase 0～9，工程深度是根本 |
| AI 技能 | 30% | 编程工作流 → API → RAG → Agent |
| 算法 | 贯穿 | 每周 5～7 题，不单独占 Phase |

**AI 启动时机**：Phase 0 即可用 Cursor；Spring AI 建议在 Java Phase 4 并行；RAG 项目在 Phase 5 后启动。

## 弱项加速规则

基线评估中 **≤2 分** 的模块，在主路线中 **时间 ×1.5**；**≥4 分** 的模块可压缩 30% 或只做验收。

| 弱项示例 | 调整 |
|----------|------|
| JVM 弱 | Phase 2 延长 2 周，加 2 次 OOM 实验 |
| 算法弱 | 每周题量 5→8，先 Hot 100 数组/链表/二叉树 |
| Spring 弱 | Phase 4 不跳过源码，加自定义 Starter |
| AI 零基础 | W1 起 AI 阶段 0，但不压缩 Java Phase 1 |
