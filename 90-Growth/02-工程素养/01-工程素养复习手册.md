# 专题复习：工程素养与软实力

> 对应技能清单 §十。7 年工程师与 3 年的差距，往往在这里。

---

## 一、Code Review

**Review 什么**：
- 正确性、边界、并发安全
- 可读性、命名、单一职责
- 性能（N+1、无界集合）、安全（注入、越权）
- 测试是否覆盖核心路径

**怎么 Review**：小 PR、先理解意图、提建议不说教、区分 must-fix vs nit。

**AI 时代**：AI 生成代码更要 Review 事务、并发、安全。

---

## 二、技术方案设计（ADR）

```markdown
# ADR-001：订单超时取消用延迟消息

## 背景
30 分钟未支付需取消

## 方案对比
| 方案 | 优点 | 缺点 |
| 扫表 | 简单 | 延迟大、DB 压力 |
| 延迟 MQ | 精准、解耦 | 依赖 MQ、幂等 |

## 决策
选 RocketMQ 延迟消息

## 风险
消息重复 → 幂等表；MQ 不可用 → 降级扫表补偿
```

**要素**：背景、目标/非目标、方案对比、决策、风险、回滚、监控指标。

---

## 三、估时与排期

- **WBS** 拆到 0.5～2 天粒度
- **留 buffer** 20～30%（联调、评审、线上问题）
- 区分「必须」和「可砍」
- 风险前置：依赖方、环境、数据迁移

---

## 四、技术选型

```
1. 澄清需求（QPS、一致性、团队熟悉度）
2. 列 2～3 方案
3. 维度打分：性能、成本、运维、生态、招聘
4. 选「够用」不选「最新」
5. 记录 ADR，方便后人
```

---

## 五、故障复盘（5 Whys）

```
现象：支付成功率下降
Why1：调用支付网关超时
Why2：连接池耗尽
Why3：慢 SQL 占满连接
Why4：缺索引
Why5：上线前未做 explain
→ 改进：慢 SQL 门禁、连接池监控、索引评审 checklist
```

**模板**：时间线、根因、影响面、改进项（含负责人和截止日期）、不追责个人。

---

## 六、跨团队沟通

| 对象 | 要点 |
|------|------|
| 产品 | 问清业务规则、边界、优先级 |
| 测试 | 可测性、环境、核心用例 |
| 运维 | 部署、监控、回滚预案 |
| 上级 | 风险透明、要资源要早说 |

**书面**：会议纪要、结论、待办；避免口头需求。

---

## 七、Mentoring

- 任务拆解、结对、Review 反馈
- 分享笔记/内部分享（费曼学习）
- 帮新人建立「排查思路」而不只给答案

---

## 八、技术影响力

- 内部分享、文档沉淀（你的知识库就是例子）
- 规范制定：日志、异常、API、数据库变更
- 开源/博客（求职加分）

---

## 九、面试怎么讲软实力

用 **STAR**：情境、任务、行动、结果。

例：「服务雪崩（S）→ 负责稳定性（T）→ 上限流+扩容+复盘（A）→ 可用性 99.9→99.95（R）」
