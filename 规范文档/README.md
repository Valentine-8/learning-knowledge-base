## 核心约定（摘要）

1. 正式内容在 **`技术成长/`**，板块名用**中文**。
2. 文章用 **`01-主题名.md`** 编号，板块用 **`00-速查总览.md`**。
3. **禁止**英文编号顶层目录（`01-Java/` 等已废止）。
4. 写作风格、一文一题、Markdown 模板等见 Specification 全文。

根目录下的 `Repository-Specification.md`、`Repository-Structure.md` 为本目录副本，修改时请**两处同步**。
