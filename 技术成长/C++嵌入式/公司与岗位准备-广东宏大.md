## 三、你的简历怎么投这个岗（诚实版）

**不要**：把 Java CRM 经历包装成「多年嵌入式」。  
**要**：强调 **软件功底 + 学习迁移 + 相关交叉**。

### 可强调

- 近 7 年 **复杂业务系统** 与 **线上问题定位**  
- **cc-site-svc**：BFF、协议代理、多租户 — 和 **设备-网关-云端** 分层类似  
- **FollowUpAI**：实时消息、多线程服务、资源受限场景下的工程化  
- **C++ 专题学习 / 个人练习**（本目录复习进度可作佐证）  
- 青岛理工 **计算机本科**，有 **ToG 严谨流程**（人社部项目）

### 需准备话术（必问）

**Q：你主要是 Java，为什么转嵌入式？**  

> 职业上希望进入 **无人系统/航空软件** 方向；嵌入式 C++ 是核心技能，我在系统性地补 **C++11/内存模型/RTOS/Linux 嵌入式**，并用 **[举例：手写环形队列/读过 STM32 文档/做过 xxx 练习]** 验证。Java 积累的 **并发、网络、架构、排障** 可以迁移，语言层我在快速补齐。

**Q：嵌入式经验不多？**  

> 诚实说 **量产嵌入式年限不如纯嵌入式工程师**；但我有 **7 年交付与 legacy 维护**，学习曲线和 **读手册、调 bug** 的能力已验证。入职后会优先补 **贵司 toolchain 和业务域**。
