# 03 · 四种通信模式

> **预计阅读**：50 min · **难度**：★★★★

---

## 1. Unary（一元 RPC）

最常用，一问一答：

```protobuf
rpc GetOrder(GetOrderRequest) returns (OrderResponse);
```

```java
// 服务端
@Override
public void getOrder(GetOrderRequest req, StreamObserver<OrderResponse> responseObserver) {
    OrderResponse resp = buildOrder(req.getOrderId());
    responseObserver.onNext(resp);
    responseObserver.onCompleted();
}

// 客户端（阻塞）
OrderResponse resp = stub.getOrder(request);
```

---

## 2. Server Streaming

```protobuf
rpc ExportOrders(ExportRequest) returns (stream OrderRow);
```

**场景**：大批量导出、订阅推送、AI token 流。

```java
// 服务端
public void exportOrders(ExportRequest req, StreamObserver<OrderRow> obs) {
    for (OrderRow row : query()) {
        obs.onNext(row);
    }
    obs.onCompleted();
}

// 客户端
Iterator<OrderRow> it = stub.exportOrders(req);
while (it.hasNext()) {
    process(it.next());
}
```

## 3. Client Streaming

```protobuf
rpc UploadMetrics(stream MetricPoint) returns (UploadSummary);
```

**场景**：批量上报、日志聚合。

```java
StreamObserver<MetricPoint> requestObserver = stub.uploadMetrics(new StreamObserver<>() {
    public void onNext(UploadSummary summary) { ... }
    public void onCompleted() { ... }
    public void onError(Throwable t) { ... }
});
for (MetricPoint p : points) {
    requestObserver.onNext(p);
}
requestObserver.onCompleted();
```

---

## 4. Bidirectional Streaming

```protobuf
rpc Chat(stream ChatMessage) returns (stream ChatMessage);
```

**场景**：实时聊天、协同编辑、双向管道。

```java
StreamObserver<ChatMessage> requestObs = stub.chat(new StreamObserver<ChatMessage>() {
    public void onNext(ChatMessage msg) { display(msg); }
    ...
});
requestObs.onNext(outgoing);
```

**注意**：应用层需自己定义心跳、背压、断线重连。

---

## 5. 背压与流控

HTTP/2 有窗口流控；gRPC 应用层：

- 慢消费时不要无限 `onNext`
- 客户端/async stub 注意 `ClientCallStreamObserver` `isReady()`
- 服务端处理慢时 HTTP/2 会反压

---

## 6. 与 REST 流式对比

| | gRPC stream | REST |
|---|-------------|------|
| Server stream | 原生 | SSE / chunked |
| Client stream | 原生 | 少见 |
| 双向 | 原生 | WebSocket |
| 契约 | .proto | 自行约定 |
