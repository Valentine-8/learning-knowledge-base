# 大数据 · 速查

| 组件 | 场景 |
|------|------|
| **Kafka** | 日志管道、事件总线（见 MQ 专题） |
| **Flink** | **低延迟流计算**、CEP、实时大屏 |
| **Spark** | **批处理**、离线数仓、机器学习 |
| **ClickHouse** | **OLAP 分析**、报表、日志分析 |
| **Hive** | 离线 SQL 数仓（Hadoop 生态） |

**Java 后端边界**：业务 OLTP 仍用 MySQL；大数据团队维护 Flink/Spark 作业；后端通过 Kafka/接口消费结果。
