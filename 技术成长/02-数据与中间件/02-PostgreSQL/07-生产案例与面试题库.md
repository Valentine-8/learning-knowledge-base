## 1. 生产案例

### 案例 1：表膨胀磁盘占满

| 项 | 内容 |
|----|------|
| 现象 | 磁盘 90%，业务慢 |
| 根因 | 长事务 + autovacuum 未清理 dead tuple |
| 修复 | 杀长事务；`VACUUM (ANALYZE)`；必要时 pg_repack |
| 预防 | 监控 xact 时长、bloat |

### 案例 2：JSONB 查询慢

| 项 | 内容 |
|----|------|
| 根因 | `@>` 无 GIN 索引 |
| 修复 | `CREATE INDEX USING GIN (payload)` |
| 预防 | 慢查询 log + EXPLAIN |

### 案例 3：连接数打满

| 项 | 内容 |
|----|------|
| 根因 | Java 未池化，每请求 new Connection |
| 修复 | HikariCP max 20；PgBouncer 连接池 |
| 预防 | `max_connections` 与池大小规划 |

### 案例 4：从 MySQL 迁移主键冲突

| 项 | 内容 |
|----|------|
| 根因 | SERIAL 序列未同步到 max(id) |
| 修复 | `SELECT setval('user_id_seq', (SELECT MAX(id) FROM user));` |
