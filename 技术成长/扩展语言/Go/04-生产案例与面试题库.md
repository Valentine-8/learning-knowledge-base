## 1. 生产案例

### 案例 1：goroutine 泄漏

| 项 | 内容 |
|----|------|
| 现象 | 内存缓慢涨，goroutine 数万 |
| 根因 | 无缓冲 channel 发送阻塞，消费者退出 |
| 修复 | context 取消 + select default；WaitGroup |
| 预防 | pprof goroutine 定期 dump |

### 案例 2：闭包捕获循环变量

| 项 | 内容 |
|----|------|
| 现象 | 10 个 goroutine 都打印 10 |
| 根因 | `go func() { fmt.Println(i) }()` 捕获同一 i |
| 修复 | `go func(id int) { ... }(i)` |
| 预防 | 永远传参 |

### 案例 3：nil map 写入 panic

| 项 | 内容 |
|----|------|
| 现象 | 生产 panic: assignment to entry in nil map |
| 根因 | `var m map[string]int` 未 make |
| 修复 | `m = make(map[string]int)` |
| 预防 | 静态检查 + review |

## 3. 手写题

**用 channel 实现生产者消费者**

```go
func producer(ch chan<- int) {
    for i := 0; i < 10; i++ {
        ch <- i
    }
    close(ch)
}

func consumer(ch <-chan int, done chan<- struct{}) {
    for v := range ch {
        fmt.Println(v)
    }
    done <- struct{}{}
}
```

**实现超时调用**

```go
select {
case result := <-callAPI():
    return result, nil
case <-time.After(3 * time.Second):
    return nil, fmt.Errorf("timeout")
}
```

## 4. defer 经典题

func main() {
    defer fmt.Println("1")

}
