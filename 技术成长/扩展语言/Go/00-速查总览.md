## 1. 为什么 Java 工程师学 Go

| 场景 | 说明 |
|------|------|
| 云原生 | Docker、K8s、Prometheus、etcd 用 Go |
| CLI 工具 | kubectl、helm、terraform-provider |
| 微服务 | 高并发网关、Sidecar、Agent |
| 性能 | 编译型、低内存、启动快 |
| 补位 | 脚本比 Shell 稳，比 Java 轻 |

**定位**：Java 主业 + Go 读源码/写工具/小服务，非全面替换。

## 3. Java vs Go 速对照

| Java | Go |
|------|-----|
| class | struct + method |
| interface 显式 implements | **隐式实现** |
| extends | **组合 embedding** |
| Exception try/catch | **error 返回值** |
| new Thread | **go func()** |
| synchronized | **mutex / channel** |
| Maven/Gradle | **go mod** |
| null | **nil** |
| GC | GC（低延迟调优） |

## 5. 核心语法片段

```go
// 变量
name := "Go"
var age int = 10

// 函数多返回值
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("divide by zero")
    }
    return a / b, nil
}

// 结构体
type User struct {
    ID   int64
    Name string
}

// 接口隐式实现
type Reader interface {
    Read(p []byte) (n int, err error)
}
```

## 6. 并发速查

```go
// goroutine
go doWork()

// channel
ch := make(chan int, 10)
ch <- 1
v := <-ch
close(ch)

// select
select {
case v := <-ch:
    fmt.Println(v)
case <-time.After(time.Second):
    fmt.Println("timeout")
}
```

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| goroutine 和线程？ | goroutine 更轻，M:N 调度 |
| channel 有缓冲和无缓冲？ | 无缓冲同步；有缓冲异步至满 |
| Go 错误处理？ | if err != nil，无异常 |
| interface 怎么实现？ | 方法集匹配即实现，无 implements |
| Go 为何适合云原生？ | 单二进制、交叉编译、并发、K8s 生态 |
