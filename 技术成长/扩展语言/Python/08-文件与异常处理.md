# 08 · 文件与异常处理

> **Java 对照**：`with open(...) as f:` ≈ `try (var in = Files.newBufferedReader(...))`；`except` ≈ `catch`，但 Python **没有 checked exception**，不必声明 throws。
>
> **本章目标**：读写文本文件；with 语句；try/except 处理错误。
> **预计用时**：6～8 小时 · **难度**：★★★

---

## 1. 打开与读取

```python
f = open("data.txt", "r", encoding="utf-8")
content = f.read()
f.close()
print(content)
```

| 模式 | 含义 |
|------|------|
| `r` | 读（默认） |
| `w` | 写（覆盖） |
| `a` | 追加 |
| `rb` / `wb` | 二进制 |

**必须指定 encoding=utf-8**（Windows 中文环境），否则可能乱码。

---

## 2. with 语句（推荐）

自动关闭文件：

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

`strip()` 去掉行尾 `\n`。

## 3. 写入

```python
lines = ["第一行\n", "第二行\n"]
with open("out.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)

with open("out.txt", "a", encoding="utf-8") as f:
    f.write("追加一行\n")
```

## 5. 异常处理

```python
try:
    n = int(input("整数："))
    print(10 / n)
except ValueError:
    print("不是合法整数")
except ZeroDivisionError:
    print("不能除以 0")
except Exception as e:
    print("其他错误", e)
else:
    print("没有异常时执行")
finally:
    print("无论如何都执行")
```

**不要用**：

```python
try:
    ...
except:
    pass  # 吞掉所有错误，调试地狱
```

## 6. 主动抛出

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("余额不足")
    return balance - amount
```

## 7. 读 CSV 简易版

```python
import csv

with open("users.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["email"])
```
