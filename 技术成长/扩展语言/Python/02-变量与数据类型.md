# 02 · 变量与数据类型

> **Java 对照**：Java 写 `int x = 10;` 编译期定类型；Python 写 `x = 10` 运行时才绑定类型，且 `x`  later 可赋字符串。`None` ≈ `null`。
>
> **本章目标**：掌握 Python 基本类型与运算；理解动态类型。
> **预计用时**：3～4 小时（Java 开发者可快读） · **难度**：★★

---

## 1. 变量是什么

**变量**像贴标签的盒子：名字指向一个值。

```python
age = 30
name = "Alice"
print(name)
print(age)
```

- `=` 是**赋值**，读作「把右边赋给左边」
- 变量名：字母/下划线开头，可含数字，如 `user_id`、`score2`
- 不能有空格、不能以数字开头

```python
# 合法
total_price = 99.5
_private = 1

# 非法
# 2score = 1
# user name = "x"
```

## 2. 基本类型

### 2.1 整数 int

```python
a = 10
b = -3
big = 10 ** 20    # 幂运算，Python 整数不限位数
print(type(a))    # <class 'int'>
```

### 2.2 浮点数 float

```python
pi = 3.14
price = 19.99
print(type(price))  # <class 'float'>
```

**注意**：浮点有精度误差：

```python
print(0.1 + 0.2)  # 0.30000000000000004
```

金额计算后期用 `Decimal`；入门先知道现象即可。

### 2.3 布尔 bool

```python
is_ok = True
is_fail = False
print(type(is_ok))  # <class 'bool'>
```

只有 `True` 和 `False`，首字母大写。

### 2.4 字符串 str（下一章深入）

```python
s = "hello"
t = 'world'
print(type(s))  # <class 'str'>
```

单引号双引号等价。

### 2.5 查看类型

```python
x = 42
print(type(x))
print(isinstance(x, int))  # True
```

## 3. 动态类型

同一变量名可以重新绑定不同类型（不推荐乱用，但语言允许）：

```python
x = 10
x = "ten"
print(x)
```

Java 里 `int x = 10; x = "ten";` 编译不过；Python 运行时才检查类型。

---

## 4. 类型转换

```python
# str → int
n = int("123")
print(n + 1)  # 124

# int → str
s = str(456)
print("编号:" + s)

# float ↔ int
print(int(3.9))    # 3 截断
print(float(5))    # 5.0
```

**失败会报错**：

```python
int("abc")  # ValueError
```

安全转换模式：

```python
text = "42"
if text.isdigit():
    n = int(text)
else:
    print("不是数字")
```

## 5. 运算符

### 5.1 算术

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `+ - * /` | 加减乘除 | `7 / 2` → `3.5` |
| `//` | 整除 | `7 // 2` → `3` |
| `%` | 取余 | `7 % 2` → `1` |
| `**` | 幂 | `2 ** 10` → `1024` |

```python
minutes = 125
hours = minutes // 60
remain = minutes % 60
print(hours, remain)  # 2 5
```

### 5.2 比较（结果是 bool）

```python
print(3 > 1)   # True
print(3 == 3)  # True，注意是两个等号
print(3 != 2)  # True
print(3 >= 3)  # True
```

### 5.3 逻辑

```python
print(True and False)  # False
print(True or False)   # True
print(not True)        # False
```

### 5.4 赋值简写

```python
count = 0
count += 1   # 等同 count = count + 1
count *= 2
```

## 6. 输入 input()

```python
name = input("请输入姓名：")
print("你好,", name)
```

`input` 读入的**永远是字符串**。要数字必须转换：

```python
age_text = input("年龄：")
age = int(age_text)
print("明年", age + 1)
```

一行写法：

```python
age = int(input("年龄："))
```

若用户输入非数字 → `ValueError`，第 08 章学异常处理。

## 7. 常量约定

Python 没有 `final` 关键字。全大写名字表示「不要改」：

```python
MAX_SIZE = 100
PI = 3.14159
```

靠程序员自觉，不是语言强制。

---

## 8. None

表示「没有值」，类似 SQL 的 NULL：

```python
result = None
if result is None:
    print("还没有结果")
```

比较 None 用 `is None`，不要用 `== None`（习惯写法）。

---

## 9. 常见错误

```python
# 字符串和数字相加
"年龄:" + 30  # TypeError

# 正确
"年龄:" + str(30)
f"年龄:{30}"
```

```python
# 混淆 = 和 ==
if x = 3:  # SyntaxError，赋值不能写在 if 里
    pass
```
