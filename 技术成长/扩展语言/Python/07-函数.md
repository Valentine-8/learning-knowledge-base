# 07 · 函数

> **Java 对照**：`def` ≈ 方法；**无方法重载**（同名不同参靠默认参数/`*args`）；**可变默认参数** `def f(x, lst=[])` 是经典坑，Java 没有这个问题。
>
> **本章目标**：定义与调用函数；参数与返回值；作用域。
> **预计用时**：8～10 小时 · **难度**：★★★

---

## 1. 为什么需要函数

把重复逻辑封装成**可复用块**：

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
greet("Bob")
```

---

## 2. 定义与调用

```python
def add(a, b):
    """返回两数之和。"""  # 文档字符串 docstring
    return a + b

result = add(3, 5)
print(result)
```

- `def` 定义函数名和参数
- `return` 返回结果；没有 return 则返回 `None`
- 函数必须先定义再调用（同一文件内顺序）

## 3. 参数类型

### 3.1 位置参数

```python
def power(base, exp):
    return base ** exp

print(power(2, 10))
```

### 3.2 默认参数

```python
def connect(host, port=3306):
    print(host, port)

connect("localhost")
connect("localhost", 5432)
```

**陷阱**：默认值不要用可变对象！

```python
# 错误
def bad(x, bucket=[]):
    bucket.append(x)
    return bucket

# 正确
def good(x, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(x)
    return bucket
```

### 3.3 关键字参数

```python
def create_user(name, age, city="SZ"):
    return {"name": name, "age": age, "city": city}

create_user(name="Alice", age=30)
create_user("Bob", 25, city="BJ")
```

### 3.4 *args 与 **kwargs

```python
def log(level, *messages, **meta):
    print(level, messages, meta)

log("INFO", "a", "b", user="alice", ip="1.2.3.4")
```

## 4. 返回值

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([1, 5, 3])
print(lo, hi)
```

返回多个值实际是返回一个 **tuple**。

## 5. 作用域

```python
x = 10  # 全局

def foo():
    x = 20  # 局部，不影响全局
    print("内部", x)

foo()
print("外部", x)
```

**修改全局**（少用）：

```python
count = 0

def inc():
    global count
    count += 1
```

**LEGB 规则**：Local → Enclosing → Global → Built-in。嵌套函数：

```python
def outer():
    msg = "outer"

    def inner():
        print(msg)

    inner()

outer()
```

## 6. lambda 匿名函数

```python
square = lambda x: x * x
print(square(5))

nums = [3, 1, 4, 1, 5]
nums.sort(key=lambda x: -x)
print(nums)
```

复杂逻辑用 `def`，一行表达式可用 lambda。

## 7. 文档与类型提示（入门）

```python
def add(a: int, b: int) -> int:
```

2. 函数 `celsius_to_fahrenheit(c)` 返回华氏。
3. 函数接收 list，返回最大值和最小值（不用内置 max/min）。
4. 函数 `count_words(text)` 返回单词数（按空格 split）。
5. 递归：`factorial(5)` → 120。

### 练习 5 参考

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```
