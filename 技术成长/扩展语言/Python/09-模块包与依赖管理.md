## 1. 模块是什么

一个 `.py` 文件就是一个**模块**。把代码分到多个文件，便于组织。

`math_utils.py`：

```python
def add(a, b):
    return a + b

PI = 3.14159
```

`main.py`：

```python
import math_utils

print(math_utils.add(1, 2))
print(math_utils.PI)
```

## 2. import 几种写法

```python
import math
print(math.sqrt(16))

from math import sqrt
print(sqrt(16))

from math import sqrt as square_root
print(square_root(16))

# 不推荐：from math import *
```

---

## 3. `if __name__ == "__main__"`

模块被 import 时，不希望执行测试代码：

```python
# math_utils.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("自测:", add(1, 2))
```

直接运行 `python math_utils.py` 会打印自测；被 import 不会。

## 4. 包 package

含 `__init__.py` 的文件夹（3.3+ 可无，建议保留）：

```text
myproject/
├── main.py
└── tools/
    ├── __init__.py
    └── string_util.py
```

`tools/string_util.py`：

```python
def slugify(text):
    return text.lower().replace(" ", "-")
```

`main.py`：

```python
from tools.string_util import slugify
print(slugify("Hello World"))
```

## 5. 虚拟环境 venv

**每个项目独立环境**，避免包装乱。

```powershell
cd D:\学习\python-practice\myapp
python -m venv .venv
.venv\Scripts\Activate.ps1
```

激活后提示符前有 `(.venv)`。

```powershell
pip install requests
pip freeze > requirements.txt
```

别人恢复：

```powershell
pip install -r requirements.txt
```

退出环境：`deactivate`

## 6. pip 常用

```powershell
pip install requests==2.32.3
pip install -U pandas
pip uninstall requests
pip list
```

**习惯**：`requirements.txt` 锁版本。
