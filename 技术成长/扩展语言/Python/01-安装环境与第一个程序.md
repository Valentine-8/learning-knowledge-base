> **Java 对照**：你已会 `public static void main` 和 Maven。Python 用 `python hello.py` 直接运行源码，无需 javac；包管理用 pip（第 09 章），类似 Maven。
>
> **本章目标**：完成安装；会在终端运行 `.py`；认识**缩进代替 `{}`**。
> **预计用时**：1～2 小时（Java 开发者可快读概念部分） · **难度**：★

## 1. Python 是什么

Python 是一种**编程语言**。你用文字（代码）告诉计算机做什么，Python 解释器把代码一行行执行。

| 特点 | 说明 |
|------|------|
| 解释型 | 不用先编译成 exe，改代码后直接运行 |
| 语法简洁 | 接近英语，适合入门 |
| 用途广 | 网站、自动化、数据分析、人工智能 |

本知识库里：**Java 写业务系统，Python 写脚本和 AI 实验**。你已有 Java 基础，重点学**语法差异**和**生态工具**，不必从零理解「什么是编程」。

## 2. 安装 Python（Windows）

### 2.1 下载

1. 打开 [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 下载 **Python 3.12.x** 或 **3.11.x**（不要 2.x，已淘汰）
3. 运行安装包

### 2.2 安装选项（重要）

安装界面底部勾选：

- **Add python.exe to PATH**（必须勾选，否则终端找不到 python）

建议选 **Install Now**。安装路径默认即可。

### 2.3 验证安装

打开 **PowerShell** 或 **CMD**：

```powershell
python --version
```

应显示类似：

```text
Python 3.12.3
```

再试：

```powershell
python -c "print('ok')"
```

输出 `ok` 即成功。

**常见问题**：

| 现象 | 解决 |
|------|------|
| `python 不是内部或外部命令` | 重装并勾选 Add to PATH；或重启终端 |
| 显示 `Python 2.7` | 用 `py -3.12` 或调整 PATH 顺序 |
| 微软商店占位符 | 设置 → 应用 → 应用执行别名 → 关闭 python.exe 别名 |

## 4. 第一个程序

### 4.1 创建 hello.py

在任意文件夹（建议 `D:\学习\python-practice`）新建文件 `hello.py`：

```python
print("Hello, Python!")
print(1 + 2)
```

### 4.2 运行

终端进入该目录：

```powershell
cd D:\学习\python-practice
python hello.py
```

输出：

```text
Hello, Python!
3
```

**`print`**：把内容显示到屏幕。括号里是**表达式**，会先计算再显示。

### 4.3 程序结构初识

```python
# 这是注释，Python 会忽略

print("第一行")
print("第二行")
```

- 一行一条语句（简单程序）
- `#` 开头是**注释**，给人看的
- Python **区分大小写**：`Print` 会报错

## 5. 缩进：Python 的「大括号」

Java 用 `{ }` 包一段代码。Python 用**缩进**（通常 4 个空格）：

```python
if 3 > 1:
    print("条件成立")
    print("仍在 if 块内")
print("if 已结束")
```

**Java 对照**：

```java
if (3 > 1) {
    System.out.println("条件成立");
    System.out.println("仍在 if 块内");
}
System.out.println("if 已结束");
```

规则：

1. 冒号 `:` 后面要缩进
2. 同一块缩进必须一致（不要混 Tab 和空格）
3. 缩进结束 = 块结束

**错误示例**：

```python
if True:
print("缩进错了")   # IndentationError
```

## 6. 交互模式 vs 脚本模式

### 6.1 交互模式（REPL）

终端输入 `python` 回车，出现 `>>>`：

```python
>>> 1 + 1
2
>>> print("hi")
hi
>>> exit()
```

适合试一行代码。**学习阶段**也建议写 `.py` 文件，养成保存习惯。

### 6.2 脚本模式

把代码写在 `.py` 文件里，用 `python 文件名.py` 运行。正式项目都用这种方式。

## 7. 认识报错（别怕）

| 报错 | 含义 | 示例 |
|------|------|------|
| `SyntaxError` | 语法写错 | 少括号、缩进错 |
| `NameError` | 名字未定义 | 变量拼错 |
| `TypeError` | 类型不对 | `"1" + 1` |

示例：

```python
print("hello"
```

```text
SyntaxError: '(' was never closed
```

读报错：**最后一行**是类型，**箭头指向**大致位置。
