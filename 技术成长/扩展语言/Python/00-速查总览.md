## 1. 环境（30 秒）

```bash

# Windows: .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
python script.py
```

| 工具 | 用途 |
|------|------|
| `venv` | 虚拟环境，项目隔离 |
| `pip` | 装包 |

## 2. Java → Python 一句话对照

| Java | Python |
|------|--------|
| `static void main` | `if __name__ == "__main__":` |
| `List<String>` | `list[str]` / `List[str]` |
| `Map<K,V>` | `dict` |
| `null` | `None` |
| `true/false` | `True/False` |
| `interface` | `Protocol` / 鸭子类型 |
| `try-with-resources` | `with open(...) as f:` |
| `==` 比较对象 | `==` 值；`is` 身份（别乱用） |
| 编译型强类型 | 动态类型 + 可选 type hints |

## 3. 核心语法

```python
# 切片 [start:end:step]  左闭右开
nums[1:4]      # index 1,2,3
nums[-1]       # 最后一个
nums[::-1]     # 反转

# 解包
a, *mid, b = [1, 2, 3, 4, 5]
first, second = d.items()  # dict 遍历用 .items()

# 推导式
squares = [x*x for x in range(10) if x % 2 == 0]
mapping = {k: v for k, v in pairs}

# 默认参数陷阱：可变默认值用 None
def append_item(x, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(x)
    return bucket
```

## 6. 并发（面试一句）

| 模型 | 说明 |
|------|------|
| **GIL** | 同一进程多线程不能并行执行 Python 字节码；CPU 密集用 `multiprocessing` |

## 7. 工程习惯

```python
# 入口
def main() -> None:
    ...

if __name__ == "__main__":
    main()

# 日志
import logging
logging.basicConfig(level=logging.INFO)
log = logging.getLogger(__name__)
log.info("done %s", name)

# 配置：环境变量优先
import os
api_key = os.environ.get("OPENAI_API_KEY")
```

## 8. 易错点

- 用 `is` 比较字符串/数字（应使用 `==`）
- `except Exception: pass` 吞异常
- 可变默认参数 `def f(x, lst=[])`
- 循环里 `+=` 拼接大字符串（用 `list` + `join`）
- 不 pin 版本：`requirements.txt` 写 `requests` 不写 `requests==2.32.3`
