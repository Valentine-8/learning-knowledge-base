# 06 · 流程控制

> **本章目标**：if/elif/else；for 与 while；break/continue；range；嵌套循环。
> **预计用时**：6～8 小时 · **难度**：★★

---

## 1. if 语句

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

- 条件是**表达式**，结果为 bool
- 冒号 + 缩进块
- `elif` 可多个，`else` 可选

**注意**：Python 没有 `switch`（3.10+ 有 `match`，见 §6）。

---

## 2. 真值判断

以下视为 **False**：

```python
False, None, 0, 0.0, "", [], {}, set()
```

其余一般为 True：

```python
if []:
    print("不会执行")

if [1]:
    print("会执行")

name = ""
if not name:
    print("名字为空")
```

## 3. for 循环

```python
for i in range(5):
    print(i)  # 0 1 2 3 4

for i in range(2, 10, 2):
    print(i)  # 2 4 6 8

fruits = ["a", "b", "c"]
for f in fruits:
    print(f)
```

`range(n)` 生成 0～n-1 的整数序列（惰性，省内存）。

---

## 4. while 循环

```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("发射")
```

**避免死循环**：循环体内必须让条件最终为 False。

```python
# 读入直到 quit
while True:
    cmd = input("> ").strip()
    if cmd == "quit":
        break
    print("你输入了", cmd)
```

## 5. break 与 continue

```python
for n in range(10):
    if n == 3:
        continue   # 跳过本次，进入下一轮
    if n == 7:
        break      # 跳出整个循环
    print(n)
```

## 6. match（Python 3.10+，了解）

```python
def http_status(code):
    match code:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case 500 | 502:
            return "Server Error"
        case _:
            return "Unknown"

print(http_status(404))
```

零基础用 `if/elif` 足够；读新代码时认识即可。

## 7. 嵌套循环

打印乘法表片段：

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="\t")
    print()
```

**循环 else**（少见）：

```python
for n in range(2, 10):
    if n % 7 == 0:
        print("找到 7 的倍数")
        break
else:
    print("没找到")  # 没 break 才执行
```

## 8. 实用模式

### 8.1 累加 / 计数

```python
total = 0
for x in [1, 2, 3, 4, 5]:
    total += x
print(total)
```

### 8.2 找最大

```python
nums = [3, 1, 4, 1, 5]
best = nums[0]
for n in nums[1:]:
    if n > best:
        best = n
print(best)  # 也可 max(nums)
```

### 8.3 过滤

```python
nums = [1, 2, 3, 4, 5, 6]
evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
print(evens)
```

## 9. 本章练习

1. 读入整数，判断奇偶。
2. 打印 1～100 所有能被 3 整除的数。
3. 猜数字：程序想 42，用户反复猜，大了小了提示，直到猜对。
4. 九九乘法表（9×9）。
5. 斐波那契前 20 项：1, 1, 2, 3, 5, 8, …

### 练习 3 框架

```python
secret = 42
while True:
    guess = int(input("猜："))
    if guess == secret:
        print("对了")
        break
    elif guess > secret:
        print("大了")
    else:
        print("小了")
```
