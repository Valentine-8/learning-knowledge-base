# 05 · 字典与集合

---

## 1. 字典 dict

**键值对**映射，键必须**可哈希**（不可变类型），用 `{}`。

```python
user = {
    "id": 1001,
    "name": "Alice",
    "email": "alice@example.com",
}
print(user["name"])
print(user.get("age"))        # None，键不存在
print(user.get("age", 18))    # 默认 18
```

---

## 2. 增删改

```python
user = {"name": "Bob"}

user["age"] = 30              # 新增或修改
user.update({"city": "SZ", "age": 31})

del user["city"]
removed = user.pop("age", None)

print(user.keys())
print(user.values())
print(user.items())           # 键值对，遍历常用
```

**遍历**：

```python
for key in user:
    print(key, user[key])

for k, v in user.items():
    print(k, v)
```

## 3. 字典推导式

```python
nums = [1, 2, 3, 4, 5]
square_map = {n: n * n for n in nums}
print(square_map)
```

## 4. 嵌套结构（真实数据常这样）

```python
users = [
    {"id": 1, "name": "Alice", "tags": ["admin", "vip"]},
    {"id": 2, "name": "Bob", "tags": ["user"]},
]

print(users[1]["name"])
print(users[0]["tags"][0])

# 统计
for u in users:
    print(u["id"], u["name"])
```

JSON API 返回的数据几乎都是 dict + list 组合。

## 5. 集合 set

**无序、不重复**，用 `{1, 2, 3}` 或 `set()`。

```python
s = {1, 2, 3, 2, 1}
print(s)  # {1, 2, 3}

s.add(4)
s.remove(2)
s.discard(99)  # 不存在不报错

a = {1, 2, 3}
b = {3, 4, 5}
print(a & b)   # 交集 {3}
print(a | b)   # 并集 {1,2,3,4,5}
print(a - b)   # 差集 {1, 2}
```

**去重**：

```python
items = [1, 2, 2, 3, 3, 3]
unique = list(set(items))
print(unique)
```

## 6.  defaultdict 与 Counter（常用）

```python
from collections import defaultdict, Counter

# 自动创建缺失键
graph = defaultdict(list)
graph["a"].append("b")
graph["a"].append("c")
print(dict(graph))

# 计数
words = ["apple", "ban", "apple", "pie"]
cnt = Counter(words)
print(cnt.most_common(2))
```

## 8. 本章练习

1. 用 dict 存 5 个同学姓名→分数，查某人分数，改分数。
2. 统计字符串 `"hello world"` 每个字母出现次数（用 dict 或 Counter）。
3. 两个 list 找共同元素：`[1,2,3]` 和 `[2,3,4]`。
4. 嵌套：list 里 3 个 dict 表示商品（name, price），求总价。
5. 读入多行 `name:score`，存入 dict，打印最高分姓名。

### 练习 5 参考思路

```python
scores = {}
while True:
    line = input().strip()
    if not line:
        break
    name, score = line.split(":")
    scores[name] = int(score)

best = max(scores, key=scores.get)
print(best, scores[best])
```
