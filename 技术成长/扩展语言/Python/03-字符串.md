# 03 · 字符串

> **本章目标**：熟练字符串索引切片；常用方法；split/join；f-string 格式化。
> **预计用时**：6～8 小时 · **难度**：★★

---

## 1. 字符串本质

字符串是**字符序列**，用引号包起来，**不可变**（不能改某一个字符，只能生成新串）。

```python
s = "Python"
print(len(s))   # 6
print(s[0])     # P，索引从 0 开始
print(s[-1])    # n，-1 是最后一个
```

---

## 2. 索引与切片

```python
text = "hello world"

print(text[0])      # h
print(text[6])      # w
print(text[-1])     # d

# 切片 [start:end:step]  左闭右开
print(text[0:5])    # hello
print(text[6:])     # world
print(text[:5])     # hello
print(text[::2])    # hlowrd  步长 2
print(text[::-1])   # dlrow olleh  反转
```

**越界**：

```python
text[100]   # IndexError
text[0:100]  # 可以，自动截到末尾
```

---

## 3. 字符串拼接

```python
a = "Hello"
b = "Python"
print(a + " " + b)

# 重复
print("ab" * 3)  # ababab
```

大量拼接不要用 `+=` 循环（慢），用 `list` + `join`（见 §6）。

---

## 4. f-string（首选格式化）

```python
name = "Alice"
score = 95.5
print(f"姓名:{name}, 分数:{score:.1f}")
print(f"1+2={1+2}")
print(f"{'hi':>10}")  # 右对齐宽度 10
```

| 写法 | 含义 |
|------|------|
| `{score:.2f}` | 保留 2 位小数 |
| `{n:05d}` | 整数宽度 5，前补 0 |
| `{s!r}` | repr 形式 |

旧式 `%` 和 `.format()` 了解即可，新代码用 f-string。

## 5. 常用方法

```python
s = "  Hello Python  "

print(s.strip())           # 去两端空白
print(s.lower())           # 小写
print(s.upper())           # 大写
print(s.replace("Python", "World"))
print(s.startswith("  H"))
print(s.endswith("n  "))
print("Py" in s)           # True
print(s.find("Python"))    # 索引，找不到 -1
print(s.index("Python"))   # 找不到抛 ValueError
print(s.count("l"))
```

**分割与连接**：

```python
line = "apple,banana,cherry"
parts = line.split(",")
print(parts)  # ['apple', 'banana', 'cherry']

joined = "-".join(parts)
print(joined)  # apple-banana-cherry
```

**按行拆**：

```python
multiline = "a\nb\nc"
lines = multiline.splitlines()
```

## 6. join 性能

```python
words = ["I", "love", "Python"]
sentence = " ".join(words)
print(sentence)
```

错误做法（慢）：

```python
result = ""
for w in words:
    result += w + " "
```

## 7. 转义与原始字符串

```python
print("第一行\n第二行")
print("路径: C:\\Users\\name")
print(r"C:\Users\name")  # 原始字符串，\ 不转义
```

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表 |
| `\\` | 反斜杠 |
| `\'` `\"` | 引号 |

三引号多行：

```python
doc = """
第一行
第二行
"""
```

## 8. 字符串不可变

```python
s = "hello"
# s[0] = "H"  # TypeError

s = "H" + s[1:]  # 正确：新建字符串
print(s)
```

## 9. 实用小函数

```python
# 去除用户输入空白
user = input("用户名:").strip()

# 大小写不敏感比较
if user.lower() == "admin":
    print("管理员")

# 是否全数字
"12345".isdigit()      # True
"12a".isdigit()        # False

# 是否字母
"abc".isalpha()
```
