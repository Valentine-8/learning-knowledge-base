## 题 4 · 环形缓冲区（重点）

**要求**：模板或 C 均可；支持 `push`、`pop`、`empty`、`full`；线程不安全版即可，能讲如何加 mutex。

```cpp
// 接口示例
class RingBuffer {
public:
    explicit RingBuffer(size_t cap);
    bool push(uint8_t byte);
    bool pop(uint8_t& byte);
    bool empty() const;
    bool full() const;
private:
    std::vector<uint8_t> buf_;
    size_t head_, tail_, cap_;
};
```

**考察点**：head/tail 取模；满/空判定 `(tail+1)%cap == head`；嵌入式 UART RX 常用。

<details>
<summary>题 4 · 环形缓冲区</summary>

```cpp
bool RingBuffer::push(uint8_t b) {
    size_t next = (tail_ + 1) % cap_;
    if (next == head_) return false;
    buf_[tail_] = b;
    tail_ = next;
    return true;
}
bool RingBuffer::pop(uint8_t& b) {
    if (head_ == tail_) return false;
    b = buf_[head_];
    head_ = (head_ + 1) % cap_;
    return true;
}
```
</details>
