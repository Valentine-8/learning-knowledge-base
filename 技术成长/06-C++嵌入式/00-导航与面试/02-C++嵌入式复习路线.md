# C++ 嵌入式复习路线（2～4 周）

> 按 **Java 工程师转岗嵌入式** 设计。每日勾选 [03-复习进度追踪.md](./03-复习进度追踪.md)。

---

## 目标能力（面试够用线）

| 能力 | 标准 |
|------|------|
| C++ 语法 | 能讲指针/引用/RAII/智能指针/虚函数/移动语义 |
| 内存 | 栈堆、对齐、泄漏、volatile **≠** atomic |
| 并发 | mutex、条件变量、atomic 基础；RTOS 信号量能类比 |
| 总线 | UART/SPI/I2C/CAN 区别 + 适用场景 |
| RTOS | 任务调度、优先级反转、临界区 |
| Linux 嵌入式 | 交叉编译、g++ 构建、pthread、socket 基础 |
| 手写 | 环形队列、位操作、简单状态机 |
