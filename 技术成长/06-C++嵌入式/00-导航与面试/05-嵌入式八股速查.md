## 一、总线与通信（Q1～Q15）

### Q1. UART 特点？

**A：** 异步、全双工、点对点；TX/RX/GND；波特率需一致；简单远距离调试首选；无时钟线。

### Q2. UART 帧结构？

**A：** 起始位(0) + 数据位(5～9) + 可选校验 + 停止位(1～2)；LSB 先发。

### Q3. SPI 特点？

**A：** 同步、全双工；主从；SCLK/MOSI/MISO/CS；速度快；多从需多 CS；占 GPIO 多。

### Q4. SPI 模式 0～3？

**A：** CPOL（空闲时钟电平）+ CPHA（采样边沿）；模式 0：CPOL=0 CPHA=0 最常见。

### Q5. I2C 特点？

**A：** 同步、半双工；两线 SDA/SCL；多主多从；7/10 位地址；上拉电阻；速度 100k/400k/1M。

### Q6. I2C 与 SPI 选型？

**A：** 传感器多、引脚少 → I2C；高速 ADC/Flash → SPI；长距离多节点 → CAN。

### Q7. CAN 总线特点？

**A：** 差分、多主、广播、仲裁 ID； automotive/航空常用；可靠、抗干扰；125k～1M。

### Q8. CAN 帧类型？

**A：** 数据帧、远程帧、错误帧、过载帧；标准 ID 11 位 / 扩展 29 位。

### Q9. RS485 与 UART？

**A：** RS485 在 UART 之上用差分驱动；半双工多节点；工业现场。

### Q10. Ethernet 在嵌入式？

**A：** 百兆/千兆 PHY + MAC；TCP/IP 栈（lwIP 或 Linux）；无人机图传、地面站。

### Q11. DMA 是什么？

**A：** 外设与内存直接搬运，不占用 CPU；适合 ADC 采样、SPI 大块传输；需配置通道、地址、长度。

### Q12. 中断 vs 轮询？

**A：** 中断：事件驱动、省 CPU、响应快；轮询：简单但占 CPU。实时外设多用中断+DMA。

### Q13. 中断里能 printf 吗？

**A：** **不推荐**；ISR 要短；printf 慢且可能重入；设标志位，任务里处理。

### Q14. 大端小端？

**A：** 多字节存储顺序；网络字节序大端；ARM 常小端；`htonl/ntohl` 转换。

### Q15. 波特率误差容忍？

**A：** UART 一般 ±2% 内可通信；时钟源精度、分频系数影响。

## 二、RTOS（Q16～Q25）

### Q16. RTOS 与 Linux 区别？

**A：** RTOS：确定性、可预测延迟、资源小、无 MMU 也可；Linux：功能全、延迟抖动大、适合应用层。

### Q17. 任务状态？

**A：** 就绪、运行、阻塞、挂起；调度器选最高优先级就绪任务。

### Q18. 信号量 vs 互斥量？

**A：** 信号量计数、可多个资源；互斥量二元、谁加锁谁解锁、有优先级继承；保护临界区用 mutex。

### Q19. 优先级反转？

**A：** 高优先级等低优先级持有的锁，中优先级任务抢占低 → 高被间接阻塞；**优先级继承**缓解。

### Q20. 消息队列用途？

**A：** 任务间传数据；异步解耦；ISR 发队列、任务收。

### Q21. FreeRTOS 常用 API（了解）？

**A：** `xTaskCreate`、`vTaskDelay`、`xSemaphoreTake/Give`、`xQueueSend/Receive`。

### Q22. tick 与阻塞？

**A：** `vTaskDelay(n)` 阻塞 n 个 tick；实际时间 = n × tick_period。

### Q23. 栈溢出怎么查？

**A：** 栈水印 fill pattern；MPU 保护；调试器看 SP；增大 stack size。

### Q24. 临界区？

**A：** 关中断或 mutex；保护共享变量；越短越好。

### Q25. 裸机 vs RTOS 何时选？

**A：** 简单状态机裸机；多模块并发、网络协议栈 → RTOS 或 Linux。

## 三、Linux 嵌入式（Q26～Q35）

### Q26. 交叉编译是什么？

**A：** 在 x86 主机用 `arm-linux-gnueabihf-g++` 生成 ARM 可执行文件；需 sysroot/链接库。

### Q27. Makefile / CMake 核心？

**A：** 目标、依赖、编译选项 `-O2 -Wall`、链接 `-lpthread`；CMake 跨平台生成构建文件。

### Q28. 设备树 Device Tree？

**A：** 描述硬件连接；Linux 内核 boot 解析；驱动与硬件解耦。

### Q29. 用户态驱动访问硬件？

**A：** `/dev/xxx` + `open/read/write/ioctl`；内核驱动注册字符设备。

### Q30. pthread 创建与同步？

**A：** `pthread_create/join`；`pthread_mutex_t`；`pthread_cond_wait/signal`。

### Q31. 进程 vs 线程嵌入式？

**A：** 线程共享地址空间轻量；进程隔离好；嵌入式 Linux 应用多用多线程。

### Q32. socket 编程步骤？

**A：** `socket → bind → listen → accept`（服务端）；`connect`（客户端）；`send/recv`。

### Q33. TCP vs UDP 无人机场景？

**A：** 控制指令 TCP/可靠；图传/遥测可 UDP + 应用层重传；实时性 UDP 低延迟。

### Q34. OTA 升级注意？

**A：** 双分区、校验签名、断电保护、回滚；bootloader 切换。

### Q35. gdb 远程调试？

**A：** `gdbserver`  on target + host `target remote`；交叉 gdb。

## 四、C/C++ 嵌入式特有点（Q36～Q40）

### Q36. volatile 用途？

**A：** 告诉编译器 **不要优化掉** 对变量的读写；**硬件寄存器**、ISR 共享标志；**不保证原子**、不替代 mutex。

### Q37. volatile 与 atomic 区别？（=C++专题 C96）

**A：** atomic 有内存序、CAS；volatile 仅防优化；多线程同步用 atomic/mutex。

### Q38. 位域、位操作？

**A：** 寄存器配置常用 `| & ^ << >>`；清位 `(reg &= ~MASK)`；置位 `(reg |= MASK)`。

### Q39. 看门狗 WDT？

**A：** 定时喂狗，超时复位；防程序跑飞；RTOS idle 或专用任务 feed。

### Q40. 飞控/无人机软件分层（概念）？

**A：** 传感器驱动 → 姿态估计(IMU+融合) → 控制律(PID) →  actuators；通信链路(MAVLink 等)；地面站。具体栈因公司而异，**面试诚实说了解架构，细节入职学**。
