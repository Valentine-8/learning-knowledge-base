> 给 **赵晨宇** 这种 7 年 Java 后端：知道差在哪、怎么补、面试怎么说。

## 一、概念对照表

| Java | C/C++ 嵌入式 |
|------|----------------|
| GC | **手动/RAII**；对象生命周期你要管 |
| `new Object()` | `new`/`malloc`；必须 `delete`/`free` 或智能指针 |
| 引用默认安全 | **指针** 可 null、悬空、越界 |
| `synchronized` | `mutex` / `pthread_mutex` / RTOS semaphore |
| `volatile`（Java 内存可见） | C++ `volatile` **语义不同** → 硬件用 volatile，线程用 atomic |
| 异常 try/catch | 嵌入式常 **禁用异常**（-fno-exceptions） |
| 泛型擦除 | C++ 模板 **编译期展开**，代码体积增大 |
| Spring 容器 | 没有；自己管理依赖 |
| JAR 部署 | 交叉编译 **ELF 二进制** 烧录/OTA |
| REST | UART/CAN/socket 二进制协议 |

## 三、Java 经验怎么「翻译」成嵌入式话术

| Java 经历 | 嵌入式类比 |
|-----------|------------|
| cc-site-svc BFF | **通信网关**、协议转发、token=会话鉴权 |
| 多租户 orgId 路由 | **设备 ID / 节点地址** 路由 |
| FollowUpAI 消息队列 | **任务间队列**、异步事件 |
| CloudCC 服务云移动 API | **端侧状态同步**、离线/弱网（概念类比） |
| 人社部流程系统 | **严格状态机**、审计、规则引擎 |
| Redis 限流 | **资源受限**下的节流 |

**面试句**：「虽然我最近栈是 Java，但 **BFF 网关、多线程服务、状态机业务** 和嵌入式里的 **通信中间层、RTOS 任务、事件驱动** 在结构上是相通的。」

## 四、建议避免的坑

| ❌ | ✅ |
|----|-----|
| 说「Java 和 C++ 差不多」 | 承认内存/并发模型差异，正在补 |
| Claim 多年 STM32 经验 | 说学习路径 + 手写 + 若有板子实验 |
| 把 volatile 当 synchronized | 背 C96 + 八股 Q36～Q37 |
