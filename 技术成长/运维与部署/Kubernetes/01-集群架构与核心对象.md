# 01 · 集群架构与核心对象

> **目标读者**：理解 K8s 控制面与数据面、会写 Pod/Deployment YAML、掌握 label/selector。
> **预计阅读**：60 min · **难度**：★★★★

---

## 1. 为什么需要 Kubernetes

Docker 解决 **单机** 打包运行；生产需要：

- 多机调度、故障自愈、弹性伸缩
- 滚动发布、配置/密钥管理
- 服务发现、负载均衡

**K8s** = 容器编排平台，声明式 API + 控制器循环。

---

## 2. 控制平面组件

| 组件 | 作用 |
|------|------|
| **kube-apiserver** | 唯一 API 入口，认证鉴权、校验、持久化到 etcd |
| **etcd** | 分布式 KV，存集群 desired/actual state |
| **kube-scheduler** | 为新 Pod 选 Node（资源、亲和、污点） |
| **kube-controller-manager** | 各控制器：Deployment、ReplicaSet、Node、Job… |
| **cloud-controller-manager** | 对接云 LB、路由等（可选） |

**声明式**：你 `kubectl apply` 期望状态；控制器不断 reconcile 实际状态。

---

## 3. 节点组件

| 组件 | 作用 |
|------|------|
| **kubelet** | 节点 agent，管 Pod 生命周期、挂载 volume、探针 |
| **kube-proxy** | Service ClusterIP 的 iptables/IPVS 规则 |
| **容器运行时** | containerd / CRI-O（运行容器） |

## 4. Pod — 最小调度单元

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: order-app
  labels:
    app: order-app
    version: v1
spec:
  containers:
    - name: app
      image: order-app:1.0.0
      ports:
        - containerPort: 8080
      env:
        - name: SPRING_PROFILES_ACTIVE
          value: prod
      resources:
        requests:
          memory: "512Mi"
          cpu: "250m"
        limits:
          memory: "1Gi"
          cpu: "1000m"
  restartPolicy: Always
```

| 概念 | 说明 |
|------|------|
| 一个 Pod 多容器 | sidecar（日志、mesh）、init 容器 |
| 共享 | Network namespace（localhost 互通）、Volume |
| IP | 每 Pod 一个集群内 IP，重启可能变 |

**生产很少直接创建 Pod**，用 Deployment 管理。

## 5. Label 与 Selector

```yaml
metadata:
  labels:
    app: order-app
    tier: backend
spec:
  selector:
    matchLabels:
      app: order-app
```

```bash
kubectl get pods -l app=order-app
kubectl label pod foo env=prod --overwrite
```

Service、Deployment 通过 **selector** 关联 Pod。

## 6. Deployment 与 ReplicaSet

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: order-app
spec:
  replicas: 3
  revisionHistoryLimit: 5
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  selector:
    matchLabels:
      app: order-app
  template:
    metadata:
      labels:
        app: order-app
    spec:
      containers:
        - name: app
          image: order-app:1.0.1
```

```
Deployment
    └── ReplicaSet (revision 2)
            └── Pod × 3
```

更新镜像 → 新 ReplicaSet → 逐步扩新缩旧。

## 7. Namespace 与资源隔离

```bash
kubectl create namespace prod
kubectl get pods -n prod
```

| 常见 ns | 用途 |
|---------|------|
| default | 默认 |

## 8. ConfigMap 与 Secret

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  application.yaml: |
    server:
      port: 8080
---
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
stringData:
  password: "change-me"
```

挂载到 Pod：

```yaml
envFrom:
  - secretRef:
      name: db-secret
volumeMounts:
  - name: config
    mountPath: /config
    readOnly: true
volumes:
  - name: config
    configMap:
      name: app-config
```

**Secret 默认 base64，非加密**；生产用 sealed-secrets、Vault、云 KMS。
