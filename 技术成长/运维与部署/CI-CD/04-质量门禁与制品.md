# 04 · 质量门禁与制品

> **预计阅读**：50 min · **难度**：★★★

---

## 1. 质量门禁体系

```
代码提交
  → 编译通过（Gate 1）
  → 单元测试 100% pass（Gate 2）
  → 覆盖率 ≥ 60%（Gate 3）
  → Sonar 无 Blocker（Gate 4）
  → 依赖无高危 CVE（Gate 5）
  → 镜像无 Critical 漏洞（Gate 6）
  → 部署
```

不达标 **abortPipeline**，禁止合并或发布。

---

## 2. 单元测试与覆盖率

```xml
<!-- pom.xml JaCoCo -->
<plugin>
  <groupId>org.jacoco</groupId>
  <artifactId>jacoco-maven-plugin</artifactId>
  <executions>
    <execution>
      <goals><goal>prepare-agent</goal></goals>
    </execution>
    <execution>
      <id>report</id>
      <phase>verify</phase>
      <goals><goal>report</goal></goals>
    </execution>
    <execution>
      <id>check</id>
      <goals><goal>check</goal></goals>
      <configuration>
        <rules>
          <rule>
            <element>BUNDLE</element>
            <limits>
              <limit>
                <counter>LINE</counter>
                <value>COVEREDRATIO</value>
                <minimum>0.60</minimum>
              </limit>
            </limits>
          </rule>
        </rules>
      </configuration>
    </execution>
  </executions>
</plugin>
```

## 3. SonarQube

```bash
mvn sonar:sonar \
  -Dsonar.projectKey=order-service \
  -Dsonar.host.url=http://sonar.company.com \
  -Dsonar.token=$SONAR_TOKEN
```

| 指标 | 门禁建议 |
|------|----------|
| Coverage | ≥ 60%（核心模块更高） |
| Duplicated Lines | < 3% |
| Blocker/Critical | 0 |
| Security Hotspots | 已审查 |

Jenkins：`waitForQualityGate abortPipeline: true`

|------|------|
| OWASP Dependency-Check | CVE 数据库 |
| Snyk | SaaS，PR 集成 |

## 6. 制品管理

### Maven 制品（Nexus / Artifactory）

```xml
<distributionManagement>
  <repository>
    <id>nexus-releases</id>
    <url>https://nexus.company.com/repository/maven-releases/</url>
  </repository>
</distributionManagement>
```

```bash
mvn deploy -DskipTests   # CI 已测完再 deploy
```

### Docker 镜像（Harbor / ECR）

| 实践 | 说明 |
|------|------|
| 标签 | git sha + build number，禁 latest 上生产 |
| 扫描 | Harbor Trivy 内置 |
| 签名 | cosign 镜像签名 |
| 保留策略 | 按时间/数量清理 |

## 7. SBOM 与可追溯

**SBOM**（Software Bill of Materials）：软件物料清单，供应链安全要求。

```bash
# CycloneDX Maven 插件
mvn org.cyclonedx:cyclonedx-maven-plugin:makeAggregateBom
```

制品元数据：谁构建、哪次 commit、依赖版本、扫描结果。
