## 1. 生产故障案例

### 案例 1：SNAPSHOT 依赖上生产

| 项 | 内容 |
|----|------|
| 现象 | 生产行为与测试不一致 |
| 根因 | CI 未阻断 SNAPSHOT，Nexus 上 SNAPSHOT 被覆盖 |
| 修复 | release 分支只允许 release 版本；deploy 门禁 |
| 预防 | maven-enforcer-plugin  ban SNAPSHOT |

### 案例 2：Docker latest 回滚失败

| 项 | 内容 |
|----|------|
| 现象 | 出问题想回滚，不知道上一版本镜像 |
| 根因 | 始终 push `:latest`，覆盖旧镜像 |
| 修复 | 按 git sha 打 tag；K8s deployment 记录 revision |
| 预防 | 禁 latest 上 prod |

### 案例 3：Sonar 门禁绕过

| 项 | 内容 |
|----|------|
| 现象 | 技术债累积，Coverage 30% |
| 根因 | `-Dsonar.skip=true` 在 Jenkinsfile 被加入 |
| 修复 | 主干保护 + Quality Gate 强制 |
| 预防 | PR 必须过 CI；Code Review 看 Jenkinsfile |
