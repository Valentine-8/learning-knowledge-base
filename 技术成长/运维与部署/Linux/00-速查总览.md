## 2. 文件与目录速查

```bash
ls -lah          # 列表含隐藏、人类可读
cd /var/log      # 切换目录
pwd              # 当前路径
find / -name "*.log" 2>/dev/null
grep -r "ERROR" /app/logs/
tail -f app.log  # 实时跟踪
head -n 100 f    # 前 100 行
wc -l file       # 行数
```

| 路径 | 含义 |
|------|------|
| `/etc` | 配置文件 |
| `/var/log` | 日志 |
| `/proc` | 进程与内核信息（虚拟） |
| `/tmp` | 临时文件 |
| `/home` | 用户家目录 |
| `/opt` / `/app` | 应用部署 |

## 3. 进程速查

```bash
ps aux | grep java
ps -ef --forest
top / htop
kill -15 PID     # SIGTERM 优雅
kill -9 PID      # SIGKILL 强制
pkill -f "order-service"
pgrep -f java
nice -n 10 command
```

| 信号 | 含义 |
|------|------|
| SIGTERM (15) | 请求终止 |
| SIGKILL (9) | 强制杀死，不可捕获 |
| SIGHUP (1) | 重载配置 |

## 4. 权限速查

```bash
chmod 755 script.sh    # rwxr-xr-x
chown app:app /app
chown -R app:app /app/logs

# 数字：owner-group-other
# r=4 w=2 x=1
```

| 权限 | 文件 | 目录 |
|------|------|------|
| r | 读内容 | 列目录 |
| w | 写内容 | 增删改目录项 |
| x | 执行 | 进入目录 |

**sudo**：`visudo` 编辑，`/etc/sudoers`。

---

## 5. 网络速查

```bash
ss -tlnp              # 监听端口
ss -tan state established
curl -v http://localhost:8080/health
ping host
traceroute host
dig domain
nslookup domain
telnet host 3306      # 测端口（或用 nc -zv）
```

---

## 6. 磁盘与内存

```bash
df -h                 # 文件系统用量
du -sh /var/log/*     # 目录大小
free -h               # 内存
vmstat 1              # 每秒采样
iostat -x 1           # 磁盘 IO
uptime                # 负载 load average
```

## 7. 排障三板斧

```
1. 看现象 → 日志（应用 + 系统）
2. 看资源 → CPU/内存/磁盘/网络/负载
3. 看进程 → 端口、连接、线程、堆栈
```

Java 专项：`jstack` `jmap` `arthas`（见 Java 笔记）。

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| load average 含义？ | 1/5/15 分钟运行队列+不可中断 IO 平均长度 |
| 软链接和硬链接？ | 软链新 inode 指路径；硬链同 inode 共享数据 |
| 僵尸进程？ | 子进程结束父未 wait，占 PID，需杀父进程 |
| 0 号进程？ | systemd（旧 init），所有进程祖先 |
| top 中 %wa 高？ | IO wait，查磁盘瓶颈 |
