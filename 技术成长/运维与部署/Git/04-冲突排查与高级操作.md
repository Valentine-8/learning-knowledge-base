# 04 · 冲突排查与高级操作

## 冲突解决

```bash
git status   # Unmerged paths
# 编辑文件去掉 <<<< ==== >>>>
git add .
git commit   # 或 rebase --continue
```

## stash

```bash
git stash push -m "wip"
git stash pop
```

## reflog（救命）

```bash
git reflog
git reset --hard HEAD@{2}
```

误 reset 后找回 commit。

## revert（安全回滚）

```bash
git revert <bad-commit>
```

生成反向提交，适合已推送历史。

## bisect（找引入 bug 的 commit）

```bash
git bisect start
git bisect bad
git bisect good <old-good-sha>
```
