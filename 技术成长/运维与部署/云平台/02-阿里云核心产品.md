# 02 · 阿里云核心产品

> **预计阅读**：60 min · **难度**：★★★

---

## 1. 计算

### ECS（Elastic Compute Service）

| 概念 | 说明 |
|------|------|
| 实例规格 | 通用 g、计算 c、内存 r |
| 镜像 | Alibaba Cloud Linux、CentOS、Windows |
| 系统盘/数据盘 | ESSD 云盘 |
| 安全组 | 入站出站规则 |
| 密钥对 | SSH 登录 |

```bash
# Java 应用典型配置
# 4C8G ESSD 100G + 安全组 8080 内网
```

### ACK（容器服务 Kubernetes）

托管 K8s：控制面免运维，Worker 为 ECS 或 ECI。

| 模式 | 说明 |
|------|------|
| 托管版 | 推荐，Master 免费 |
| Serverless | ECI 按 Pod 计费 |
| 专有版 | 自管 Master |

## 2. 网络

| 产品 | 说明 |
|------|------|
| VPC | 私有网络 10.0.0.0/8 |
| vSwitch | 子网，绑定 AZ |
| SLB | 四层/七层负载均衡 |
| ALB | 应用型 LB，HTTP/HTTPS |
| NLB | 网络型，高性能 |
| CDN | 静态资源加速 |
| WAF | Web 应用防火墙 |
| DDoS 高防 | 流量清洗 |

**典型**：公网 SLB → 私网 ACK Ingress → Pod。

---

## 3. 存储

| 产品 | 类型 | 场景 |
|------|------|------|
| OSS | 对象 | 图片、日志归档、静态资源 |
| NAS | 文件 | 共享目录 |
| ESSD | 块 | ECS/数据库盘 |
| Tablestore | NoSQL | 海量结构化 |

```java
// OSS Java SDK
OSS ossClient = new OSSClientBuilder().build(endpoint, accessKeyId, accessKeySecret);
ossClient.putObject("bucket", "orders/1.pdf", new File("1.pdf"));
String url = ossClient.generatePresignedUrl("bucket", "orders/1.pdf", expiration);
```

## 4. 数据库与缓存

| 产品 | 说明 |
|------|------|
| RDS MySQL | 托管 MySQL，主备、只读 |
| RDS PostgreSQL | 同 RDS 系列 |
| PolarDB | 云原生数据库，存算分离 |
| Redis/Tair | 托管缓存，集群版 |
| MongoDB | 托管 MongoDB |
| DTS | 数据迁移同步 |

**RDS 优势**：自动备份、监控、主备切换、参数组。

```yaml
# Spring 连 RDS
spring:
  datasource:
    url: jdbc:mysql://rm-xxx.mysql.rds.aliyuncs.com:3306/shop
```

## 5. 中间件

| 产品 | 说明 |
|------|------|
| RocketMQ | 消息队列，阿里开源 |
| MSE | 微服务引擎，托管 Nacos/Zookeeper |

| AHAS | 限流熔断（Sentinel 云版） |
| API 网关 | 统一入口、鉴权、限流 |

## 6. 安全与身份

| 产品 | 说明 |
|------|------|
| RAM | 身份与访问管理 |
| STS | 临时凭证 |
| KMS | 密钥管理 |
| 堡垒机 | 运维审计 |
| 云安全中心 | 漏洞、基线 |

**最佳实践**：应用用 **RAM 角色** 访问 OSS，不用 AccessKey 硬编码。

## 7. 运维与 DevOps

| 产品 | 说明 |
|------|------|
| 云监控 | 基础指标告警 |
| 日志服务 SLS | 类似 ELK |
| 云效 | CI/CD |
| Terraform | 基础设施即代码 |

---

## 8. 典型三层架构（阿里云）

```
Internet
   → CDN（静态）
   → WAF → SLB
   → ACK（Java 微服务 × N）
   → RDS MySQL 主 + 只读
   → Redis 集群
   → RocketMQ
   → OSS（文件）
   → SLS + ARMS（可观测）
```

---

## 9. 小结

| 要点 | 一句话 |
|------|--------|
| ECS/ACK | 计算首选容器化 ACK |
| RDS | 生产 MySQL 用托管 |
| OSS | 文件上对象存储 |
| RAM | 最小权限，角色替 AK |
