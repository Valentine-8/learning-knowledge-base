## 1. 函数

```bash
log_info() {
  echo "[INFO] $(date '+%Y-%m-%d %H:%M:%S') $*"
}

log_error() {
  echo "[ERROR] $*" >&2
}

deploy() {
  local env=$1
  local version=$2
  log_info "Deploying $version to $env"
  # ...
}

deploy prod v1.2.0
```

| 关键字 | 说明 |
|--------|------|
| `local` | 函数内局部变量 |
| `return N` | 返回退出码，非值 |
| `$*` / `$@` | 函数参数 |

## 2. 参数解析 getopts

```bash
#!/bin/bash
set -euo pipefail

usage() {
  echo "Usage: $0 -e ENV -v VERSION [-f]"
  exit 1
}

ENV=""
VERSION=""
FORCE=false

while getopts "e:v:fh" opt; do
  case $opt in
    e) ENV=$OPTARG ;;
    v) VERSION=$OPTARG ;;
    f) FORCE=true ;;
    h) usage ;;
    *) usage ;;
  esac
done

[[ -z "$ENV" || -z "$VERSION" ]] && usage
echo "Deploy $VERSION to $ENV, force=$FORCE"
```

## 3. 实战：健康检查脚本

```bash
#!/bin/bash
set -euo pipefail

URL="${1:-http://localhost:8080/actuator/health}"
TIMEOUT=5
RETRIES=3

check_health() {
  local code
  code=$(curl -s -o /dev/null -w "%{http_code}" --connect-timeout "$TIMEOUT" "$URL")
  [[ "$code" == "200" ]]
}

for i in $(seq 1 $RETRIES); do
  if check_health; then
    echo "OK: $URL"
    exit 0
  fi
  echo "Attempt $i failed, retry..."
  sleep 2
done

echo "FAIL: $URL not healthy" >&2
exit 1
```

## 4. 实战：日志清理

```bash
#!/bin/bash
set -euo pipefail

LOG_DIR=${LOG_DIR:-/app/logs}
RETAIN_DAYS=${RETAIN_DAYS:-7}

find "$LOG_DIR" -name "*.log.gz" -mtime +"$RETAIN_DAYS" -delete
find "$LOG_DIR" -name "*.log" -size +500M -exec gzip {} \;

usage=$(df -h "$LOG_DIR" | awk 'NR==2 {print $5}' | tr -d '%')
if [[ $usage -gt 85 ]]; then
  echo "WARN: disk usage ${usage}%" | mail -s "Log Alert" ops@company.com
fi
```

## 5. 实战：批量重启 Java 服务

```bash
#!/bin/bash
set -euo pipefail

SERVICES=(order-service payment-service user-service)
APP_HOME=/app
JAVA_OPTS="-Xms512m -Xmx512m"

for svc in "${SERVICES[@]}"; do
  pid=$(pgrep -f "${svc}.jar" || true)
  if [[ -n "$pid" ]]; then
    echo "Stopping $svc (PID $pid)..."
    kill -15 "$pid"
    for i in {1..30}; do
      kill -0 "$pid" 2>/dev/null || break
      sleep 1
    done
    kill -0 "$pid" 2>/dev/null && kill -9 "$pid"
  fi
  echo "Starting $svc..."
  nohup java $JAVA_OPTS -jar "$APP_HOME/$svc/$svc.jar" \
    > "$APP_HOME/$svc/logs/console.log" 2>&1 &
  sleep 5
done
```

生产更推荐 **systemd** 或 **K8s rollout**。

## 6. 实战：备份脚本

```bash
#!/bin/bash
set -euo pipefail

BACKUP_DIR=/backup
DATE=$(date +%Y%m%d_%H%M%S)
DB_HOST=localhost
DB_NAME=shop

mysqldump -h "$DB_HOST" -u backup -p"$DB_PASS" \
  --single-transaction "$DB_NAME" \
  | gzip > "$BACKUP_DIR/${DB_NAME}_${DATE}.sql.gz"

find "$BACKUP_DIR" -name "*.sql.gz" -mtime +14 -delete

# 可选上传 OSS
# aws s3 cp "$BACKUP_DIR/${DB_NAME}_${DATE}.sql.gz" s3://bucket/backup/
```

## 8. 调试技巧

```bash
bash -x script.sh          # 跟踪执行
bash -n script.sh          # 语法检查
set -x                     # 脚本内开启
set +x                     # 关闭

# 陷阱清理
trap 'rm -f /tmp/mylock' EXIT
```

## 9. 与 Java 项目集成

| 场景 | 脚本位置 |
|------|----------|
| 启动停止 | `bin/start.sh` |
| CI 构建 | `scripts/build.sh` |
| Docker entrypoint | `docker-entrypoint.sh` |
| Git hooks | `.git/hooks/pre-commit` |

Maven 调用：

```xml
<exec-maven-plugin>
  <execution>
    <phase>package</phase>
    <goals><goal>exec</goal></goals>
    <configuration>
      <executable>bash</executable>
      <arguments><argument>scripts/package.sh</argument></arguments>
    </configuration>
  </execution>
</exec-maven-plugin>
```
