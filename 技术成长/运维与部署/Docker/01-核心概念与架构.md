# 01 · 核心概念与架构

> **目标读者**：理解容器底层隔离原理、镜像分层与存储驱动，能在面试中对比 VM 与 Docker。
> **预计阅读**：50 min · **难度**：★★★

---

## 1. Docker 是什么

Docker 是 **容器运行时 + 镜像格式 + 工具链**，把应用与依赖打包成可移植单元，「一次构建，到处运行」。

**Java 后端价值**：

- 开发/测试/生产环境一致（JDK 版本、时区、字体）
- CI 构建镜像 → 仓库 → K8s 滚动发布
- 本地 `docker compose up` 拉起 MySQL/Redis/MQ + Boot

## 2. Docker vs 虚拟机

```
虚拟机                           容器
┌──────┐ ┌──────┐              ┌──────┐ ┌──────┐
│ App  │ │ App  │              │ App  │ │ App  │
│ Guest│ │ Guest│              └──────┘ └──────┘
│  OS  │ │  OS  │              ┌─────────────────┐
└──┬───┘ └──┬───┘              │   Docker Engine  │
   Hypervisor                 └────────┬─────────┘
┌──────────────┐                      Host OS
│   Host OS    │                      Kernel
└──────────────┘
```

| 维度 | VM | 容器 |
|------|-----|------|
| 隔离 | 硬件级虚拟化，强 | namespace + cgroup，共享内核 |
| 启动 | 分钟级 | 秒级 |
| 镜像大小 | GB 级 | MB～几百 MB |
| 密度 | 低 | 高 |
| 安全边界 | 更强（独立内核） | 内核漏洞影响面大，需加固 |

**面试答法**：容器不是微型 VM，是 **受隔离限制的进程组**。

## 3. Linux 内核机制

### 3.1 Namespace（隔离）

| Namespace | 隔离内容 |
|-----------|----------|
| PID | 进程 ID 空间 |
| NET | 网络栈、IP、端口 |
| MNT | 挂载点 / 文件系统视图 |
| UTS | hostname |
| IPC | 信号量、消息队列 |
| USER | UID/GID 映射 |

容器内 `pid 1` 通常是 Java 或 tini，看不到宿主机其他进程。

### 3.2 Cgroup（资源限制）

- CPU quota、memory limit、IO、pid 数
- **K8s 的 requests/limits 最终落到 cgroup**
- Java 容器 OOM Kill 根因常是 **JVM 堆 > memory limit**

```bash
docker run -m 512m --cpus=1.5 myapp
```

### 3.3 Union FS 与镜像层

镜像由 **只读层** 叠加；容器启动加 **可写层**（Copy-on-Write）。

```
镜像层:  base OS → JDK → jar
容器层:  可写（日志、tmp）  ← 容器删则丢，需 volume 持久化
```

**好处**：

- 多镜像共享 base 层，省磁盘
- build 时未变层走缓存，加速 CI

## 4. Docker 架构组件

| 组件 | 作用 |
|------|------|
| **docker CLI** | 用户命令 |
| **dockerd** | 守护进程，管理镜像/容器/网络 |
| **containerd** | 容器生命周期，拉镜像 |
| **runc** | OCI 标准，真正 `fork/exec` 容器进程 |
| **Registry** | Docker Hub、Harbor、ACR 等 |

```
docker run → dockerd → containerd → runc → 容器进程
```

**与 K8s**：K8s 不直接调 dockerd（1.24+ 移除 dockershim），用 **containerd/CRI-O**。

---

## 5. 镜像与 OCI

- **OCI**（Open Container Initiative）：镜像格式与运行时标准。
- 镜像名：`registry/namespace/repo:tag`，如 `harbor.company.com/order/app:v1.2.3`。
- **digest**：`sha256:...` 不可变，生产应用 digest 追溯。

```bash
docker inspect myapp:1.0 --format='{{.Id}}'
docker history myapp:1.0    # 看每层大小
```

---

## 6. 容器生命周期

```
created → running → paused
              ↓
         stopped → removed
```

| 状态 | 说明 |
|------|------|
| running | 主进程在跑 |
| stopped | 已 stop，可 `docker start` |
| removed | `docker rm`，可写层删除 |

**主进程 = PID 1**：Docker 发 SIGTERM 给 PID 1；Java 需正确处理信号做 graceful shutdown。

## 7. .dockerignore

```
target/
.git/
*.md
.idea/
```

减少 build context，加速上传，避免把 `target/` 打进镜像。
