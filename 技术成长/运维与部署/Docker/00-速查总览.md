## 2. 镜像 vs 容器

| | 镜像 Image | 容器 Container |
|---|-----------|----------------|
| 类比 | 类 / 安装包 | 实例 / 进程 |
| 可写层 | 只读层叠加 | 顶层可写层（Copy-on-Write） |
| 生命周期 | 持久 | 启停删 |

---

## 3. 常用命令

```bash
# 镜像
docker build -t myapp:1.0 .
docker images
docker pull / push

# 容器
docker run -d -p 8080:8080 --name app myapp:1.0
docker ps -a
docker logs -f app
docker exec -it app bash
docker stop app && docker rm app

# 清理
docker system prune -a    # 慎用，删未用镜像
```

## 4. Dockerfile 骨架（Java 多阶段）

```dockerfile
FROM eclipse-temurin:21-jdk-alpine AS builder
WORKDIR /build
COPY pom.xml .
COPY src ./src
RUN mvn -B package -DskipTests

FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
COPY --from=builder /build/target/*.jar app.jar
USER nobody
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar"]
```

## 5. 网络模式

| 模式 | 说明 |
|------|------|
| bridge | 默认，自定义网络 DNS 解析服务名 |
| host | 共用宿主机网络，无端口映射 |
| none | 无网络 |
| overlay | Swarm/K8s CNI 跨主机 |

## 6. 数据卷

```bash
docker volume create mysql_data
docker run -v mysql_data:/var/lib/mysql mysql:8
# 绑定挂载（开发）
docker run -v $(pwd)/logs:/app/logs myapp
```

---

## 7. docker-compose 最小示例

```yaml
services:
  app:
    build: .
    ports: ["8080:8080"]
    depends_on: [mysql, redis]
  mysql:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: secret
  redis:
    image: redis:7-alpine
```

```bash
docker compose up -d
docker compose logs -f app
docker compose down
```

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| Docker vs VM？ | 容器共享内核，秒级启动，更轻；VM 完整 OS 隔离 |
| 镜像分层？ | Union FS，每层只读，改拷贝写；利于缓存与共享 |
| ENTRYPOINT vs CMD？ | ENTRYPOINT 主命令；CMD 默认参数，可被 run 覆盖 |
| 容器数据如何持久？ | volume / bind mount |
| Java 容器 OOM？ | 未设 memory limit 或 JVM 堆大于 limit |
