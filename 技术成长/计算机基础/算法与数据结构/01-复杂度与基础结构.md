> **阅读目标**：建立复杂度分析直觉，掌握数组/链表/栈队列/哈希及双指针、滑动窗口模板。对应 Hot 100 中约 40% 题目。

## 一、算法复杂度

### 1.1 大 O 表示法

**定义**：描述输入规模 `n` 增长时，时间或空间消耗的上界趋势，忽略常数和低阶项。

| 复杂度 | 典型场景 | n=10⁶ 量级感受 |
|--------|----------|----------------|
| O(1) | 哈希查表、数组下标访问 | 瞬时 |
| O(log n) | 二分、平衡树查找 | 约 20 步 |
| O(n) | 单次遍历 | 10⁶ 次操作 |
| O(n log n) | 排序、分治 | 可接受 |
| O(n²) | 双重循环、朴素 DP | 10¹²，危险 |
| O(2^n) | 子集枚举、朴素回溯 | 仅 n≤20 左右 |
| O(n!) | 全排列 | 仅 n≤10 左右 |

**面试常问**：

- **最好/平均/最坏**：快排平均 O(n log n)，最坏 O(n²)（已有序 + 选首元素为 pivot）。
- **均摊**：`ArrayList.add` 均摊 O(1)，因扩容复制偶尔 O(n)。
- **空间复杂度**：除输入外额外空间；递归深度计入栈空间。

### 1.2 复杂度估算技巧

```
单层循环           → O(n)
嵌套循环           → O(n²) 或 O(n×m)
二分               → O(log n)
分治 T(n)=2T(n/2)+O(n) → O(n log n)（主定理）
递归树             → 层数 × 每层工作量
```

**Java 工程师注意**：线上接口若 O(n²) 且 n 为订单量/用户量，需警惕；日志聚合、批量 DB 查询要先估数据规模。

## 二、数组与字符串

### 2.1 数组特性

| 操作 | 数组 | ArrayList |
|------|------|-----------|
| 随机读 | O(1) | O(1) |
| 尾部追加 | — | 均摊 O(1) |
| 中间插入/删除 | O(n) | O(n) |

**考点**：双指针、滑动窗口、前缀和、差分数组。

### 2.2 双指针

**类型**：

| 类型 | 场景 | 例子 |
|------|------|------|
| 对撞指针 | 有序数组求和 | 两数之和 II |
| 快慢指针 | 链表环、原地删重 | 141、26 |
| 同向双指针 | 滑动窗口、子数组 | 无重复字符最长子串 |

**模板：对撞指针**

```java
int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) { /* 记录答案 */ left++; right--; }
    else if (sum < target) left++;
    else right--;
}
```

**模板：滑动窗口（可变窗口）**

```java
Map<Character, Integer> cnt = new HashMap<>();
int left = 0, ans = 0;
for (int right = 0; right < s.length(); right++) {
    char c = s.charAt(right);
    cnt.merge(c, 1, Integer::sum);
    while (/* 窗口不合法 */) {
        char d = s.charAt(left++);
        cnt.merge(d, -1, Integer::sum);
        if (cnt.get(d) == 0) cnt.remove(d);
    }
    ans = Math.max(ans, right - left + 1);
}
```

### 2.3 前缀和与差分

**前缀和**：`pre[i] = sum(nums[0..i-1])`，区间和 O(1)。

**差分**：区间 `[l,r]` 全体 +v → `diff[l]+=v`, `diff[r+1]-=v`，适合多次区间修改。

**Java**：大数据量区间统计可用前缀和；定时任务批量改库存可用差分思想。

## 三、链表

### 3.1 结构对比

| | 数组 | 单向链表 | 双向链表 |
|--|------|----------|----------|
| 内存 | 连续 | 离散 | 离散 |
| 随机访问 | O(1) | O(n) | O(n) |
| 头插/删 | O(n) | O(1) | O(1) |
| 缓存友好 | 好 | 差 | 差 |

**Java**：`LinkedList` 实现 `Deque`，面试手写链表题用自定义 `ListNode`。

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}
```

### 3.2 核心技巧

| 技巧 | 用途 |
|------|------|
| 虚拟头节点 dummy | 简化头删/合并 |
| 快慢指针 | 找中点、判环、找环入口 |
| 反转 | 迭代三指针或递归 |
| 合并 | 归并排序链表 |

**反转链表（迭代）**

```java
ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
```

**环检测**：快指针走 2 步、慢 1 步，相遇则有环。入口：相遇后一指针回 head，同步走，再遇即入口（数学证明：距离关系）。

### 3.3 高频题

| 题 | 标签 | 要点 |
|----|------|------|
| 206 反转链表 | 链表 | 迭代/递归 |
| 141 环形链表 | 快慢 | Floyd |
| 142 环形入口 | 快慢 | 二次相遇 |
| 21 合并两个有序链表 | 归并 | dummy |

## 四、栈与队列

### 4.1 栈（LIFO）

**应用**：括号匹配、单调栈、DFS 迭代、表达式求值、函数调用栈。

**单调栈**：维护单调递增/递减栈，求「下一个更大元素」「柱状图最大矩形」。

```java
// 下一个更大元素 I：nums[i] 右侧第一个更大
Deque<Integer> stack = new ArrayDeque<>();
int[] ans = new int[n];
Arrays.fill(ans, -1);
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
        ans[stack.pop()] = nums[i];
    }
    stack.push(i);
}
```

### 4.2 队列（FIFO）

**应用**：BFS 层序、滑动窗口最大值（单调队列）。

**Java API**：

```java
Deque<Integer> queue = new ArrayDeque<>(); // 作 Queue
queue.offer(x);
queue.poll();

Deque<Integer> stack = new ArrayDeque<>(); // 作 Stack
stack.push(x);
stack.pop();
```

**勿用** `java.util.Stack`（继承 Vector，性能差且非接口规范）。

### 4.3 单调队列（滑动窗口最大值）

维护 deque 存**下标**，队头为当前窗口最大值下标；入队时从队尾弹出较小元素。

复杂度：每个元素最多入队出队一次 → O(n)。

## 五、哈希表

### 5.1 原理与复杂度

**平均** O(1) 增删查；**最坏** O(n)（哈希冲突极端）。Java `HashMap` 链表 + 红黑树（树化阈值 8）。

| 结构 | 有序 | 线程安全 | 场景 |
|------|------|----------|------|
| HashMap | 否 | 否 | 通用 |
| LinkedHashMap | 插入/访问序 | 否 | LRU |
| TreeMap | 键有序 | 否 | 范围查询 |
| ConcurrentHashMap | 否 | 是 | 并发 |

### 5.2 典型用法

| 模式 | 例子 |
|------|------|
| 频次统计 | 字母异位词、TopK 前奏 |
| 补数/差值 | 两数之和 `target - x` |
| 去重 | 最长连续序列 |
| 分组 | 按排序后字符串分组 |

**两数之和**

```java
Map<Integer, Integer> map = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    if (map.containsKey(target - nums[i])) {
        return new int[]{map.get(target - nums[i]), i};
    }
    map.put(nums[i], i);
}
```

### 5.3 与 Java HashMap 面试联动

- **hashCode/equals**：键相等必须 hash 相等；重写 equals 必重写 hashCode。
- **扩容**：负载因子 0.75，2 倍扩容 rehash。
- **线程安全**：`Collections.synchronizedMap` 或 `ConcurrentHashMap`（分段/CAS+synchronized）。

## 六、排序算法速览

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|------|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | 是 | 教学用 |
| 选择 | O(n²) | O(n²) | O(1) | 否 | |
| 插入 | O(n²) | O(n²) | O(1) | 是 | 近乎有序时优 |
| 快排 | O(n log n) | O(n²) | O(log n) 栈 | 否 | 工程常用 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 | 链表排序 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 | TopK 基础 |

**快排 partition 要点**：选 pivot，双指针交换，递归左右。工程优化：三数取中、小数组 insertion sort、尾递归优化。

**Java**：`Arrays.sort` 基本类型 Dual-Pivot Quicksort；对象 TimSort（归并+插入，稳定）。

## 七、二分查找

### 7.1 标准模板（左闭右闭）

```java
int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2; // 防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

### 7.2 变体

| 变体 | 边界处理 |
|------|----------|
| 左边界 first >= target | `right = mid` 或 `right = mid - 1` 分支 |
| 右边界 last <= target | `left = mid + 1` |
| 旋转数组 | 判哪半有序 |
| 二分答案 | 答案单调，check(mid) 可行 |

**误区**：`mid = (left + right) / 2` 在极大下标可能溢出；循环条件 `left <= right` vs `<` 与区间定义一致。

## 十、面试高频问答

| 问 | 答要点 |
|----|--------|
| ArrayList 和 LinkedList？ | 数组随机读快、尾插均摊 O(1)；链表头尾 O(1) 但无随机读。Java 中 ArrayList 更常用。 |
| HashMap 原理？ | 数组+链表+红黑树；hash 扰动；扩容 rehash；线程不安全。 |
| 如何判断算法能否过？ | 1e5 一般 O(n log n)；1e6 O(n) 或 O(n log n) 常数小；O(n²) 仅 n≤3000 左右。 |
| 稳定排序意义？ | 相等元素相对顺序不变；多关键字排序、对象排序需要稳定。 |
| 双指针和滑动窗口区别？ | 双指针泛指两下标；滑动窗口常指维护区间 [left,right] 满足某性质。 |
