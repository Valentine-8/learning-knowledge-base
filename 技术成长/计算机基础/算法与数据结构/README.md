## 学习顺序

```
01 基础结构（双指针、哈希）→ 02 树堆 → 03 图搜索
         ↓
04 DP/贪心（最难，需前置递归思维）
         ↓
05 按题型刷题 + 错题本
```

**不要随机刷题**：每题打标签（如 `#双指针 #单调栈`），同一标签连续刷 5–10 题再换。

## Java 对照

| 算法结构 | Java API |
|----------|----------|
| 栈 | `Deque` / `ArrayDeque`（勿用 legacy `Stack`） |
| 队列 | `ArrayDeque` / `PriorityQueue` |
| 堆 | `PriorityQueue`，Comparator 控制大小顶 |
| 哈希 | `HashMap` / `LinkedHashMap`（LRU）/ `TreeMap` |
| 并查集 | 手写 `parent[]` + 路径压缩 |
| 图 | 邻接表 `Map<Integer, List<Integer>>` |
