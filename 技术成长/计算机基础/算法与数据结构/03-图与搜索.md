## 一、图的基础

### 1.1 概念

| 术语 | 说明 |
|------|------|
| 有向/无向 | 边是否有方向 |
| 带权 | 边有权重 |
| 度 | 无向：邻边数；有向：入度/出度 |
| 连通 | 任意两点有路径 |
| 强连通 | 有向图双向可达 |

### 1.2 存储

| 结构 | 空间 | 查邻边 | 适用 |
|------|------|--------|------|
| 邻接矩阵 | O(V²) | O(1) | 稠密图、V 小 |
| 邻接表 | O(V+E) | O(度) | **稀疏图、面试默认** |

```java
// 邻接表：点编号 0..n-1
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
// 加边 u -> v
graph.get(u).add(v);
```

**带权图**：`List<int[]>` 存 `{v, weight}` 或 `Map<Integer, List<Pair>>`。

## 二、DFS 深度优先搜索

### 2.1 模板

```java
void dfs(int u, List<List<Integer>> g, boolean[] vis) {
    vis[u] = true;
    for (int v : g.get(u)) {
        if (!vis[v]) dfs(v, g, vis);
    }
}
```

**应用**：连通分量、路径存在、环检测、回溯、岛屿问题。

### 2.2 网格 DFS

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

void dfsGrid(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length) return;
    if (grid[i][j] == '0') return;
    grid[i][j] = '0'; // 标记访问
    for (int[] d : dirs) dfsGrid(grid, i + d[0], j + d[1]);
}
```

**200 岛屿数量**：遍历网格，遇 '1' 则 count++ 并 DFS 沉岛。

### 2.3 回溯 vs DFS

| | 回溯 | DFS |
|--|------|-----|
| 目的 | 枚举所有解 | 遍历/连通性 |
| 特点 | 选-探-撤 | 可能只找一条路径 |
| 典型 | 全排列、子集 | 岛屿、环 |

## 三、BFS 广度优先搜索

### 3.1 模板

```java
int bfs(int start, int target, List<List<Integer>> g) {
    Queue<Integer> q = new ArrayDeque<>();
    boolean[] vis = new boolean[n];
    q.offer(start);
    vis[start] = true;
    int step = 0;
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            int u = q.poll();
            if (u == target) return step;
            for (int v : g.get(u)) {
                if (!vis[v]) {
                    vis[v] = true;
                    q.offer(v);
                }
            }
        }
        step++;
    }
    return -1;
}
```

### 3.2 性质

- **无权图**最短路（边权均为 1）
- 层序扩展，适合「最少步数」「最少转换」
- 空间 O(V)，时间 O(V+E)

### 3.3 经典题

| 题 | 要点 |
|----|------|
| 127 单词接龙 | BFS + 通配符建图或枚举变字符 |
| 752 打开转盘锁 | 状态 BFS |
| 1091 二进制矩阵最短路 | 8 方向 BFS |
| 994 腐烂橘子 | 多源 BFS |

**多源 BFS**：初始把所有源入队，再统一扩展（腐烂橘子）。

## 四、拓扑排序

### 4.1 概念

**有向无环图 DAG** 上节点线性排序，使所有边 u→v 中 u 在 v 前。

**应用**：课程依赖、任务调度、编译顺序、Maven 依赖解析。

### 4.2 Kahn 算法（BFS 入度）

```java
List<Integer> topologicalSort(int n, int[][] edges) {
    int[] indegree = new int[n];
    List<List<Integer>> g = new ArrayList<>();
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] e : edges) {
        g.get(e[0]).add(e[1]);
        indegree[e[1]]++;
    }
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) q.offer(i);
    List<Integer> order = new ArrayList<>();
    while (!q.isEmpty()) {
        int u = q.poll();
        order.add(u);
        for (int v : g.get(u)) {
            if (--indegree[v] == 0) q.offer(v);
        }
    }
    return order.size() == n ? order : Collections.emptyList(); // 空表示有环
}
```

### 4.3 DFS 拓扑

后序栈：DFS 完 push，逆序即拓扑。判环：三色标记（白灰黑），遇灰节点有环。

**207 课程表**：能否完成 = 无环。 **210 课程表 II**：输出顺序。

## 五、并查集（Union-Find）

### 5.1 操作

- **find(x)**：找根，**路径压缩**
- **union(x,y)**：按 **秩/大小** 合并

```java
class UnionFind {
    int[] parent, size;

    UnionFind(int n) {
        parent = new int[n];
        size = new int[n];
        Arrays.fill(size, 1);
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;
        size[ra] += size[rb];
        return true;
    }
}
```

**均摊** O(α(n)) ≈ O(1)。

### 5.2 应用

| 场景 | 题 |
|------|-----|
| 连通分量 | 547 省份数量 |
| 判环（无向） | 冗余连接 |
| Kruskal 最小生成树 | 按边权 union |
| 动态连通 | 684 |

**128 最长连续序列**：数值域并查或 HashSet O(n)。

## 六、最短路径

### 6.1 算法选型

| 算法 | 复杂度 | 条件 |
|------|--------|------|
| BFS | O(V+E) | 无权 |
| Dijkstra | O(E log V) 堆 | **非负权** |
| Bellman-Ford | O(VE) | 可有负权，判负环 |
| Floyd | O(V³) | 全源，V 小 |

### 6.2 Dijkstra（堆优化）

```java
int[] dijkstra(int n, List<List<int[]>> g, int src) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
    pq.offer(new int[]{src, 0});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], d = cur[1];
        if (d > dist[u]) continue; // 过期条目
        for (int[] e : g.get(u)) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
```

**不能有负权边**；负权用 Bellman-Ford。

**743 网络延迟时间**：单源最短路到各点最大值。

### 6.3 0-1 BFS

边权仅 0/1 时，Deque 替代 PQ：权 0 放队头，权 1 放队尾。

## 十四、Floyd 与传递闭包

**Floyd-Warshall** O(V³)：全源最短路，允许负权无负环。

```java
for (int k = 0; k < n; k++)
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
      dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
```
