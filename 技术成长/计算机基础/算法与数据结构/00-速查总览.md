## 一、复杂度

| notation | 含义 |
|----------|------|
| O(1) O(log n) O(n) O(n log n) | 常数、对数、线性、线性对数 |
| O(n²) O(2^n) | 平方、指数（需优化） |

**空间复杂度**：辅助数组、递归栈深。

---

## 二、数据结构要点

| 结构 | 操作复杂度 | 考点 |
|------|------------|------|
| 数组 | 随机读 O(1)，插删 O(n) | 双指针、滑动窗口 |
| 链表 | 插删 O(1)，找 O(n) | 反转、环检测、合并 |
| 栈/队列 | push/pop O(1) | 单调栈、BFS |
| 哈希表 | 均摊 O(1) | 两数之和、频次 |
| 二叉树 | 遍历 O(n) | 前中后序、层序、BST |
| 堆 | 插删 O(log n) | **TopK**、优先队列 |
| 图 | BFS/DFS O(V+E) | 最短路径、拓扑 |

**红黑树**：Java TreeMap/HashMap 树化；平衡二叉搜索树，增删查 O(log n)。

## 三、算法模板

### 二分

```text
左闭右闭 while left<=right；mid 防溢出 left+(right-left)/2
```

### 滑动窗口

```text
右扩、不满足则左缩，维护窗口状态
```

### BFS / DFS

```text
BFS 最短步数（无权图）；DFS 回溯、连通分量
```

### 动态规划

```text
1. 状态定义 dp[i] 含义
2. 转移方程
3. 初始条件
4. 顺序（背包：物品在外层或容量在外层）
```

**经典**：背包、LCS、编辑距离、股票、爬楼梯、打家劫舍。

### 贪心

证明局部最优 → 全局最优（区间、跳跃游戏）。

## 六、面试速答

| 问 | 答 |
|----|-----|
| 快排复杂度？ | 平均 O(n log n)，最坏 O(n²)；不稳定 |
| 堆和优先队列？ | 数组实现完全二叉树，TopK 用大小顶堆 |
| HashMap 和 TreeMap？ | 哈希 O(1) 无序；红黑树 O(log n) 有序 |
