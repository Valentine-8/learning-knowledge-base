> **建议用时**：通读 90 min + 手写爬楼梯、打家劫舍、01 背包、最长递增子序列。

## 一、动态规划本质

### 1.1 适用条件

1. **最优子结构**：大问题的最优解包含子问题最优解
2. **重叠子问题**：递归会重复计算，需记忆化或表格
3. **无后效性**：当前状态概括历史，未来只依赖状态

**与分治**：分治子问题独立（归并）；DP 子问题重叠（斐波那契）。

**与贪心**：贪心每步局部最优且不需回溯；DP 常需比较多种子决策。

### 1.2 解题四步

```
1. 状态定义：dp[i] 或 dp[i][j] 含义
2. 转移方程：如何从子状态得到当前
3. 初始条件：base case
4. 计算顺序：保证依赖已算（背包内外层循环方向）
```

**实现形态**：自顶向下记忆化 / 自底向上填表 / 空间优化滚动数组。

## 二、一维线性 DP

### 2.1 斐波那契 / 爬楼梯（70）

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

`dp[i] = dp[i-1] + dp[i-2]`，空间可 O(1)。

### 2.2 打家劫舍（198 / 213）

```java
int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int x : nums) {
        int cur = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

**213 环形**：拆成 [0,n-2] 与 [1,n-1] 两次线性。

### 2.3 最长递增子序列 LIS（300）

**O(n²)**：`dp[i]` = 以 i 结尾的 LIS 长度。

**O(n log n)**：维护 tails 数组，tails[k] 为长度 k+1 的 LIS 最小末尾；二分找插入位置。

```java
int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int x : nums) {
        int lo = 0, hi = size;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;
        if (lo == size) size++;
    }
    return size;
}
```

### 2.4 最大子数组和（53）

`dp[i] = max(nums[i], dp[i-1] + nums[i])`，即 Kadane。

## 三、二维 DP

### 3.1  unique paths（62）

```java
int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] += dp[j - 1];
        }
    }
    return dp[n - 1];
}
```

### 3.2 最小路径和（64）

`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。

### 3.3 最长公共子序列 LCS（1143）

```java
int longestCommonSubsequence(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (a.charAt(i - 1) == b.charAt(j - 1))
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}
```

**编辑距离（72）**：增删改三操作，`dp[i][j]` 为 a[0..i) 到 b[0..j) 最少步数。

## 四、背包问题

### 4.1 0-1 背包

n 物品，容量 W，每件最多选一次， maximize sum value。

```java
int knapsack01(int[] w, int[] v, int W) {
    int n = w.length;
    int[] dp = new int[W + 1];
    for (int i = 0; i < n; i++) {
        for (int c = W; c >= w[i]; c--) { // 逆序保证 0-1
            dp[c] = Math.max(dp[c], dp[c - w[i]] + v[i]);
        }
    }
    return dp[W];
}
```

**416 分割等和子集**：能否凑满 sum/2。

### 4.2 完全背包

每件无限次 → 内层容量 **正序** `for (c = w[i]; c <= W; c++)`。

**322 零钱兑换**：最少硬币数，完全背包求 min。

**518 零钱兑换 II**：组合数，物品在外层避免重复排列。

### 4.3 多重背包

物品 i 有 count[i] 件 → 二进制拆分或单调队列优化（面试少见）。

### 4.4 内外层循环

| 目标 | 典型循环 |
|------|----------|
| 组合（顺序无关） | 物品在外，容量在内 |
| 排列（顺序有关） | 容量在外，物品在内 |

## 五、区间 DP

**枚举区间长度**，再枚举左端点。

**516 最长回文子序列**：

```java
int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = n - 1; i >= 0; i--) {
        dp[i][i] = 1;
        for (int j = i + 1; j < n; j++) {
            if (s.charAt(i) == s.charAt(j))
                dp[i][j] = dp[i + 1][j - 1] + 2;
            else
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
        }
    }
    return dp[0][n - 1];
}
```

**312 戳气球**：`dp[i][j]` 开区间 (i,j) 内戳气球最大得分。

**1039 多边形三角剖分**：类似区间合并代价。

## 六、状态机 DP

### 6.1 股票系列（121/122/123/188/309）

**121 一次交易**：

```java
int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, maxProfit = 0;
    for (int p : prices) {
        minPrice = Math.min(minPrice, p);
        maxProfit = Math.max(maxProfit, p - minPrice);
    }
    return maxProfit;
}
```

**122 无限次**：贪心 valley-peak 或 `dp[i][0/1]` 持有/不持有。

**123 两次**：`buy1, sell1, buy2, sell2` 四变量滚动。

## 八、贪心算法

### 8.1 适用

局部最优 → 全局最优，需 **证明**（交换论证、反证、归纳）。

### 8.2 经典

| 题 | 贪心策略 |
|----|----------|
| 55 跳跃游戏 | 维护最远可达 |
| 45 跳跃游戏 II | 当前层最远 + 下一层边界 |
| 435 无重叠区间 | 按 end 排序，选 end 最小 |
| 452 用最少数箭 | 同上区间贪心 |
| 763 划分字母区间 | 记录最后出现，扩展右边界 |
| 406 根据身高重建队列 | 先按 h 降序 k 升序，再按 k 插入 |

### 8.3 与 DP 对比

**322 零钱**：贪心错（面额 [1,3,4] 凑 6）；DP 正确。

**面试**：说清为何贪心成立，或举反例说明不成立需 DP。

## 九、记忆化搜索

```java
Map<String, Integer> memo = new HashMap<>();

int dfs(String s) {
    if (memo.containsKey(s)) return memo.get(s);
    // base + 递归
    memo.put(s, ans);
    return ans;
}
```

**139 单词拆分**：`dfs(i)` 能否拆分 s[i..]。

**329 矩阵最长递增路径**：记忆化 DFS + 四方向。

## 十、DP 调试清单

- 状态含义是否清晰、是否漏维度
- 初始化是否正确（空串、0 容量）
- 循环方向（0-1 背包逆序）
- 返回值是 `dp[n]` 还是 `max/min over dp`
- 空间能否滚动优化

## 十四、打表法与空间优化

**打表**：预处理小范围答案数组，查询 O(1)。

**滚动数组**：二维 DP 仅依赖上一行 → 一维数组滚动。

```java
// 0-1 背包空间优化
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++)
  for (int w = W; w >= weight[i]; w--)
    dp[w] = Math.max(dp[w], dp[w - weight[i]] + value[i]);
```

## 十六、贪心证明方法

1. **交换论证**：任意最优解可通过交换变为贪心解
2. **归纳法**：前 k 步最优 → 第 k+1 步贪心仍最优
3. **反证法**：假设贪心非最优，构造更优矛盾

**435 无重叠区间**：按 end 升序，选 end 最小 → 留最多空间。

## 十九、小结

```
DP：定义状态 → 转移 → 初值 → 顺序
模型：线性、背包、区间、状态机、树形
背包：0-1 逆序、完全正序、组合/排列看内外层
贪心：证明局部最优；不行上 DP
```
