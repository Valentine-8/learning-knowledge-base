> 对应技能清单 §九 安全 + §四 Spring Security。LLM 安全见 [AI工程/09-LLM安全](../../AI工程/09-LLM安全与合规.md)。

## 一、常见 Web 攻击

| 攻击 | 原理 | 防护 |
|------|------|------|
| **SQL 注入** | 拼接 SQL | 预编译 `#{}`、ORM、最小权限 DB 账号 |
| **XSS** | 注入脚本到页面 | 输出转义、CSP、HttpOnly Cookie |
| **CSRF** | 盗用登录态发请求 | Token、SameSite Cookie、Referer 校验 |
| **SSRF** | 服务端请求内网 | URL 白名单、禁止内网 IP |
| 文件上传 | 木马、路径穿越 | 类型校验、随机文件名、存对象存储 |
| 越权 | 改 ID 访问他人数据 | 服务端校验归属、RBAC |

---

## 二、认证与授权

| 概念 | 说明 |
|------|------|
| 认证 Authentication | 你是谁：登录、JWT、OAuth |
| 授权 Authorization | 你能做什么：RBAC、ABAC |
| Session | 服务端存状态，Cookie 带 SessionId |
| **JWT** | Header.Payload.Signature，无状态，注意过期与密钥 |
| **OAuth2** | 授权码模式、客户端模式；OIDC = OAuth2 + 身份 |
| SSO | 单点登录，CAS、OAuth 联邦 |

### Spring Security 链

```
Filter Chain → 认证（UserDetailsService）→ 授权（角色/权限）→ 资源访问
```

**JWT 实践**：access token 短过期 + refresh token；敏感操作再验证。

## 三、加密

| 类型 | 用途 | 例子 |
|------|------|------|
| 对称 | 大量数据加密 | AES |
| 非对称 | 密钥交换、签名 | RSA、ECC |
| 哈希 | 完整性、密码存储 | SHA-256、**BCrypt** 存密码 |
| 签名 | 防篡改 | HMAC、RSA 签名 |

**密码存储**：绝不明文；BCrypt/Argon2 + 盐。

**传输**：HTTPS（TLS）。

## 四、API 安全

- 接口鉴权、签名（timestamp + nonce 防重放）
- 限流防刷
- 敏感字段脱敏日志
- 依赖漏洞扫描（OWASP Dependency-Check）

## 五、面试速答

| 问 | 答 |
|----|-----|
| SQL 注入防？ | 预编译参数化，禁止拼接 |
| XSS 和 CSRF 区别？ | XSS 偷用户浏览器执行脚本；CSRF 借用户 Cookie 发恶意请求 |
| JWT 优缺点？ | 无状态易扩展；难主动失效、payload 不存敏感、要防泄露 |
| Session 和 JWT？ | Session 服务端状态，易注销；JWT 客户端带 token，适合分布式 |
