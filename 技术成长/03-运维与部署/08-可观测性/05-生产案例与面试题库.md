## 1. 生产故障案例

### 案例 1：告警风暴掩盖真实故障

| 项 | 内容 |
|----|------|
| 现象 | 200 条告警，On-Call 麻木，真实 P0 被淹没 |
| 根因 | 每个 Pod 重启都告警；无 grouping |
| 修复 | Alertmanager group_by；Pod 级改 Deployment 级 |
| 预防 | 告警 review 季度清理 |

### 案例 2：无 traceId 无法定位

| 项 | 内容 |
|----|------|
| 现象 | 用户投诉订单失败，日志搜不到 |
| 根因 | 日志无 traceId，网关未透传 |
| 修复 | SkyWalking Agent + Logback MDC |
| 预防 | 日志规范门禁 |

### 案例 3：Prometheus Cardinality 爆炸

| 项 | 内容 |
|----|------|
| 现象 | Prometheus OOM，查询超时 |
| 根因 | 自定义 metric 带 userId 标签 |
| 修复 | 去掉高基数标签；recording rules |
| 预防 | 标签规范：禁止 userId/orderId |

### 案例 4：ES 磁盘满集群红

| 项 | 内容 |
|----|------|
| 现象 | Kibana 不可用，日志丢失 |
| 根因 | 未配 ILM，90 天索引未删 |
| 修复 | ILM 热 7 天温 30 天冷 90 删；扩容 |
| 预防 | 磁盘告警 + 索引生命周期 |

## 3. 场景题

**Q：下单接口 P99 从 200ms 升到 2s，如何排查？**

1. Grafana：P99、QPS、错误率、饱和度
2. Trace：慢 Trace 样本，看哪段 Span 长
3. Logs：该时段 ERROR/WARN
4. Metrics：DB 连接池、Redis、下游 RT
5. 变更：最近 deploy、配置、流量突增
6. 缓解：扩容、降级、回滚
