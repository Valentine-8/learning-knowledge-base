# 云平台 · 速查总览

> 10 分钟复习。深入见 [01～04 章](./README.md)。

---

## 1. 云三层模型

| 层 | 含义 | 你管什么 | 例如 |
|----|------|----------|------|
| IaaS | 基础设施 | OS 以上 | ECS、EC2 |
| PaaS | 平台 | 应用代码 | K8s、RDS、SAE |
| SaaS | 软件 | 配置使用 | 钉钉、Salesforce |

**Java 后端常见**：IaaS（ECS + 自建 K8s）或 托管 K8s（ACK/EKS）。

---

## 2. 阿里云 vs AWS 速对照

| 能力 | 阿里云 | AWS |
|------|--------|-----|
| 虚拟机 | ECS | EC2 |
| 对象存储 | OSS | S3 |
| 关系数据库 | RDS MySQL | RDS |
| 缓存 | Tair/Redis | ElastiCache |
| 负载均衡 | SLB/ALB | ELB/ALB |
| CDN | CDN | CloudFront |
| 容器 | ACK | EKS |
| 消息 | RocketMQ | SQS/SNS/MSK |
| 注册配置 | MSE/Nacos | 自建/Cloud Map |
| 监控 | ARMS/云监控 | CloudWatch |
| VPC | VPC | VPC |
| IAM | RAM | IAM |

## 3. 典型 Java 上云架构

```
用户 → CDN → WAF → SLB/ALB
                    │
            ┌───────┴───────┐
            ▼               ▼
        ACK/EKS         ACK/EKS
     (order-service)  (payment-service)
            │               │
            ├── RDS MySQL ──┤
            ├── Redis ──────┤
            ├── OSS/S3 ─────┘
            └── MQ
```

## 4. 共享责任模型

| 云厂商负责 | 你负责 |
|-----------|--------|
| 物理机、网络、虚拟化 | OS 补丁、应用、数据 |
| 托管服务底层 | 配置、访问控制、加密 |
| 可用区基础设施 | 备份策略、合规 |

---

## 5. 成本优化速查

| 手段 | 说明 |
|------|------|
| 预留/包年 | 稳态 workload 省 30～50% |
| Spot/抢占式 | 可中断任务 |
| 右-sizing | 监控 CPU 均值，降配 |
| 对象存储生命周期 | 冷数据转归档 |
| 自动伸缩 | HPA + 定时伸缩 |

## 6. 面试 5 分钟

| 问 | 答 |
|----|-----|
| IaaS PaaS SaaS？ | 基础设施/平台/软件即服务 |
| 公有云私有云混合云？ | 混合=公有+私有+专线 |
| 为何多 AZ？ | 容灾，单 AZ 故障不影响 |
| OSS 和 EBS 区别？ | 对象 vs 块存储 |
| RAM/IAM 作用？ | 身份与权限最小化 |
