# 01 · 云计算 IaaS-PaaS-SaaS

> **预计阅读**：50 min · **难度**：★★★

---

## 1. 云计算定义

通过网络按需提供可伸缩的 IT 资源，**按需付费**、**弹性伸缩**、**自助服务**。

| 特征 | 说明 |
|------|------|
| 弹性 | 分钟级扩缩 |
| 计量 | 用多少付多少 |
| 池化 | 多租户共享物理资源 |
| 广泛访问 | API/控制台 |

---

## 2. 三种服务模型

### IaaS（Infrastructure as a Service）

提供：虚拟机、网络、块存储。

```
你管理：OS、Runtime、App、Data
云管理：虚拟化、物理机、网络
```

示例：阿里云 ECS、AWS EC2、裸金属。

**Java 团队**：ECS 上装 Docker/K8s，完全自控。

### PaaS（Platform as a Service）

提供：运行时、中间件、数据库托管。

```
你管理：App、Data
云管理：OS 以下 + 中间件
```

示例：Heroku、阿里云 SAE、RDS、托管 Redis。

**Java 团队**：RDS MySQL + ACK，少运维 OS。

### SaaS（Software as a Service）

提供：完整应用。

```
你管理：配置、数据（部分）
云管理：全部软件栈
```

示例：Office 365、Salesforce、钉钉。

---

## 3. 四种部署模型

| 模型 | 说明 |
|------|------|
| 公有云 | 阿里云、AWS、Azure |
| 私有云 | 企业自建 OpenStack |
| 混合云 | 公有 + 私有 + 专线 |
| 多云 | 避免厂商锁定，跨 AWS+阿里云 |

---

## 4. 共享责任模型

```
         SaaS     PaaS     IaaS     本地
客户     数据     数据     数据     全部
         配置     应用     应用
                  OS       OS
                           网络
                           物理
云厂商   全部     平台     虚拟化
                  以下     以下
```

**安全**：云厂商保底层，**你保账号密钥、安全组、应用漏洞**。

---

## 5. 核心概念

| 概念 | 说明 |
|------|------|
| Region | 地域，如华东1、us-east-1 |
| AZ | 可用区，同 Region 内独立机房 |
| VPC | 虚拟私有网络，逻辑隔离 |
| Subnet | VPC 内子网，分公网/私网 |
| Security Group | 虚拟防火墙 |
| EIP | 弹性公网 IP |
| NAT Gateway | 私网出公网 |

**高可用**：跨 AZ 部署，单 AZ 故障服务继续。

---

## 6. 虚拟化基础

| 技术 | 说明 |
|------|------|
| 虚拟机 | Hypervisor 隔离，KVM/Xen |
| 容器 | 共享内核，Docker |
| 裸金属 | 无虚拟化，高性能 |

云主机 = 虚拟机 + 云 API 管理 + 弹性网络存储。

---

## 7. Java 上云路径

| 阶段 | 做法 |
|------|------|
| 1. .lift | ECS 原样迁移，改 IP 为 RDS |
| 2. 改造 | 对象存储替本地文件、MQ 云服务 |
| 3. 容器化 | Docker + K8s（ACK/EKS） |
| 4. 云原生 | Serverless、Service Mesh、托管中间件 |

---

## 8. 选型考量

| 因素 | 问题 |
|------|------|
| 合规 | 数据是否必须境内 |
| 延迟 | 用户地域 |
| 生态 | 团队熟悉阿里云还是 AWS |
| 成本 | TCO 对比 |
| 技能 | 有无 K8s 运维能力 |

国内业务 → 阿里云/腾讯云为主；出海 → AWS/GCP。

---

## 9. 小结

| 要点 | 一句话 |
|------|--------|
| IaaS | 管到 OS，弹性 VM |
| PaaS | 管到运行时，RDS/K8s |
| SaaS | 开箱即用应用 |
| 共享责任 | 安全是共同责任 |
