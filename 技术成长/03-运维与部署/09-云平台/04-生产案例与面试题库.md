## 1. 生产案例

### 案例 1：安全组配错导致服务不通

| 项 | 内容 |
|----|------|
| 现象 | ECS 上 Java 8080 本地 curl OK，SLB 健康检查失败 |
| 根因 | 安全组只允许 22，未放行 SLB 网段 8080 |
| 修复 | 安全组入站：SLB 健康检查 IP 段 → 8080 |
| 预防 | IaC 模板；上线 checklist |

### 案例 2：RDS 只读实例延迟

| 项 | 内容 |
|----|------|
| 现象 | 读从库脏读，用户看到旧订单状态 |
| 根因 | 写后立即读从库，复制延迟 2s |
| 修复 | 写后读走主库；或延迟容忍 + 提示 |
| 预防 | 读写分离框架配置「写后读主」 |

### 案例 3：OSS AccessKey 泄露

| 项 | 内容 |
|----|------|
| 现象 | 账单暴增，Bucket 被挖矿程序写满 |
| 根因 | AK 提交到 GitHub |
| 修复 | 轮换 AK；RAM 角色；Bucket 策略 |
| 预防 | git-secrets 扫描；RAM Role 替代 AK |

### 案例 4：单 AZ 部署机房故障

| 项 | 内容 |
|----|------|
| 现象 | 整站不可用 2 小时 |
| 根因 | ACK、RDS 均在同一 AZ |
| 修复 | 跨 AZ 部署；RDS 多 AZ |
| 预防 | 架构 review 多 AZ 强制 |
