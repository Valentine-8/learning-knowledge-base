## 1. Bash 基础

Bash（Bourne Again Shell）是 Linux 默认 Shell，也是脚本语言。

```bash
#!/bin/bash
# 注释
echo "Hello"
```

| 执行方式 | 说明 |
|----------|------|
| `./script.sh` | 子 shell，需可执行权限 |
| `bash script.sh` | 显式指定解释器 |
| `source script.sh` | 当前 shell，变量保留 |

## 2. 变量深入

```bash
# 赋值无空格
count=0
((count++))

# 命令替换
now=$(date +%Y%m%d)
files=$(ls *.log)

# 默认值
name=${USER:-guest}       # 未设置则 guest
path=${DATA_DIR:?must set} # 未设置则报错

# 只读
readonly CONFIG=/etc/app.conf
```

**引号规则**：

| 引号 | 行为 |
|------|------|
| 双引号 | 变量展开、命令替换 |
| 单引号 | 字面量，不展开 |
| `$'...'` | 转义序列 \n \t |

## 3. 算术与字符串

```bash
# 整数
(( a = 3 + 5 ))
(( a++ ))
let "b = a * 2"

# expr（旧）
expr 1 + 2

# 字符串
file="app.log"
echo ${file%.log}      # 去后缀 → app
echo ${file/app/api}   # 替换
```

## 4. 测试与分支

```bash
# 文件测试
[[ -e path ]]    # 存在
[[ -f path ]]    # 普通文件
[[ -d path ]]    # 目录
[[ -r path ]]    # 可读
[[ -x path ]]    # 可执行
[[ -s path ]]    # 非空

# 整数
[[ $a -eq $b ]]  # 等于
[[ $a -ne $b ]]  # 不等
[[ $a -lt $b ]]  # 小于
[[ $a -ge $b ]]  # 大于等于

# 字符串
[[ -z "$s" ]]    # 空串
[[ "$s1" == "$s2" ]]
[[ "$s1" != "$s2" ]]
```

## 5. 循环

```bash
# for
for env in dev test prod; do
  deploy "$env"
done

for ((i=0; i<10; i++)); do
  echo $i
done

# while
while [[ $count -lt 5 ]]; do
  echo $count
  ((count++))
done

# until
until ping -c 1 host &>/dev/null; do
  sleep 2
done

# 读取文件
while IFS= read -r line; do
  process "$line"
done < input.txt
```

## 6. 管道与文本处理三剑客

### grep

```bash
grep -i error app.log
grep -E "ERROR|WARN" app.log     # 扩展正则
grep -v DEBUG app.log            # 反向
grep -A 3 -B 3 "Exception" app.log
grep -r "password" /app/config/
```

### sed

```bash
sed 's/old/new/g' file           # 替换
sed -i 's/debug/info/' config    # 原地修改
sed -n '10,20p' file             # 打印 10-20 行
sed '/^#/d' file                 # 删注释行
```

### awk

```bash
awk '{print $1, $3}' file        # 列
awk -F',' '{sum+=$2} END {print sum}' data.csv
awk '/ERROR/ {count++} END {print count}' app.log
awk '$3 > 100 {print $0}' file   # 条件
```

## 8. 退出码

| 码 | 含义 |
|----|------|
| 0 | 成功 |
| 1 | 一般错误 |
| 2 | 误用 |
| 127 | 命令未找到 |
| 130 | Ctrl+C |

```bash
command && echo ok || echo fail
if command; then ...; fi
```

## 9. 严格模式

```bash
#!/bin/bash
set -euo pipefail

# -e  命令失败即退出
# -u  未定义变量报错
# -o pipefail  管道任一失败则失败
```
