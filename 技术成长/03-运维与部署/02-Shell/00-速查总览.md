# Shell · 速查总览

> 10 分钟复习。默认 **Bash**。深入见 [01～03 章](./README.md)。

---

## 1. Shebang 与执行

```bash
#!/bin/bash
chmod +x script.sh
./script.sh
bash script.sh arg1 arg2
source script.sh    # 当前 shell 执行
```

---

## 2. 变量

```bash
name="world"
echo "$name"
echo "${name}_suffix"
readonly PI=3.14
export ENV_VAR=prod

# 特殊变量
$0    # 脚本名
$1 $2 # 位置参数
$#    # 参数个数
$@    # 所有参数（独立引号）
$*    # 所有参数（单字符串）
$?    # 上条命令退出码
$$    # 当前 PID
```

---

## 3. 字符串与数组

```bash
str="hello"
${#str}              # 长度
${str:0:3}           # 子串
arr=(a b c)
echo ${arr[0]}
echo ${arr[@]}
```

---

## 4. 条件与测试

```bash
# [ ] 或 [[ ]]（推荐 Bash）
[[ -f file ]]        # 文件存在
[[ -d dir ]]
[[ -z "$str" ]]      # 空
[[ -n "$str" ]]
[[ $a -eq $b ]]      # 整数比较
[[ "$a" == "$b" ]]   # 字符串

# 逻辑
[[ $a -gt 0 && $b -lt 10 ]]
```

## 5. 流程控制

```bash
if [[ -f /etc/redhat-release ]]; then
  echo "RHEL"
elif [[ -f /etc/debian_version ]]; then
  echo "Debian"
else
  echo "Unknown"
fi

for i in 1 2 3; do echo $i; done
for f in *.log; do gzip "$f"; done

while read line; do
  echo "$line"
done < file.txt

case "$1" in
  start)  start_service ;;
  stop)   stop_service ;;
  *)      echo "Usage: $0 {start|stop}" ;;
esac
```

## 6. 管道与重定向

```bash
cmd1 | cmd2 | cmd3
cmd > file 2>&1       # stdout+stderr 到文件
cmd >> file           # 追加
cmd 2>/dev/null       # 丢弃 stderr
cmd &> file           # Bash 4+

# 进程替换
diff <(sort a.txt) <(sort b.txt)
```

## 7. 常用命令组合

```bash
# 查 Java 进程
ps aux | grep '[j]ava'

# 统计日志 ERROR
grep -c ERROR app.log
awk '/ERROR/ {count++} END {print count}' app.log

# 批量杀进程
ps aux | grep order-service | awk '{print $2}' | xargs kill -15

# 找大文件
find /var/log -type f -size +100M -exec ls -lh {} \;
```

## 8. 安全要点

| 规则 | 说明 |
|------|------|
| 引号变量 | `"$var"` 防空格分词 |
| 禁 eval 用户输入 | 防注入 |
| set -euo pipefail | 严格模式 |
| 权限 | 脚本 755，敏感信息不放脚本 |

```bash
set -euo pipefail
IFS=$'\n\t'
```
