## 1. 生产故障案例

### 案例 1：未加引号导致删错文件

| 项 | 内容 |
|----|------|
| 现象 | `rm -rf /app/logs/*` 误删全部 |
| 根因 | `rm -rf $DIR/*`，DIR 为空时变成 `rm -rf /*` |
| 修复 | 备份恢复；`[[ -n "$DIR" ]] && rm -rf "${DIR:?}"/*` |
| 预防 | 变量加引号；set -u；危险操作用 trash |

### 案例 2：cron 环境变量缺失

| 项 | 内容 |
|----|------|
| 现象 | 手动执行脚本 OK，cron 失败 |
| 根因 | cron 环境极简，找不到 java 命令 |
| 修复 | 脚本内 `source /etc/profile` 或写绝对路径 |
| 预防 | cron 重定向日志；MAILTO 告警 |

### 案例 3：管道吞掉错误

| 项 | 内容 |
|----|------|
| 现象 | CI 脚本某步失败但整体成功 |
| 根因 | `cmd1 | cmd2`，cmd1 失败 $? 是 cmd2 的 |
| 修复 | `set -o pipefail` |
| 预防 | CI 脚本开头三件套 `-euo pipefail` |

## 3. 手写题精选

**写一段：统计 access.log 中 IP 访问次数 Top 10**

```bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
```

**写一段：检测端口直到可用**

```bash
until nc -z localhost 8080; do sleep 1; done
```

**获取脚本目录**

```bash
SCRIPT_DIR=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
```
