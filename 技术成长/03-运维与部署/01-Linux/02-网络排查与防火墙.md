# 02 · 网络排查与防火墙

> **预计阅读**：60 min · **难度**：★★★★

---

## 1. TCP/IP 基础回顾

```
应用层    HTTP / JDBC / Redis 协议
传输层    TCP（可靠）/ UDP（快）
网络层    IP
链路层    Ethernet
```

| 概念 | 说明 |
|------|------|
| 三次握手 | SYN → SYN+ACK → ACK |
| 四次挥手 | FIN/ACK 关闭 |
| TIME_WAIT | 主动关闭方等待 2MSL |
| CLOSE_WAIT | 对端关闭本地未 close，**泄漏排查重点** |

---

## 2. 网络配置查看

```bash
ip addr show              # IP 地址
ip route show             # 路由表
ip link show              # 网卡状态
cat /etc/resolv.conf      # DNS
hostname -I
```

**传统命令**（部分系统已废弃）：`ifconfig`、`route`。

## 3. 端口与连接排查

```bash
# 推荐 ss（替代 netstat）
ss -tlnp                   # TCP 监听
ss -ulnp                   # UDP 监听
ss -tan | head             # 所有 TCP 连接
ss -tan state time-wait | wc -l
ss -tan state close-wait

# 按端口查进程
ss -tlnp | grep 8080
lsof -i :8080
fuser -n tcp 8080
```

### 连接状态统计

```bash
ss -tan | awk 'NR>1 {print $1}' | sort | uniq -c | sort -rn
```

| 状态过多 | 可能原因 |
|----------|----------|
| TIME_WAIT | 短连接多，考虑连接池/复用 |
| CLOSE_WAIT | 应用未关闭 socket，代码 bug |
| ESTABLISHED 接近上限 | 连接泄漏或流量过大 |

## 4. 连通性测试

```bash
ping -c 4 host
traceroute host
mtr host                   # 持续 traceroute

# 端口测试
nc -zv mysql-host 3306
curl -v --connect-timeout 3 http://api:8080/actuator/health
telnet host 6379

# DNS
dig +short api.example.com
nslookup api.example.com
```

**Java 连接超时三板斧**：DNS 解析 → 网络路由 → 防火墙/安全组 → 目标服务监听。

## 5. 抓包分析

```bash
tcpdump -i eth0 port 8080 -nn -c 100
tcpdump -i any host 10.0.0.5 and port 3306 -w capture.pcap

# 分析用 Wireshark 打开 pcap
```

| 场景 | 用法 |
|------|------|
| HTTP 502 | 抓 Nginx → 后端 |
| 连接重置 | 看 RST 包谁发的 |
| 慢请求 | 看 TCP 重传 |

## 6. firewalld（RHEL/CentOS 7+）

```bash
systemctl status firewalld
firewall-cmd --state
firewall-cmd --list-all

# 开放端口
firewall-cmd --permanent --add-port=8080/tcp
firewall-cmd --reload

# 富规则
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="10.0.0.0/8" port port="8080" protocol="tcp" accept'
```

## 7. iptables 基础

```bash
iptables -L -n -v
iptables -A INPUT -p tcp --dport 8080 -j ACCEPT
iptables -A INPUT -j DROP
service iptables save    # CentOS 6
```

**链**：INPUT / OUTPUT / FORWARD → 表 filter / nat / mangle。

生产多用 **云安全组** + 主机防火墙双层。

---

## 8. NAT 与端口转发（了解）

```bash
# DNAT 示例（iptables nat 表）
iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080
```

Docker/K8s 网络大量依赖 iptables NAT。

---

## 9. 常见网络故障

| 现象 | 排查 |
|------|------|
| Connection refused | 目标未监听或防火墙 DROP |
| Connection timed out | 路由不通或防火墙 silent drop |
| No route to host | 路由/网段错误 |
| Too many open files | ulimit 或连接泄漏 |
| 502 Bad Gateway | 上游不可达，查 Nginx error log |

---

## 10. Java 后端网络 checklist

1. `ss -tlnp` 确认 Java 进程监听 0.0.0.0 还是 127.0.0.1
2. 安全组/防火墙放行端口
3. JDBC URL 主机名能否 DNS 解析
4. 连接池大小 vs 数据库 max_connections
5. HTTP 客户端超时：connect / read / write 分开设

---

## 11. 小结

| 要点 | 一句话 |
|------|--------|
| ss | 替代 netstat，查连接状态 |
| CLOSE_WAIT | 应用 bug，查代码 |
| TIME_WAIT | 短连接多，调 tcp_tw_reuse（谨慎） |
| 防火墙 | 云安全组 + firewalld 双层 |
