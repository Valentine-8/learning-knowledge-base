## 1. Linux 文件系统

### 目录树与 inode

```
/（根）
├── bin  sbin     基本命令
├── etc           配置
├── home          用户
├── var           可变数据（log、cache）
├── usr           用户程序
├── proc          进程信息（虚拟）
└── sys           内核参数（虚拟）
```

| 概念 | 说明 |
|------|------|
| inode | 文件元数据（权限、大小、块指针），不含文件名 |
| dentry | 目录项，文件名 → inode 映射 |
| block | 数据块，默认 4KB |

```bash
ls -i file.txt     # 查看 inode 号
df -i              # inode 使用率（小文件过多会耗尽）
stat file.txt      # 详细元数据
```

### 硬链接 vs 软链接

```bash
ln source hardlink        # 硬链，同 inode
ln -s source softlink     # 软链，独立 inode 指向路径
```

| 类型 | 跨分区 | 删原文件 |
|------|--------|----------|
| 硬链 | ❌ | 数据仍在 |
| 软链 | ✅ | 链断裂 |

## 2. 文件权限详解

```bash
-rwxr-xr-- 1 app app 4096 Jul  1 10:00 run.sh
│└─other
│ └─group
│  └─owner
└─类型（- 文件 d 目录 l 链接）
```

### 特殊权限

| 权限 | 含义 |
|------|------|
| SUID (4) | 执行时以文件 owner 身份运行 |
| SGID (2) | 目录下新文件继承组 |
| Sticky (1) | 目录仅 owner 可删自己文件（/tmp） |

```bash
chmod u+s /usr/bin/passwd   # SUID 示例
chmod +t /tmp               # Sticky
```

### umask

默认创建权限 = 666/777 & ~umask。常见 umask 022 → 文件 644，目录 755。

## 3. 用户与组

```bash
id app
useradd -m -s /bin/bash app
usermod -aG docker app      # 附加组
passwd app
groupadd devops
```

| 文件 | 内容 |
|------|------|
| `/etc/passwd` | 用户列表 |
| `/etc/shadow` | 密码哈希 |
| `/etc/group` | 组列表 |

**sudo**：

```bash
# /etc/sudoers.d/app
app ALL=(ALL) NOPASSWD: /bin/systemctl restart order-service
```

## 4. 进程模型

```
systemd (PID 1)
  ├── sshd
  ├── java (order-service)
  │     ├── GC 线程
  │     └── Tomcat 线程池
  └── nginx
```

### 进程状态

| 状态 | 含义 |
|------|------|
| R | Running |
| S | Sleeping（可中断） |
| D | Disk sleep（不可中断 IO） |
| Z | Zombie |
| T | Stopped |

```bash
ps aux
# USER PID %CPU %MEM VSZ RSS STAT START TIME COMMAND
```

| 字段 | 含义 |
|------|------|
| VSZ | 虚拟内存 |
| RSS | 物理内存 |
| STAT | 状态，含 `<` 高优先级 `N` 低优先级 |

## 5. 进程管理

```bash
# 后台与前后台
command &
jobs
fg %1
bg %1
nohup java -jar app.jar > /dev/null 2>&1 &

# 优先级 -20～19，越小越高
nice -n 10 java -jar app.jar
renice -n -5 -p PID
```

### 僵尸进程处理

```bash
ps aux | awk '$8=="Z" {print}'
# 找到父进程 PPID，重启或 kill 父进程
```

## 6. /proc 文件系统

```bash
cat /proc/PID/status    # 进程详情
cat /proc/PID/cmdline    # 启动命令
ls -l /proc/PID/fd        # 打开的文件描述符
cat /proc/PID/limits      # 资源限制
cat /proc/cpuinfo
cat /proc/meminfo
```

**Java 排障**：

```bash
jstack PID > thread.dump
ls /proc/PID/fd | wc -l    # FD 泄漏排查
```

## 7. 文件描述符与 ulimit

```bash
ulimit -a
ulimit -n 65535           # 当前 shell 生效
```

持久化 `/etc/security/limits.d/app.conf`：

```
app soft nofile 65535
app hard nofile 65535
```

Java 高并发需调大 **nofile**（连接数）和 **nproc**（线程数）。

## 8. 常用文件操作

```bash
cp -a src/ dst/           # 归档复制，保留权限
mv old new
rm -rf dir                # 危险，生产慎用
tar -czvf backup.tar.gz /app/logs
tar -xzvf backup.tar.gz
rsync -avz src/ user@host:/dst/
```

| 要点 | 一句话 |
|------|--------|
