## 1. 架构一图

```
┌──────────────── Control Plane ─────────────────┐
│  kube-apiserver  ← 唯一入口，REST              │
│  etcd            ← 集群状态存储                   │
│  scheduler       ← Pod → Node 调度              │
│  controller-mgr  ← Deployment/ReplicaSet 等    │
└───────────────────────┬────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
     Node 1          Node 2          Node 3
   kubelet         kubelet         kubelet
   kube-proxy      kube-proxy      kube-proxy
   ┌─Pod─┐         ┌─Pod─┐         ┌─Pod─┐
   │ app │         │ app │         │ app │
   └─────┘         └─────┘         └─────┘
```

## 2. 核心对象关系

```
Deployment  →  ReplicaSet  →  Pod(s)  →  Container(s)
     │                              │
     └──────── selector ────────────┘

Service  →  稳定 VIP/DNS  →  转发到 Pod
Ingress  →  HTTP 路由  →  Service
```

## 4. Deployment 最小 YAML

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: order-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: order-app
  template:
    metadata:
      labels:
        app: order-app
    spec:
      containers:
        - name: app
          image: registry.example.com/order-app:1.0.0
          ports:
            - containerPort: 8080
          resources:
            requests:
              memory: "512Mi"
              cpu: "500m"
            limits:
              memory: "1Gi"
              cpu: "1"
          readinessProbe:
            httpGet:
              path: /actuator/health/readiness
              port: 8080
            initialDelaySeconds: 30
          livenessProbe:
            httpGet:
              path: /actuator/health/liveness
              port: 8080
            initialDelaySeconds: 60
---
apiVersion: v1
kind: Service
metadata:
  name: order-app
spec:
  selector:
    app: order-app
  ports:
    - port: 80
      targetPort: 8080
```

## 5. Service 类型

| 类型 | 用途 |
|------|------|
| ClusterIP | 集群内访问（默认） |
| NodePort | 节点端口暴露 |
| LoadBalancer | 云 LB |
| ExternalName | DNS CNAME |

## 6. 发布策略

| 策略 | 说明 |
|------|------|
| RollingUpdate | 默认，逐步替换 Pod |
| maxSurge / maxUnavailable | 控制滚动速度 |
| 蓝绿 | 两套 Deployment + 切 Service selector |
| 金丝雀 | Istio/Argo Rollouts 或双 Deployment 权重 |

## 7. 面试 5 分钟

| 问 | 答 |
|----|-----|
| Pod 是什么？ | 最小调度单元，1+ 容器，共享网络/存储 |
| Deployment vs StatefulSet？ | 无状态 vs 有状态（固定标识、有序） |
| readiness vs liveness？ | 就绪才接流量 vs 存活否则重启 |
| 如何排查 CrashLoopBackOff？ | logs、describe、events、探针、OOM |
| K8s 和 Docker 关系？ | K8s 编排；容器运行时 containerd；Docker 可构建镜像 |
