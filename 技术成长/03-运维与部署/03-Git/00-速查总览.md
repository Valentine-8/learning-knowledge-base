# Git · 速查总览

```bash
git clone / pull / fetch
git status / diff / log --oneline --graph
git add / commit / push
git branch / checkout -b / switch
git merge / rebase / cherry-pick
git stash / reset / revert
git reflog
```

| 问 | 答 |
|----|-----|
| merge vs rebase | merge 保留分叉；rebase 线性历史，不改已推送公共分支 |
| reset vs revert | reset 改历史；revert 新提交反向，适合已推送 |
| fetch vs pull | fetch 只拉；pull = fetch + merge |
