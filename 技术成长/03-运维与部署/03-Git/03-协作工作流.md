# 03 · 协作工作流

## Git Flow（传统）

```
main（生产）← release ← develop ← feature/*
                    ↑ hotfix/*
```

适合版本发布节奏明确的产品。

## Trunk Based（互联网常见）

- 短生命分支（1～2 天）
- 小步 merge 到 **main/trunk**
- Feature Flag 隐藏未完成功能

## Pull Request / Merge Request

1. push 分支
2. 开 PR，Code Review
3. CI 通过
4. Squash merge 或 merge commit
5. 删远程分支

## .gitignore

```
target/
.idea/
*.log
.env
```

**禁止**提交密钥、生产配置。
