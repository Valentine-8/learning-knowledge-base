# 01 · 核心概念与对象模型

Git 是**分布式**版本库：每个 clone 都是完整仓库。

## 三个区域

```
工作区 → git add → 暂存区(index) → git commit → 本地仓库(.git)
                                              → git push → 远程
```

## 对象

| 对象 | 说明 |
|------|------|
| blob | 文件内容 |
| tree | 目录结构 |
| commit | 快照 + 父提交 + 作者信息 |
| tag | 指向 commit 的固定标记 |

**commit** 通过 SHA-1 标识；`HEAD` 通常指向当前分支 tip。

## 常用

```bash
git log --oneline -10
git show <commit>
git diff              # 工作区 vs 暂存区
git diff --cached     # 暂存区 vs 最后一次 commit
```
