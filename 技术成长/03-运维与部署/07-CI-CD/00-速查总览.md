# CI/CD · 速查总览

> 10 分钟复习。深入见 [01～05 章](./README.md)。

---

## 1. 核心概念

| 术语 | 英文 | 含义 |
|------|------|------|
| CI | Continuous Integration | 频繁集成，自动构建测试 |
| CD（交付） | Continuous Delivery | 随时可发布，手动上生产 |
| CD（部署） | Continuous Deployment | 自动上生产 |
| Pipeline | 流水线 | 构建→测试→扫描→部署 |
| Artifact | 制品 | jar、docker image、helm chart |
| Gate | 质量门禁 | 不达标阻断发布 |

---

## 2. 典型 Java 流水线

```
git push
  → checkout
  → mvn verify（单元测试+集成测试）
  → SonarQube 扫描
  → docker build & push
  → deploy staging（K8s/Helm）
  → 人工审批
  → deploy prod（蓝绿/金丝雀）
```

---

## 3. 工具对比

| 工具 | 特点 | 场景 |
|------|------|------|
| Jenkins | 插件生态强，自托管 | 企业内网、复杂流程 |
| GitLab CI | 与 Git 一体，YAML | GitLab 用户 |
| GitHub Actions | 云原生，Marketplace | 开源/GitHub 项目 |
| TeamCity | JetBrains，Java 友好 | IDE 团队 |
| Argo CD | GitOps 持续部署 | K8s 声明式发布 |

---

## 4. Jenkinsfile 片段

```groovy
pipeline {
  agent any
  stages {
    stage('Build') {
      steps { sh 'mvn -B clean package -DskipTests' }
    }
    stage('Test') {
      steps { sh 'mvn test' }
    }
    stage('Docker') {
      steps {
        sh 'docker build -t app:${BUILD_NUMBER} .'
        sh 'docker push registry/app:${BUILD_NUMBER}'
      }
    }
  }
}
```

---

## 5. GitLab CI 片段

```yaml
stages: [build, test, deploy]

build:
  stage: build
  script:
    - mvn -B package -DskipTests
  artifacts:
    paths: [target/*.jar]

deploy:
  stage: deploy
  script:
    - kubectl set image deploy/app app=registry/app:$CI_COMMIT_SHA
  only: [main]
```

## 6. GitHub Actions 片段

```yaml
name: CI
on: [push, pull_request]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: { java-version: '17', distribution: 'temurin' }
      - run: mvn -B verify
```

## 7. 质量门禁

| 检查 | 工具 |
|------|------|
| 单元测试覆盖率 | JaCoCo + Sonar |
| 代码规范 | Checkstyle/SpotBugs |
| 安全扫描 | OWASP Dependency-Check、Trivy |
| 镜像扫描 | Harbor、Snyk |

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| CI 和 CD 区别？ | CI 自动构建测试；CD 自动/半自动部署 |
| 蓝绿和金丝雀？ | 蓝绿全量切换；金丝雀逐步放量 |
| GitOps？ | Git 为唯一真相，Argo CD 同步集群 |
| 制品库作用？ | 版本化存储 jar/image，可追溯 |
| 流水线失败如何排查？ | 看 stage 日志、本地复现、mvn -X |
