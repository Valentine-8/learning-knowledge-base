# 01 · 运行时数据区

> **目标读者**：7 年 Java 后端，需能画出 JVM 内存模型、解释各区域存储内容与 OOM 类型，并说明 JDK8 永久代移除的影响。
> **预计阅读**：50 min · **难度**：★★★

---

## 1. 总览图

```
                    ┌──────────────────────────────────┐
                    │           Java 进程               │
  线程1 ───────────►│ PC │ 虚拟机栈 │ 本地方法栈        │
  线程2 ───────────►│ PC │ 虚拟机栈 │ 本地方法栈        │
                    ├──────────────────────────────────┤
                    │  堆 Heap（所有线程共享）           │
                    │  方法区 / Metaspace（共享）        │
                    │  直接内存（NIO，逻辑上堆外）        │
                    └──────────────────────────────────┘
```

| 区域 | 线程 | 存储内容 | 异常 |
|------|------|----------|------|
| 程序计数器 | 私有 | 当前字节码行号 | **不会 OOM** |
| 虚拟机栈 | 私有 | 栈帧、局部变量表、操作数栈 | SOE / OOM |
| 本地方法栈 | 私有 | Native 方法 | SOE / OOM |
| 堆 | 共享 | 对象实例、数组 | Heap OOM |
| Metaspace | 共享 | 类元数据、常量池等 | Metaspace OOM |
| 直接内存 | 共享 | DirectByteBuffer 等 | Direct buffer OOM |

---

## 2. 程序计数器（PC Register）

- 每条线程独立 PC，指向当前执行的字节码指令地址。
- 若执行 Native 方法，PC 为 **undefined**。
- 唯一不会发生 `OutOfMemoryError` 的区域（规范层面）。

---

## 3. 虚拟机栈

### 3.1 栈帧结构

```
栈帧 Stack Frame
├── 局部变量表（Local Variables）  slot、this、参数、局部变量
├── 操作数栈（Operand Stack）       计算中间结果
├── 动态链接（Dynamic Linking）     指向运行时常量池方法引用
└── 方法返回地址（Return Address）
```

```java
public int add(int a, int b) {
    int c = a + b;   // 局部变量 slot
    return c;
}
```

### 3.2 异常

| 异常 | 原因 |
|------|------|
| `StackOverflowError` | 递归过深、栈帧过大 |
| `OutOfMemoryError` | 无法扩展栈（`-Xss` 过大 × 线程过多） |

```bash
-Xss1m    # 每线程栈大小，默认平台相关（often 1M）
```

**面试**：栈存**基本类型、对象引用**，对象本身在堆；`int` 在栈，`Integer` 对象在堆、引用在栈。

---

## 4. 堆（Heap）

- **所有对象实例、数组** 在堆分配（逃逸分析优化除外）。
- GC 主要工作区域。

```
堆（逻辑分代，具体因收集器而异）
├── 新生代 Young
│   ├── Eden
│   └── Survivor S0 / S1
└── 老年代 Old
```

```bash
-Xms2g -Xmx2g              # 初始与最大堆
-Xmn512m                   # 新生代（G1 下含义不同）
-XX:NewRatio=2              # Old:Young = 2:1
-XX:SurvivorRatio=8         # Eden:S0:S1 = 8:1:1
```

| OOM 信息 | 含义 |
|----------|------|
| `Java heap space` | 堆无法分配对象 |
| `GC overhead limit exceeded` | 98% 时间 GC 回收 <2% 堆 |

---

## 5. 方法区与 Metaspace（JDK8+）

### 5.1 演进

| 版本 | 实现 | 位置 |
|------|------|------|
| JDK7 及前 | **永久代 PermGen** | 堆内 |
| JDK8+ | **Metaspace** | **本地内存**（Native） |

### 5.2 存储内容

- 类信息（字段、方法、字节码）
- 运行时常量池
- 静态变量（JDK7+ 静态变量**移至堆**）
- JIT 编译后的代码（Code Cache，独立区域）

```bash
-XX:MetaspaceSize=256m
-XX:MaxMetaspaceSize=512m    # 必须设上限，防类加载泄漏
```

| OOM | 常见原因 |
|-----|----------|
| `Metaspace` | 动态代理类过多、Groovy/CGLib、ClassLoader 泄漏 |
| `Compressed class space` | 类元数据压缩空间不足 |

---

## 6. 直接内存（Direct Memory）

```java
ByteBuffer buf = ByteBuffer.allocateDirect(1024 * 1024);
// 堆外分配，受 MaxDirectMemorySize 限制
```

- NIO、Netty 零拷贝常用直接内存。
- 分配回收走 **Unsafe**，Full GC 可能触发 `Cleaner` 回收 DirectBuffer。
- OOM：`Direct buffer memory`

```bash
-XX:MaxDirectMemorySize=512m
```

**面试**：直接内存**不属于** JVM 堆，但受 JVM 参数与进程内存限制。

---

## 7. 线程与内存关系

```
1000 线程 × 1MB 栈 ≈ 1GB 栈内存（不含堆）
```

| 优化 | 手段 |
|------|------|
| 减少线程 | 线程池、虚拟线程（JDK21） |
| 减小栈 | `-Xss256k`（需测 SOE） |
| 堆外泄漏 | 监控 DirectBuffer、Netty leak detection |

---

## 8. JDK 版本差异速记

| 项 | JDK7 | JDK8+ |
|----|------|-------|
| 方法区 | PermGen 堆内 | Metaspace 本地 |
| 字符串常量池 | PermGen | **堆** |
| 静态变量 | PermGen | **堆** |

---

## 9. 面试要点

| 问 | 答 |
|----|-----|
| 堆和栈区别？ | 堆共享存对象；栈私有存帧和局部变量 |
| 方法区存什么？ | 类元数据、常量池；JDK8 叫 Metaspace |
| PermGen 为什么移除？ | 大小难调、OOM 频繁；Metaspace 用本地内存可按类卸载 |
| 哪些区域会 OOM？ | 堆、Metaspace、栈扩展、直接内存、无法创建线程 |
| 对象一定在堆吗？ | 默认堆；逃逸分析可能栈上分配/标量替换 |
