## 1. 生产故障案例

### 案例 1：ThreadLocal 内存泄漏

| 项 | 内容 |
|----|------|
| 现象 | Full GC 后老年代仍 90%+，Tomcat 重启才恢复 |
| 根因 | 线程池线程复用，ThreadLocal<UserContext> 未 remove |
| 修复 | `finally { context.remove(); }` |
| 预防 | 线程池 + ThreadLocal 必须配对 remove |

### 案例 2：Metaspace OOM（动态代理）

| 项 | 内容 |
|----|------|
| 现象 | `OutOfMemoryError: Metaspace`，MyBatis Mapper 代理类爆炸 |
| 根因 | 热部署 + 每请求 new ClassLoader 未卸载 |
| 修复 | 修复 ClassLoader 泄漏；`-XX:MaxMetaspaceSize=512m` 早失败 |
| 预防 | 监控 M 区；限制反射/代理滥用 |

### 案例 3：Direct Memory OOM（Netty）

| 项 | 内容 |
|----|------|
| 现象 | 堆正常，进程 RSS 涨，Direct buffer OOM |
| 根因 | ByteBuf 未 release，泄漏检测未开 |
| 修复 | `ReferenceCountUtil.release`；`-Dio.netty.leakDetectionLevel=paranoid` 排查 |
| 预防 | 监控堆外；MaxDirectMemorySize |

### 案例 4：频繁 Full GC（堆过小）

| 项 | 内容 |
|----|------|
| 现象 | FGC 每分钟，接口 P99 飙升 |
| 根因 | K8s limit 512m 但 `-Xmx1g` 被 cgroup 杀；修正后仍 Xmx256m 过小 |
| 修复 | MaxRAMPercentage=75；Xms=Xmx=合适值 |
| 预防 | 容器内存 = 堆 + Metaspace + Direct + 栈 + 原生库 |

### 案例 5：jmap 打满磁盘

| 项 | 内容 |
|----|------|
| 现象 | 生产卡顿，磁盘 100% |
| 根因 | 30G 堆全量 dump 未用 live，文件 30G+ |
| 修复 | `jcmd GC.heap_dump` + live；低峰操作 |
| 预防 | 演练 dump 流程与磁盘空间 |

### 案例 6：System.gc 导致 STW

| 项 | 内容 |
|----|------|
| 现象 | 周期性 2s 停顿 |
| 根因 | 第三方库 RMI `System.gc()` |
| 修复 | `-XX:+DisableExplicitGC` 或 `-XX:+ExplicitGCInvokesConcurrent` |
| 预防 | GC 日志看 Full GC 触发原因 |

## 3. 高频简答模板

**堆 vs 栈**：堆存对象实例共享；栈存局部变量和方法栈帧线程私有。

**OOM 排查**：认类型 → dump → MAT Dominator → GC Roots 链 → 修 ThreadLocal/缓存/监听器。

**G1 选型**：JDK9+ 默认，Region 化，Mixed GC，设 MaxGCPauseMillis，避免 Full GC。
