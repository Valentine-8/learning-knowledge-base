## 1. 生产故障案例

### 案例 1：@Transactional 不生效

| 项 | 内容 |
|----|------|
| 现象 | 异常后数据仍提交 |
| 根因 | Service 内 `this.save()` 自调用 |
| 修复 | 拆 `AuditService` 或注入 `@Lazy self` |
| 预防 | Code Review 事务边界 |

### 案例 2：循环依赖启动失败

| 项 | 内容 |
|----|------|
| 根因 | 两 Service 构造器互依赖 |
| 修复 | 改字段注入 + `@Lazy` 或重构 |

### 案例 3：MyBatis 二级缓存脏读

| 项 | 内容 |
|----|------|
| 根因 | 多机开启二级缓存，更新不同步 |
| 修复 | 关二级缓存，改 Redis |

### 案例 4：大事务拖垮 DB

| 项 | 内容 |
|----|------|
| 根因 | `@Transactional` 内 Feign 调支付 30s |
| 修复 | 事务只包本地 DB；支付改 MQ 异步 |

### 案例 5：JWT 未校验 issuer

| 项 | 内容 |
|----|------|
| 根因 | 只验签不验 iss/aud |
| 修复 | Resource Server 配 issuer-uri |

### 案例 6：自动配置冲突双 DataSource

| 项 | 内容 |
|----|------|
| 根因 | 自定义 Bean 未 `@ConditionalOnMissingBean` |
| 修复 | Starter 规范 + exclude |
