---

## 1. JPA vs Hibernate

```
JPA = 规范（接口）
Hibernate = 实现（最常用）
Spring Data JPA = 再封装 Repository
```

---

## 2. 核心注解

| 注解 | 作用 |
|------|------|
| `@Entity` | 实体 |
| `@Table` | 表名 |
| `@Id` `@GeneratedValue` | 主键 |
| `@Column` | 列映射 |
| `@OneToMany` / `@ManyToOne` | 关联 |
| `@Version` | 乐观锁 |

---

## 3. 持久化上下文

```
EntityManager 管理一级缓存（Session）
同一事务内相同 ID 只查一次 DB
```

---

## 4. 懒加载陷阱

```java
@OneToMany(fetch = LAZY)  // 默认
// Session 关闭后访问 collection → LazyInitializationException
```

解决：`@Transactional` 内访问，或 fetch join。

---

## 5. N+1

```
查 1 次 orders + N 次 order_items = N+1
→ fetch join / @EntityGraph / batch size
```

---

## 6. Spring Data JPA

```java
interface OrderRepository extends JpaRepository<Order, Long> {
    List<Order> findByUserId(Long userId);
    @Query("select o from Order o join fetch o.items where o.id = :id")
    Optional<Order> findWithItems(@Param("id") Long id);
}
```
