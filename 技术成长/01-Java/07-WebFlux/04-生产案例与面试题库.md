## 1. 生产故障案例

### 案例 1：block() 拖死 Netty

| 项 | 内容 |
|----|------|
| 现象 | Gateway 间歇性全超时 |
| 根因 | Filter 中 JDBC `.block()` |
| 修复 | 改 boundedElastic 或移逻辑到 MVC 服务 |
| 预防 | ArchUnit 禁止 block |

### 案例 2：flatMap 并发打爆下游

| 项 | 内容 |
|----|------|
| 现象 | 聚合接口下游 503 |
| 根因 | `flatMap` 默认并发 256 |
| 修复 | `flatMap(fn, 8)` 限制并发 |
| 预防 | 代码 review reactive 操作符 |

### 案例 3：假 reactive

| 项 | 内容 |
|----|------|
| 现象 | 上 WebFlux 后性能无提升 |
| 根因 | 全链路阻塞 JDBC，仅 Controller 返回 Mono |
| 修复 | 回退 MVC + 虚拟线程 |
| 预防 | 选型 ADR + 压测对比 |

### 案例 4：WebClient 无超时

| 项 | 内容 |
|----|------|
| 现象 | 连接泄漏，内存涨 |
| 根因 | 未配 connect/read timeout |
| 修复 | `responseTimeout` + 连接池限制 |
| 预防 | WebClient 统一 Builder |
