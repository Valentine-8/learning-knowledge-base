# Spring Cloud · 速查总览

> **Spring Cloud** = 微服务工具集（注册发现、配置、网关、负载均衡、熔断），本库以 **Spring Cloud Alibaba（Nacos + Sentinel + Seata）** 为主。

---

## 1. 组件一图

```
                    ┌─────────────────────┐
                    │ Spring Cloud Gateway │ ← 统一入口、路由、鉴权
                    └──────────┬──────────┘
                               │
         ┌─────────────────────┼─────────────────────┐
         ▼                     ▼                     ▼
   order-service          pay-service          user-service
         │                     │                     │
         └─────────────────────┼─────────────────────┘
                               │
                    ┌──────────▼──────────┐
                    │       Nacos         │
                    │  注册发现 + 配置中心  │
                    └─────────────────────┘

   服务间：OpenFeign + LoadBalancer + Sentinel（限流熔断）
   分布式事务：Seata（可选）
   内部高性能：gRPC（见 gRPC 专题）
```

## 4. 核心组件速查

| 组件 | 作用 |
|------|------|
| **Nacos Discovery** | 服务注册与发现 |
| **Nacos Config** | 集中配置、动态刷新 |
| **Gateway** | API 网关、路由、Filter |
| **OpenFeign** | 声明式 HTTP 调用 |
| **LoadBalancer** | 客户端负载均衡（替代 Ribbon） |
| **Sentinel** | 流控、熔断、降级 |
| **Seata** | 分布式事务 AT/TCC |

## 6. 面试 5 分钟

| 问 | 答 |
|----|-----|
| Spring Cloud 是什么？ | 微服务治理工具集，非单一框架 |
| Nacos 和 Eureka？ | Nacos 还做配置；支持 AP/CP；国内主流 |
| Gateway 和 Zuul？ | Gateway WebFlux 非阻塞；Zuul 1 阻塞已过时 |
| Feign 原理？ | 动态代理 + LoadBalancer + HTTP |
| Sentinel 和 Hystrix？ | Sentinel 更活跃；滑动窗口、热点规则 |
