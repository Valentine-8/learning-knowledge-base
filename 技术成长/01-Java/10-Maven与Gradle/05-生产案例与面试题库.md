## 1. 生产故障案例

### 案例 1：依赖冲突 NoClassDefFoundError

| 项 | 内容 |
|----|------|
| 现象 | 生产启动失败，本地正常 |
| 根因 | 传递依赖带入旧版 guava，与方法签名不兼容 |
| 修复 | dependencyManagement 锁定 + exclude |
| 预防 | CI enforcer + dependency:tree 门禁 |

### 案例 2：SNAPSHOT 漂移

| 项 | 内容 |
|----|------|
| 现象 | 同一 tag 两次构建行为不同 |
| 根因 | 依赖 SNAPSHOT 被私服覆盖 |
| 修复 | 生产锁定 RELEASE；SBOM 记录 |
| 预防 | deploy 禁止 SNAPSHOT 到 prod |

### 案例 3：多模块循环依赖

| 项 | 内容 |
|----|------|
| 现象 | Maven reactor 构建失败 |
| 根因 | service ↔ web 互依赖 |
| 修复 | 抽取 api 模块，单向依赖 |
| 预防 | ArchUnit 依赖规则测试 |

### 案例 4：Docker 构建慢

| 项 | 内容 |
|----|------|
| 现象 | 镜像构建 15 min |
| 根因 | 每层 `mvn package` 全量下载 |
| 修复 | 多阶段 + 私服缓存 + dependency:go-offline |
| 预防 | BuildKit cache mount |

### 案例 5：日志框架冲突

| 项 | 内容 |
|----|------|
| 现象 | 日志不输出或绑定 multiple SLF4J |
| 根因 | commons-logging 与 logback 共存 |
| 修复 | exclude commons-logging |
| 预防 | spring-boot-starter 默认管理好 |
