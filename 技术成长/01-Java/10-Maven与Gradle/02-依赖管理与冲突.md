# 02 · 依赖管理与冲突

> **预计阅读**：90 min

---

## 1. 依赖声明

```xml
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-web</artifactId>
  <!-- version 可由 parent/BOM 管理 -->
  <scope>compile</scope>
  <optional>true</optional>   <!-- 不传递 -->
  <exclusions>...</exclusions> <!-- 排除传递依赖 -->
</dependency>
```

---

## 2. Scope 详解

| Scope | 场景 |
|-------|------|
| compile | 默认，全阶段需要 |
| provided | servlet-api、lombok（编译期） |
| runtime | JDBC 驱动（编译不需要） |
| test | JUnit |
| import | 仅 `<dependencyManagement>`，导入 BOM |

---

## 3. 传递依赖

A 依赖 B，B 依赖 C → A 自动依赖 C。

**问题**：版本冲突、不需要的库被打包。

---

## 4. 冲突调解规则

1. **最短路径优先**
2. **先声明优先**（路径相同时，POM 中先出现的赢）

```
mvn dependency:tree -Dverbose
mvn dependency:tree -Dincludes=org.slf4j
```

---

## 5. 排除依赖

```xml
<dependency>
  <groupId>com.example</groupId>
  <artifactId>some-lib</artifactId>
  <exclusions>
    <exclusion>
      <groupId>commons-logging</groupId>
      <artifactId>commons-logging</artifactId>
    </exclusion>
  </exclusions>
</dependency>
```

---

## 6. dependencyManagement

父 POM 或 BOM **只声明版本，不引入依赖**：

```xml
<dependencyManagement>
  <dependencies>
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-dependencies</artifactId>
      <version>3.2.0</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>
  </dependencies>
</dependencyManagement>
```

子模块引用时**省略 version**。

---

## 7. BOM（Bill of Materials）

| BOM | 用途 |
|-----|------|
| spring-boot-dependencies | Spring 生态版本对齐 |
| spring-cloud-dependencies | 微服务组件 |
| junit-bom | JUnit 5 全家桶 |

**原则**：一个项目尽量**单一 BOM 源**，避免多套版本打架。

---

## 8. 经典冲突案例

### 8.1 日志框架

```
logback vs log4j vs commons-logging
→ spring-boot-starter 已选好，exclude commons-logging
```

### 8.2 Netty 多版本

```
grpc-netty 与 elasticsearch 带入不同 netty
→ dependencyManagement 强制 netty-bom
```

### 8.3 Jackson 版本

```
Spring Boot BOM 统一管理，勿手动混版本
```

## 9. 工具与门禁

```bash
mvn dependency:analyze          # 未使用/未声明依赖
mvn enforcer:enforce            # 规则强制
mvn versions:display-dependency-updates
```

CI 集成 **OWASP Dependency-Check** 扫描 CVE。

---

## 10. SNAPSHOT vs RELEASE

| 类型 | 特点 |
|------|------|
| SNAPSHOT | 开发中，`-SNAPSHOT` 后缀，可覆盖 |
| RELEASE | 发布 immutable，不可覆盖 |

生产部署应锁定 **RELEASE** 或具体 SHA。
