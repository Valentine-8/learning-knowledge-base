# Java 压测 · 速查

> 10 分钟复习。深入见 [01～04 章](./README.md)。

---

## 1. 核心指标

| 指标 | 含义 |
|------|------|
| QPS/TPS | 每秒请求/事务数 |
| RT | 响应时间（看 P95/P99） |
| 并发数 | 同时活跃用户数 |
| 错误率 | 非 2xx/业务失败比例 |
| 饱和度 | CPU/内存/连接池使用率 |

**Little 定律**：`并发 ≈ QPS × RT`

---

## 2. 压测类型

| 类型 | 目的 |
|------|------|
| 基准 | 单接口最大能力 |
| 负载 | 目标 QPS 下稳定性 |
|  stress | 找 breaking point |
|  soak | 长时间内存泄漏 |
|  spike | 突发流量 |

---

## 3. 压测流程

```
目标 → 场景设计 → 数据准备 → 预热 → 加压 → 监控 → 报告 → 优化
```

## 5. 生产压测红线

- 隔离环境或专用 shadow 流量
- 限流保护、随时熔断
- 避开业务高峰
- 数据可回滚

---

## 6. 面试速答

| 问 | 答 |
|----|-----|
| 如何定压测目标？ | 业务峰值 × 安全系数（1.5～3） |
| P99 重要性？ | 长尾体验、SLA |
| 压测常见瓶颈？ | DB、连接池、GC、锁、下游 |
| 线上能压吗？ | 影子流量/隔离环境，严格规范 |
