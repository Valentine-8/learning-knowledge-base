# 05 面试题库与案例

> **用法**：每题先口述 2 分钟，再对照参考答案查漏。标记 `★` 为 7 年工程师必答；`▲` 为常见追问。

---

## 一、面向对象与泛型（Q1～Q10）

### Q1 ★ 面向对象四大特性是什么？多态在 JVM 层如何实现？

**考点**：OOP 基础 + 虚方法调用。

**参考答案**：
封装隐藏状态并通过接口暴露行为；继承表达 is-a；多态允许父类引用调用子类实现；抽象提取共性。实例方法多态靠 **动态绑定**：对象头指向类元数据，invokevirtual 查 vtable 偏移调用实际实现。静态方法、private/final 方法、字段访问均为编译期静态绑定。

**展开**：
- **封装**在后端体现为聚合根维护不变量，而非贫血 getter/setter
- **继承**应满足 LSP，否则多态调用产生隐藏 bug
- HotSpot 对虚方法有 **inline cache（monomorphic/bimorphic/megamorphic）** 优化，7 年工程师可顺带提 JIT

**▲ 追问**：接口 default 方法冲突如何解决？→ 类优先于接口，子接口优先于父接口，否则显式 override。

**踩坑**：认为「多态包括重载」——重载是编译期静态分派。

---

### Q2 ★ 重载和重写的区别？

**参考答案**：

| 维度 | 重载 | 重写 |
|------|------|------|
| 位置 | 同类 | 子类 |
| 签名 | 参数不同 | 相同（返回类型可协变） |
| 绑定 | 编译期 | 运行期 |
| 权限 | 无关 | 不能更严格 |

**踩坑**：泛型擦除导致 `method(List<String>)` 与 `method(List<Integer>)` 擦除后签名冲突。

---

### Q3 ★ 为什么组合优于继承？举例说明继承破坏封装。

**参考答案**：继承将子类与父类实现耦合，父类变更可能导致子类行为异常（fragile base class）。组合通过接口委托，运行时切换实现。例：`Stack extends Vector` 暴露 `add(index)` 破坏栈语义；应用 `Stack` 内部持有 `Deque` 委托。

**▲ 追问**：Template Method 模式是否违背组合优先？→ 有意为之的框架扩展点，需文档化钩子方法。

---

### Q4 ★ equals 和 hashCode 契约？只重写 equals 会怎样？

**参考答案**：equals 满足自反、对称、传递、一致；equal 对象 hashCode 必须相等。HashMap 先算 hash 定位桶再 equals 比较，hashCode 不一致会导致「相等 key 取不到 value」。

**踩坑**：用可变字段作 hashCode，对象 put 后修改字段导致丢失。

---

### Q5 ★ 抽象类与接口如何选择？Java 8 后接口变化？

**参考答案**：需共享状态或模板方法用抽象类；需多「能力标签」或 API 演进用接口。Java 8 引入 default/static 方法；9 私有方法；接口可含实现，但不能替代所有抽象类场景（构造器、字段保护）。

---

### Q6 ★ 解释 PECS，写 copy 方法签名。

**参考答案**：Producer Extends, Consumer Super。只读用 extends，只写用 super。

```java
public static <T> void copy(List<? extends T> src, List<? super T> dest)
```

`Collections.sort(List<T>)` 需读写同一 T，故不用通配符。

---

### Q7 ★ 什么是类型擦除？运行时如何获取泛型类型？

**参考答案**：泛型仅编译期检查，字节码中变为原始类型；类型信息存 Signature 属性供反射。运行时 `new T()` 不可行。获取方式：子类化 `TypeToken<List<String>> {}`、反射 `ParameterizedType`、Spring `ResolvableType`。

**▲ 追问**：桥方法是什么？→ 擦除后保持泛型 override 多态，编译器生成合成方法。

---

### Q8 ★ `List<Object>` 是 `List<String>` 的父类型吗？为什么？

**参考答案**：不是。泛型不变（invariant），若允许则可通过 `List<Object>` 插入 Integer 破坏 `List<String>` 类型安全。数组协变 `Object[] o = new String[1]` 会在 arraystore 时运行时失败，故泛型设计为不变。

---

### Q9 ★ 不可变对象有什么好处？如何设计？

**参考答案**：线程安全、可缓存共享、简化推理。`final` 类、final 字段、不暴露 mutable 引用（防御性拷贝）、操作返回新实例。

---

### Q10 ★ SOLID 在微服务中的例子？

**参考答案**：
- S：订单服务不管支付细节
- O：新增支付渠道加 Strategy 不改旧代码
- L：缓存实现可互换
- I：读写接口分离
- D：依赖 Repository 接口非 MyBatis 实现

## 二、注解、反射与异常（Q11～Q20）

### Q11 ★ 注解的本质是什么？@Retention 三种区别？

**参考答案**：注解是带元数据的接口，JDK 动态代理或生成类实现 `Annotation`。SOURCE 编译丢弃；CLASS 进 class 反射不可见；RUNTIME 运行时可读。Spring 扫描需 RUNTIME。

---

### Q12 ★ 元注解 @Target、@Inherited、@Repeatable 作用？

**参考答案**：@Target 限定标注位置（TYPE、METHOD 等）；@Inherited 类注解子类继承；@Repeatable 同位置多次注解，容器注解包裹。

---

### Q13 ★ 编译期注解处理 vs 运行期反射？

**参考答案**：APT（Lombok、MapStruct）在 javac 生成代码，零运行时开销；Spring 运行期扫描 class 构建 BeanDefinition。热路径应用 APT 或字节码生成，避免反射 invoke。

---

### Q14 ★ 反射为什么慢？如何优化？

**参考答案**：访问检查、装箱、难内联。优化：缓存 Method/Field、setAccessible、MethodHandle、CGLIB/ByteBuddy 生成代理。Spring 6 Native AOT 预计算减少反射。

---

### Q15 ★ Class.forName 与 .class 区别？

**参考答案**：forName 默认触发类初始化（static 块）；`.class` 不触发。JDBC `Class.forName(driver)` 曾用于注册驱动，JDBC 4+  SPI 自动加载。

---

### Q16 ★ Spring 如何把 @Autowired 注入字段？

**参考答案**：AutowiredAnnotationBeanPostProcessor 在 Bean 实例化后通过反射（或缓存的 MethodHandle）解析 `@Autowired`/`@Value`，从容器取依赖注入。构造器注入优先于字段注入（不可变、易测试）。

**▲ 追问**：循环依赖如何解决？→ 三级缓存 + 早期引用（仅单例属性注入）。

---

### Q17 ★ Checked 与 Unchecked 异常如何选型？

**参考答案**：现代后端倾向业务异常 extends RuntimeException，边界层统一处理；避免 throws 污染签名。Checked 适合可恢复且调用方必须处理的 API（如低层 IO 库）。Spring 事务默认 rollback RuntimeException。

---

### Q18 ★ 如何设计业务异常体系？

**参考答案**：errorCode + message + httpStatus；区分用户可见与内部诊断；保留 cause 链；全局 `@RestControllerAdvice` 映射；日志带 traceId。

---

### Q19 ★ try-with-resources 原理？suppressed exception？

**参考答案**：编译器生成 finally 调用 close；主 try 与 close 均异常时，close 异常作为 suppressed 附加到主异常。

---

### Q20 ★ Java 反序列化为何危险？如何防护？

**参考答案**：readObject 可触发 gadget 链 RCE。禁用不可信数据反序列化；用 JSON；必须时用 ObjectInputFilter 白名单；不启用 Jackson default typing。

---

## 三、BIO / NIO / Netty（Q21～Q30）

### Q21 ★ BIO、NIO、AIO 区别？Java NIO 是异步吗？

**参考答案**：
- BIO：阻塞 wait + 拷贝，一线程一连接
- NIO：Selector 多路复用，同步非阻塞 read/write
- AIO：Proactor，完成通知（Linux 实现有限）

Java NIO **不是**严格异步 IO，是 IO 多路复用 + 非阻塞同步读写。

**展开对比表**：

| 模型 | 线程模型 | 典型 QPS 瓶颈 | Java API |
|------|----------|---------------|----------|
| BIO | 1:1 线程连接 | 线程数、栈内存 | Socket |
| NIO | 1:N EventLoop | EventLoop 阻塞 | Selector |
| AIO | 回调 | 生态弱 | AsynchronousSocketChannel |

**7 年加分**：结合业务说「网关 10w 长连接选 Netty；内部 CRUD 微服务 Java 21 虚拟线程 + 阻塞 JDBC 更简单」。

---

### Q22 ★ 什么是 Reactor 模型？Netty 属于哪种？

**参考答案**：事件分发器 accept/read/write 就绪事件，分派 Handler。Netty 主从 Reactor：Boss accept，Worker 处理 IO。单 Reactor 单线程 Redis 经典；业务阻塞需 Worker 线程池 offload。

---

### Q23 ★ Selector 的 select、poll、epoll 区别（Linux）？

**参考答案**：select/poll O(n) 遍历 fd 集合；epoll O(1) 事件回调，无 fd 数量硬限制（历史 select 1024）。Java NIO EpollSelectorProvider 在 Linux 用 epoll。

---

### Q24 ★ Buffer 的 flip、clear、compact？

**参考答案**：flip：limit=position, position=0 准备读；clear：position=0, limit=capacity 准备写（不删数据）；compact：未读数据移到开头，准备继续写。

---

### Q25 ★ 为什么 Netty 用 EventLoop 而不是每 Channel 一线程？

**参考答案**：C10K 下线程爆炸。EventLoop 单线程处理多 Channel IO，无锁串行；需严格避免阻塞 EventLoop。

---

### Q26 ★ ByteBuf 与 ByteBuffer 区别？为何要引用计数？

**参考答案**：ByteBuf 读写双索引、自动扩容、池化、堆外支持。引用计数管理池化内存生命周期，release 归还池；泄漏导致 Direct Memory OOM。

---

### Q27 ★ TCP 粘包拆包原因与解决方案？

**参考答案**：TCP 字节流无边界。固定长、分隔符、长度字段（最常用）、协议封装。Netty LengthFieldBasedFrameDecoder。

---

### Q28 ★ Netty 内存泄漏如何排查？

**参考答案**：`-Dio.netty.leakDetection.level=paranoid`（开发）；SimpleChannelInboundHandler 自动 release；异常路径 ReferenceCountUtil.release；堆外内存监控。

---

### Q29 ★ 零拷贝是什么？Java 如何用到？

**参考答案**：减少用户态内核态拷贝。sendfile、mmap；FileChannel.transferTo；DirectByteBuf 减少 heap-direct 拷贝。

---

### Q30 ★ 虚拟线程 vs Netty，何时选谁？

**参考答案**：虚拟线程简化阻塞式业务代码，适合 IO 密集 HTTP/DB；Netty 提供协议栈、内存池、极致吞吐，RPC/网关/长连接仍主流。可组合：虚拟线程跑在 Servlet，底层仍可能 Netty（WebClient）。

---

## 四、Stream 与 Java 新特性（Q31～Q40）

### Q31 ★ Stream 中间操作为何 lazy？

**参考答案**：融合操作（fusion）减少遍历次数；短路操作可提前终止；构建计算链延迟到终端操作。

---

### Q32 ★ map 与 flatMap 区别？

**参考答案**：map 一对一转换；flatMap 一对多展开再 flatten。例：订单列表 → 所有订单项用 flatMap(Order::getItemsStream)。

---

### Q33 ★ Collectors.toMap 有哪些坑？

**参考答案**：重复 key 抛异常需 merge 函数；value 为 null NPE；并行流 toMap 需线程安全 merge。

---

### Q34 ★ Parallel Stream 适用与不适用场景？

**参考答案**：适用：大集合 CPU 密集纯计算。不适用：小集合、IO、共享 mutable、LinkedList 拆分差、common pool 影响全局。

**展开**：
- ForkJoinPool.commonPool 并行度 = CPU-1，与 `CompletableFuture.supplyAsync` 默认池相同，互相争抢
- `Spliterator.ORDERED` 并行仍保证 encounter order，有 merge 成本
- 正确替代：显式 `ExecutorService` + 分批 + `CompletableFuture.allOf`

**案例**：100 元素列表 parallelStream 做 JSON 序列化 —— 慢于顺序流（任务拆分开销 > 计算量）。

---

### Q35 ★ Optional 正确使用方式？反模式？

**参考答案**：链式 map/orElseThrow，不用 get()。反模式：字段 Optional、of 可空值、过度替代 if。

---

### Q36 ★ java.time 如何正确处理时区？

**参考答案**：存储 Instant/UTC；展示 ZonedDateTime 按用户 ZoneId；解析带 offset；避免 SimpleDateFormat；DB 用 timestamptz。

---

### Q37 ★ Record 是什么？与 class 区别？JPA 能用吗？

**参考答案**：不可变数据载体，自动生成 equals/hashCode/toString/accessor。不能继承类；JPA 实体慎用（需无参构造、mutable 代理）。

---

### Q38 ★ Sealed Class 解决什么问题？

**参考答案**：限制继承体系，配合 pattern matching exhaustive switch，领域模型穷举（Payment 类型）。

---

### Q39 ★ Java 21 虚拟线程原理概要？pin 问题？

**参考答案**：JVM 挂载虚拟线程到平台线程 carrier，阻塞时卸载释放 carrier。synchronized/native 可能 pin 住 carrier 降低伸缩性。

---

### Q40 ★ 从 Java 8 升级到 17 要关注什么？

**参考答案**：模块反射 opens、移除 JAXB、依赖兼容、GC 默认 G1、Record/Sealed 采用、CI 多版本测试、容器镜像升级。

## 五、综合设计与线上案例（Q41～Q50）

### Q41 ★ 设计一个注解驱动的限流组件，说明扩展点。

**参考答案**：
- `@RateLimit(qps, key)` 注解
- Aspect 拦截，key 支持 SpEL
- RateLimiter 接口 + Guava/Redis 实现
- 超限抛 BusinessException
- 配置中心动态 QPS 可选

**考察**：注解 + AOP + 可测试 + 分布式一致性（Redis sliding window）。

---

### Q42 ★ 线上 Full GC 频繁，如何与 Direct Memory 关联排查？

**案例**：
- 现象：RPC 网关延迟高，GC log Full GC 每分钟
- 发现：Direct buffer 占用高，Netty leak detection 报 LEAK
- 根因：自定义 Handler 缓存 ByteBuf 未 release
- 修复：ReferenceCountUtil.release；升级 Handler 用 SimpleChannelInboundHandler
- 预防：堆外监控、压测 leak detection

**考点**：NIO 内存 + JVM 工具链（phase2-JVM）。

---

### Q43 ★ 接口返回 List 还是 Stream？DTO 用 Record 还是 class？

**参考答案**：
- REST 返回 JSON 必 materialize 为 List，不用 Stream（Stream 非 Serializable、单次消费）
- 内部服务层可用 Stream 延迟处理
- 对外 API DTO 用 Record 简洁；JPA Entity 用 class；需 builder/继承用 class

### Q44 ★ 如何 Code Review 一段滥用 Parallel Stream 的代码？

**案例代码**：

```java
users.parallelStream().forEach(u -> {
    UserDetail d = userClient.fetch(u.getId());  // HTTP
    cache.put(u.getId(), d);
});
```

**问题**：IO 在 parallelStream、共享 cache 非线程安全、common pool 阻塞。

**改进**：虚拟线程或专用线程池 + CompletableFuture；ConcurrentHashMap；批量接口。

---

### Q45 ★ 比较 Tomcat 线程池与 Netty EventLoop 处理 1 万长连接。

**参考答案**：

| 维度 | Tomcat BIO 思维 | Netty |
|------|-----------------|-------|
| 线程数 | 数千 platform threads | 少量 EventLoop |
| 内存 | 栈 × 线程数 | ByteBuf 池 + 少线程 |
| 阻塞 | 线程阻塞 read | 非阻塞 + 多路复用 |
| 编程 | 同步 Servlet | 回调/Pipeline |

Tomcat NIO 折中：Poller + Worker，但 Servlet API 仍阻塞语义。WebFlux 或虚拟线程是 Tomcat 生态的现代化路径。

---

### Q46 ★ 接口多继承 default 方法冲突怎么解决？

**参考答案**：
1. 类上的方法优先于接口 default
2. 子接口 default 优先于父接口
3. 两个无关接口同名 default → 实现类必须显式 override

```java
interface A { default void m() { System.out.println("A"); } }
interface B { default void m() { System.out.println("B"); } }
class C implements A, B {
    @Override public void m() { A.super.m(); }
}
```

---

### Q47 ★ 深拷贝 vs 浅拷贝？如何实现深拷贝？

**参考答案**：浅拷贝共享引用字段；深拷贝递归复制引用对象。实现：拷贝构造器、JSON 往返、序列化（慢且需 Serializable）。`record` 字段为 immutable 引用时浅拷贝即够用。

---

### Q48 ★ MyBatis `@Select` 如何映射到 SQL 执行？

**参考答案**：Mapper 接口 JDK 动态代理 → MapperProxy.invoke → MapperMethod 解析注解/SQL → SqlSession 执行 → 结果映射。XML 与注解混用最终都进 MappedStatement  registry。

---

### Q49 ★ EventLoop 任务队列积压如何监控？

**参考答案**：Netty pendingTasks、Micrometer 自定义 gauge、写延迟 histogram；Arthas 查看 EventLoop 线程栈是否卡在业务代码；修复：offload 到 businessExecutor。

---

### Q50 ★ Structured Concurrency 解决什么问题？

**参考答案**：子任务与父 scope 生命周期绑定；任一失败可取消兄弟任务；错误传播结构化。对比「线程池 fire-and-forget」资源泄漏与超时难取消问题。

## 七、白板编程题

### 8.1 实现 LRU Cache（LinkedHashMap）

```java
public class LRUCache<K, V> extends LinkedHashMap<K, V> {
    private final int capacity;

    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);  // accessOrder=true
        this.capacity = capacity;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > capacity;
    }
}
```

**追问**：线程安全版本？→ `Collections.synchronizedMap` 或 Caffeine。

### 8.2 反转单链表（迭代）

```java
ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

语言专题关联：Node 不可变 vs 可变设计。

### 8.3 泛型：找出 List 中最大元素

```java
public static <T extends Comparable<T>> T max(List<T> list) {
    if (list.isEmpty()) throw new IllegalArgumentException();
    T result = list.get(0);
    for (T t : list) {
        if (t.compareTo(result) > 0) result = t;
    }
    return result;
}
```

边界：`? extends Comparable` vs `Comparable<? super T>` 差异。

## 八、场景题：订单导出 OOM

**背景**：7 年工程师负责订单系统，运营导出 500 万订单 Excel，JVM heap OOM。

**排查路径**：
1. 堆 dump：大对象 char[]/byte[] 占满
2. 代码：`orders.stream().collect(toList())` 全量加载 + POI 内存模式
3. 根因：Stream 看似惰性，terminal collect 物化全量

**方案**：
- 游标分页 / keyset pagination 流式读 DB
- EasyExcel / CSV 流式写
- 异步任务 + OSS 下载链接
- 导出限流 + 最大行数

**语言考点**：Stream 不是银弹；理解惰性到 terminal 的物化点。

## 九、场景题：RPC 超时与异常传播

**背景**：A 调 B 调 C，C 超时，B 捕获 Exception 返回 null，A NPE。

**规范**：
- RPC 层：TimeoutException 转 BusinessException 或 Result 包装
- 不用 null 表示失败；Optional 仅内部，API 用 Result<T>
- 异常链保留：`new ServiceException("B failed", cause)`
- Sentinel/熔断：快速失败而非长时间阻塞

**关联章节**：02 异常体系 + 03 Netty 超时 IdleStateHandler。

## 十、场景题：Java 17 升级后反射失败

**背景**：Spring Boot 2.x 应用升级 JDK 17，启动报 `InaccessibleObjectException`。

**原因**：模块系统封闭 `java.lang` 等包，CGLIB/反射无法 setAccessible。

**解决**：
- 升级 Spring Boot 3.x（Jakarta EE）
- 临时 `--add-opens java.base/java.lang=ALL-UNNAMED`（最小集）
- 依赖版本对齐 Hibernate、MyBatis

**7 年工程师**：能讲清 JPMS 与框架反射的博弈，不是简单加 JVM 参数。

## 附录 A：连环追问示例

### A.1 从 HashMap 到泛型擦除

**面试官**：HashMap 为什么 key 要重写 hashCode？  
**你**：定位桶 + equals 比较…  
**追问**：那 `List<String>` 和 `List<Integer>` 运行时类型？  
**你**：都是 List，擦除为 Object；所以不能 `list.add(1)` 到 `List<String>`…  
**追问**：MyBatis 如何返回 `List<User>`？  
**你**：MappedStatement 的 ResultType + 反射构造 User，ParameterizedType 来自接口方法签名…

### A.2 从 Tomcat 到 Netty 到虚拟线程

**面试官**：1 万 WebSocket 连接怎么扛？  
**你**：Netty Reactor，Boss/Worker…  
**追问**：业务逻辑放哪？  
**你**：EventLoop 只做 IO，业务 offload 线程池…  
**追问**：Java 21 能否不用 Netty 写 HTTP？  
**你**：可以，虚拟线程 + 阻塞 Servlet/HttpClient，但自定义二进制协议、RPC 框架仍选 Netty…

### A.3 从 Stream 到 OOM

**面试官**：Stream 比 for 循环快吗？  
**你**：不一定；小集合有开销；parallel 看 CPU 与拆分…  
**追问**：导出百万行为什么 OOM？  
**你**：terminal collect 物化；应分页 + 流式写文件…
