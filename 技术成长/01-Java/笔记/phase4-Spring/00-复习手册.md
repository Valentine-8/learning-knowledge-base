## 一、IoC / Bean（极简）

- IoC：容器管生命周期；DI：注入依赖
- 生命周期：实例化 → 注入 → Aware → BPP → @PostConstruct → BPP(after/AOP) → 使用 → destroy
- **构造器注入**优先；多实现 `@Primary` / `@Qualifier`

---

## 二、循环依赖

- 三级缓存：singletonObjects / earlySingletonObjects / singletonFactories
- **仅**单例 + 属性注入；构造器循环 → `@Lazy` 或重构

---

## 三、AOP

- JDK（接口）/ CGLIB（类）；Boot 默认 CGLIB
- **同类 `this.xxx()` 不走代理** → 事务/AOP 失效

---

## 四、Boot

- `@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`
- `AutoConfiguration.imports` + `@Conditional*`

---

## 五、MVC

`Filter → DispatcherServlet → Interceptor → Controller → JSON`

---

## 六、事务

- REQUIRED / REQUIRES_NEW / NESTED 常考
- 失效：非 public、自调用、吞异常、checked 未 rollbackFor
