## 1. 集合框架一图

```
Collection                              Map
├── List                                ├── HashMap（无序 O(1)）
│   ├── ArrayList（首选）               ├── LinkedHashMap（插入序 / LRU）
│   ├── LinkedList                      ├── TreeMap（红黑树有序）
│   └── CopyOnWriteArrayList            └── ConcurrentHashMap（线程安全）
├── Set
│   ├── HashSet（底层 HashMap）
│   ├── LinkedHashSet
│   └── TreeSet
└── Queue / Deque
    ├── ArrayDeque（栈/队列首选）
    ├── PriorityQueue（堆）
    └── BlockingQueue 家族（并发）
```

## 2. 选型口诀

| 需求 | 首选 | 备选 |
|------|------|------|
| 随机读多、尾插多 | ArrayList | — |
| 头尾队列/栈 | ArrayDeque | LinkedList（少用） |
| 去重 | HashSet | LinkedHashSet（保序） |
| 有序 Map | TreeMap | LinkedHashMap（按插入/LRU） |
| 并发 Map | ConcurrentHashMap | — |
| 并发 List 读多写少 | CopyOnWriteArrayList | — |
| 生产者-消费者 | LinkedBlockingQueue | ArrayBlockingQueue |

## 3. 核心参数速记

| 类 | 关键参数 |
|----|----------|
| ArrayList | 默认容量 10；扩容 **1.5 倍**；首次 add 才分配 |
| HashMap | 默认 16；负载因子 **0.75**；树化 **8** / 退树 **6** / 数组 **64** |
| ConcurrentHashMap | 不允许 null；JDK8 **synchronized 锁桶头 + CAS** |
| PriorityQueue | 小顶堆；**非线程安全**；`Comparator` 决定顺序 |

## 4. HashMap put 五步

```
1. hash(key) 扰动
2. 桶下标 (n-1) & hash
3. 桶空 → 放 Node
4. 否则比 key → 覆盖 / 尾插链表或树
5. ++size；超 threshold → resize（2 倍）
```

## 5. fail-fast vs fail-safe

| | fail-fast | fail-safe |
|--|-----------|-----------|
| 代表 | ArrayList、HashMap | COWAList、CHM |
| 机制 | modCount 检测 | 遍历副本/弱一致 |
| 场景 | 单线程别边遍历边改 | 并发读多写少 |

## 6. 面试 5 分钟版

| 问 | 答 |
|----|-----|
| HashMap 为什么容量 2 的幂？ | `(n-1)&hash` 等价取模且分布均匀；扩容可快速判断节点去留 |
| equals 与 hashCode？ | equals 相等 → hashCode 必须相等；否则 HashMap 找不到 |
| CHM JDK8 怎么锁？ | 桶空 CAS；否则 synchronized 锁头节点 |
| ArrayList 扩容？ | 1.5 倍 `old + (old>>1)` |
| PECS？ | Producer extends 只读；Consumer super 只写 |

## 7. 易错 checklist

- [ ] `Arrays.asList` 固定大小，不能 add/remove
- [ ] `subList` 是视图，原列表改结构会异常
- [ ] HashMap 初始容量要预估，避免频繁 resize
- [ ] `Integer` 作 key 注意 -128~127 缓存
- [ ] CHM `size()` 是估计值
- [ ] Stream 里不要改外部可变变量
