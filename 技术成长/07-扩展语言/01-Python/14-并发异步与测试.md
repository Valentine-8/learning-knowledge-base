## 1. GIL 是什么

**全局解释器锁**：同一进程内，任意时刻只有一个线程执行 Python 字节码。

| 场景 | 建议 |
|------|------|
| CPU 密集（算数、加密） | `multiprocessing` 或多进程 |
| IO 密集（HTTP、读盘） | `threading` 或 **asyncio** |
| 简单脚本 | 单线程足够 |

面试答法：GIL 让 CPU 多线程不能并行算 Python 代码；IO 等待时会释放 GIL，所以多线程爬接口仍有意义。

## 2. threading 示例

```python
import threading
import requests

urls = ["https://httpbin.org/delay/1"] * 5

def fetch(url):
    r = requests.get(url, timeout=30)
    print(url, r.status_code)

threads = []
for u in urls:
    t = threading.Thread(target=fetch, args=(u,))
    t.start()
    threads.append(t)

for t in threads:
    t.join()
print("全部完成")
```

更简单用线程池：

```python
from concurrent.futures import ThreadPoolExecutor, as_completed

def fetch(url):
    return requests.get(url, timeout=30).status_code

with ThreadPoolExecutor(max_workers=8) as pool:
    futures = [pool.submit(fetch, u) for u in urls]
    for fut in as_completed(futures):
        print(fut.result())
```

## 3. asyncio 入门

```python
import asyncio
import httpx

async def fetch(client, url):
    resp = await client.get(url)
    return resp.status_code

async def main():
    urls = ["https://httpbin.org/get"] * 10
    async with httpx.AsyncClient(timeout=30) as client:
        tasks = [fetch(client, u) for u in urls]
        codes = await asyncio.gather(*tasks)
        print(codes)

asyncio.run(main())
```

规则：

- `async def` 定义协程
- `await` 等待异步操作
- **不要在 async 里写** `requests.get`（阻塞），用 `httpx` 或 `aiohttp`

## 4. multiprocessing 了解

```python
from multiprocessing import Pool

def square(n):
    return n * n

if __name__ == "__main__":
    with Pool(4) as p:
        print(p.map(square, range(10)))
```

Windows 必须 `if __name__ == "__main__"` 保护入口。

## 5. pytest 测试

`calc.py`：

```python
def add(a, b):
    return a + b

def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b
```

`test_calc.py`：

```python
import pytest
from calc import add, divide

def test_add():
    assert add(1, 2) == 3

def test_divide():
    assert divide(10, 2) == 5

def test_divide_by_zero():
    with pytest.raises(ValueError):
        divide(1, 0)
```

