## 1. 为什么用类

当数据和行为绑在一起更清晰时，用**类**描述「一类东西」。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name}: 汪汪")

d = Dog("旺财")
d.bark()
```

- `class` 定义类
- `__init__` **构造方法**，创建对象时自动调用
- `self` 代表**当前实例**，必须作为第一个参数
- `bark` 是**实例方法**

## 2. 属性与方法

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额须为正")
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount

    def __repr__(self):
        return f"BankAccount({self.owner!r}, {self.balance})"

acc = BankAccount("Alice", 100)
acc.deposit(50)
acc.withdraw(30)
print(acc)
```

## 3. 类属性 vs 实例属性

```python
class Counter:
    total = 0  # 类属性，所有实例共享

    def __init__(self):
        Counter.total += 1
        self.id = Counter.total

a = Counter()
b = Counter()
print(Counter.total, a.id, b.id)
```

## 4. 封装约定

Python 无 `private`，用命名约定：

```python
class User:
    def __init__(self, password):
        self._password = password      # 单下划线：内部使用
        self.__secret = "x"            # 双下划线：名称改写，避免子类误用
```

## 5. 继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError

class Cat(Animal):
    def speak(self):
        print(f"{self.name}: 喵")

class Dog(Animal):
    def speak(self):
        print(f"{self.name}: 汪")

def make_speak(animal: Animal):
    animal.speak()

make_speak(Cat("Tom"))
make_speak(Dog("Spike"))
```

**super()** 调用父类：

```python
class Employee(Person):
    def __init__(self, name, emp_id):
        super().__init__(name)
        self.emp_id = emp_id
```

## 6. dataclass（简化数据类）

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

p = Point(1.0, 2.0)
print(p)
```

适合主要是数据的类，少写样板代码。
