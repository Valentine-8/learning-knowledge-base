# 04 · 列表与元组

> **本章目标**：掌握 list 的增删改查、切片、遍历；理解 tuple 不可变；嵌套列表。
> **预计用时**：6～8 小时 · **难度**：★★

---

## 1. 列表 list 是什么

**列表**是有序、可变的元素集合，用 `[]`。

```python
nums = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]
empty = []
print(type(nums))  # <class 'list'>
print(len(nums))   # 5
```

---

## 2. 索引与切片（同字符串）

```python
fruits = ["apple", "banana", "cherry"]
print(fruits[0])
print(fruits[-1])
print(fruits[1:3])  # ['banana', 'cherry']
```

---

## 3. 修改列表

```python
nums = [1, 2, 3]
nums[0] = 10
print(nums)  # [10, 2, 3]

nums[1:3] = [20, 30, 40]  # 切片赋值可改变长度
print(nums)
```

---

## 4. 增删元素

```python
items = [1, 2]

items.append(3)        # 尾部加一个 [1,2,3]
items.extend([4, 5])   # 尾部加多个 [1,2,3,4,5]
items.insert(0, 0)     # 指定位置插入 [0,1,2,3,4,5]

removed = items.pop()       # 弹最后一个
first = items.pop(0)        # 弹 index 0
items.remove(3)             # 删第一个值为 3 的元素

del items[0]                # 删 index 0
items.clear()               # 清空
```

## 5. 查找与排序

```python
nums = [3, 1, 4, 1, 5]
print(1 in nums)       # True
print(nums.index(4))   # 2
print(nums.count(1))   # 2

nums.sort()            # 原地升序
print(nums)

nums.sort(reverse=True)
sorted_copy = sorted([3, 1, 2])  # 新列表，不改原列表
print(sorted_copy)
```

**自定义排序**：

```python
users = [("bob", 80), ("alice", 95)]
users.sort(key=lambda x: x[1], reverse=True)
print(users)
```

## 6. 遍历

```python
fruits = ["apple", "banana", "cherry"]

for f in fruits:
    print(f)

for i, f in enumerate(fruits):
    print(i, f)

# 同时遍历多个列表
names = ["a", "b"]
scores = [90, 85]
for n, s in zip(names, scores):
    print(n, s)
```

---

## 7. 列表复制（重要）

```python
a = [1, 2, 3]
b = a              # b 和 a 指向同一列表！
b.append(4)
print(a)           # [1, 2, 3, 4]

# 浅拷贝
c = a.copy()
c.append(99)
print(a)           # 不变
```

**嵌套列表陷阱**：

```python
matrix = [[0] * 3] * 3  # 错误！三行同一引用
matrix[0][0] = 1
print(matrix)  # 三行第一列都是 1

# 正确
matrix = [[0] * 3 for _ in range(3)]
```

## 8. 元组 tuple

**不可变**有序序列，用 `()`。

```python
point = (3, 4)
single = (42,)     # 单元素必须加逗号
not_tuple = (42)   # 这是 int

print(point[0])
# point[0] = 5  # TypeError
```

**用途**：固定结构、函数返回多值、dict 的 key。

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([1, 5, 3])
print(lo, hi)
```

## 9. 列表推导式（预览）

```python
squares = [x * x for x in range(10)]
evens = [x for x in range(20) if x % 2 == 0]
print(squares)
print(evens)
```
