> **Java 对照**：列表推导式 ≈ `stream.map().filter().collect()` 的一行版；`yield` 生成器 Java 无直接对应（类似 Iterator 惰性）；`@decorator` ≈ 手写 AOP/动态代理的轻量版。
>

## 1. 推导式

```python
# list
squares = [x * x for x in range(10)]
evens = [x for x in range(20) if x % 2 == 0]

# dict
idx = {name: i for i, name in enumerate(["a", "b", "c"])}

# set
unique_lens = {len(w) for w in ["hi", "hello", "hey"]}

# 嵌套（别太深）
matrix = [[i * j for j in range(3)] for i in range(3)]
```

## 2. 生成器函数 yield

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(5):
    print(x)
```

`yield` 暂停函数，下次 `next()` 继续。适合**大数据流**，不必一次加载内存。

```python
def read_lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.strip()
```

## 4. 迭代器协议

```python
nums = iter([1, 2, 3])
print(next(nums))
print(next(nums))
# next(nums)  # StopIteration
```

`for` 循环底层就是 iter + next。

## 5. 装饰器入门

```python
import functools
import time

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} {time.perf_counter() - start:.3f}s")
        return result
    return wrapper

@timer
def work():
    time.sleep(0.1)

work()
```

`@timer` 等价于 `work = timer(work)`。

## 6. 上下文管理器（复习）

```python
from contextlib import contextmanager

@contextmanager
def tag(name):
    print(f"[{name} start]")
    try:
        yield
    finally:
        print(f"[{name} end]")

with tag("job"):
    print("doing")
```
