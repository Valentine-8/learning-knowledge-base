# 专题复习：操作系统（进程 · 内存 · IO · 死锁）

> 对应技能清单 §九。计网见 [计算机网络](../02-计算机网络/00-速查总览.md)。

---

## 一、进程与线程

| 概念 | 说明 |
|------|------|
| 进程 | 资源分配单位，独立地址空间 |
| 线程 | CPU 调度单位，共享进程内存 |
| 协程 | 用户态轻量，主动让出（Go、虚拟线程底层载体） |

**进程状态**：新建、就绪、运行、阻塞、终止。

**上下文切换**：保存寄存器、PC、栈指针 → 换进程开销大。

---

## 二、进程通信 IPC

| 方式 | 说明 |
|------|------|
| 管道 / 命名管道 | 半双工 |
| 消息队列 | 内核维护 |
| 共享内存 | 最快，需同步 |
| 信号量 | 同步互斥 |
| Socket | 跨机器 |

---

## 三、内存管理

| 概念 | 说明 |
|------|------|
| 虚拟内存 | 每个进程独立地址空间 |
| 分页 | 固定大小页框，页表映射 |
| 分段 | 逻辑段，易碎片 |
| 页面置换 | LRU、FIFO、Clock |
| TLB | 页表缓存，加速地址转换 |

**Java 关联**：JVM 堆是进程堆空间的一部分；堆外 Direct Memory。

---

## 四、IO 模型（与 NIO 对应）

| 模型 | 说明 |
|------|------|
| 阻塞 IO | 等数据就绪 |
| 非阻塞 IO | 轮询 |
| **IO 多路复用** | select/poll/epoll，NIO/Netty 基础 |
| 异步 IO | 内核完成再通知（AIO） |

**epoll**：LT/ET 模式；ET 需一次读完。

---

## 五、死锁

**四条件**：互斥、占有等待、不可抢占、循环等待。

**处理**：预防（破坏条件）、避免（银行家）、检测恢复、鸵鸟（偶尔死锁）。

**Java**：`jstack` 看 `Found Java-level deadlock`。

---

## 六、锁与同步（OS 视角）

- 互斥锁 Mutex、读写锁 RWLock、自旋锁
- **用户态锁 vs 内核锁**：竞争激烈时 synchronized 可能膨胀到 OS Mutex

---

## 七、面试速答

| 问 | 答 |
|----|-----|
| 进程和线程区别？ | 进程独立内存；线程共享，切换轻，需同步 |
| 虚拟内存作用？ | 隔离、比物理内存大、简化链接加载 |
| select 和 epoll？ | select 有 fd 上限 O(n) 扫描；epoll 事件驱动 O(1) |
| 死锁条件？ | 互斥、占有等待、不可抢占、循环等待 |
