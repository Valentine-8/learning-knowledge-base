## 一、Web 攻击类

### Q1：SQL 注入如何发生？MyBatis 如何防？

**答**：不可信输入拼进 SQL 改变语义。`#{}` 预编译绑定参数；`${}` 仅列名白名单；ORM 参数化；DB 最小权限。

### Q2：XSS 三种类型？如何防？

**答**：存储型（持久）、反射型（URL）、DOM 型（纯前端）。输出编码、CSP、HttpOnly Cookie、避免 `innerHTML`；Thymeleaf 默认转义。

### Q3：CSRF 和 XSS 区别与联系？

**答**：CSRF 借用户 Cookie 发恶意请求；XSS 在页面执行脚本。XSS 可偷 token 绕过 CSRF 防护，故优先防 XSS。

### Q4：SSRF 危害与防护？

**答**：服务端请求内网/本机/metadata。URL 白名单、禁内网段、禁危险协议、redirect 校验。

### Q5：如何防止越权？

**答**：服务端校验资源归属 userId；RBAC `@PreAuthorize`；垂直越权禁默认开放 admin API；数据权限 SQL 拦截。

### Q6：文件上传要注意什么？

**答**：扩展名+魔数白名单、随机文件名、存 OSS 非 webroot、大小限制、病毒扫描、禁止执行权限。

## 二、认证授权类

### Q7：Session 和 JWT 怎么选？

**答**：Session 服务端状态，易注销，适合单体+Redis；JWT 无状态，适合微服务+移动端，需短 exp+refresh 解决失效。

### Q8：JWT 结构？为何不存敏感信息？

**答**：Header.Payload.Signature；Payload Base64 可解码非加密，存 sub/roles/exp，不存密码。

### Q9：JWT 被盗怎么办？

**答**：短 access exp、refresh rotation、HTTPS、HttpOnly 存 refresh（若用 Cookie）、敏感操作 MFA、黑名单（高敏）。

### Q10：OAuth2 授权码模式完整步骤？

**答**：redirect authorize → 用户同意 → code 回 redirect_uri → 后端 code+secret 换 token → access 调 API；state 防 CSRF；PKCE 给公共客户端。

### Q11：401 和 403？

**答**：401 未认证或凭证无效；403 已认证无权限。

### Q12：RBAC 和 ABAC？

**答**：RBAC 角色-权限；ABAC 属性策略更细（部门、时间）。Spring `@PreAuthorize` SpEL；复杂用 OPA。

### Q13：单点登录原理？

**答**：统一 IdP 认证发 ticket/token，各 SP 信任 IdP 公钥或共享 session（CAS TGT）；OAuth2/OIDC 联邦常见。

## 三、加密类

### Q14：对称和非对称使用场景？

**答**：对称 AES 加密 bulk；非对称 RSA/ECC 交换密钥、数字签名；TLS 混合。

### Q15：为何不用 SHA-256 存密码？

**答**：太快无盐可被彩虹表/GPU 暴力；应用 BCrypt/Argon2 慢哈希+盐。

### Q16：HMAC 作用？

**答**：共享密钥的消息认证码，验证完整性与来源；API 签名常用 HMAC-SHA256。

### Q17：HTTPS 握手做了什么？

**答**：协商套件、验证证书链、ECDHE 交换预主密钥、派生对称密钥、加密应用数据。

### Q18：数字证书作用？

**答**：CA 签名绑定域名与公钥，防中间人；浏览器信任根 CA。

## 四、API 与架构类

### Q19：如何设计开放 API 签名？

**答**：appId+secret；canonical string 含 method/path/query/body/timestamp/nonce；HMAC 签名；服务端验 timestamp 窗口与 nonce 去重。

### Q20：如何防重放攻击？

**答**：timestamp+nonce+签名；nonce Redis 唯一；幂等键；支付回调序列号。

### Q21：限流怎么做？429 场景？

**答**：网关令牌桶/滑动窗口；Redis 计数；Sentinel；登录、短信、下单接口必限。

### Q22：微服务安全架构？

**答**：网关验 JWT、TLS 终止；内网 mTLS 可选；Feign 透传 Authorization；服务间 M2M client_credentials；Secret 不进镜像。

### Q23：日志安全注意什么？

**答**：不记 password/token/完整身份证；脱敏；防日志注入换行；集中审计。

## 五、Spring Security 类

### Q24：Filter Chain 大致顺序？

**答**：SecurityContext 持久化 → 认证过滤器（表单/JWT）→ 授权 → 异常处理；`OncePerRequestFilter` 自定义 JWT。

### Q25：CSRF 何时开何时关？

**答**：Cookie Session 表单应用开启；纯 JWT Header 无 Cookie 常关；若 Cookie 存 token 仍需 CSRF 或 SameSite Strict。

### Q26：`@PreAuthorize` 和 `@Secured`？

**答**：PreAuthorize SpEL 灵活（hasAuthority）；Secured 角色名简单。需 `@EnableMethodSecurity`。

### Q27：BCryptPasswordEncoder 原理？

**答**：Blowfish 变体，内置盐，cost 2^rounds 次；matches 常数时间比较。

## 六、场景设计题

### S1：设计电商订单接口安全

**要点**：

- HTTPS + JWT 或 Session
- 创建订单鉴权、库存幂等（Idempotency-Key）
- 支付回调验签 + 幂等表
- 订单详情校验 userId 防越权
- 敏感字段脱敏
- 限流防刷

### S2：第三方 OAuth 登录「用微信登录」

**要点**：

- 授权码模式，secret 仅后端
- state 随机校验
- 绑定本地 user（openid unionid）
- 首次注册与已有账号绑定流程
- token 存服务端或 JWT 自签

### S3：发现 Log4Shell 如何应急？

**要点**：

- 确认版本 < 2.15
- 升级 2.17+ 或 JVM 参数 `-Dlog4j2.formatMsgNoLookups=true`
- WAF 规则临时挡 `${jndi:`
- 扫描外联与异常进程
- 依赖树排查传递引入

### S4：API 被刷如何排查？

**要点**：

- 网关/access log 看 IP、User-Agent、路径分布
- 限流、验证码、WAF、封 IP
- 账号层面异常登录告警
- 业务是否存在 IDOR 被批量遍历

## 七、判断题速记

| 说法 | 对错 |
|------|------|
| HTTPS 就防 XSS | 错，XSS 在浏览器执行 |
| POST 比 GET 安全 | 不完全，都需 HTTPS |
| JWT 加密了用户信息 | 错，仅签名，payload 可解码 |
| OAuth2 是认证协议 | 错，授权；OIDC 才是身份 |
| CORS 能防 CSRF | 错，CORS 限读响应；CSRF 用 Token/SameSite |
| 密码 MD5 加盐一次就够 | 错，应用 BCrypt/Argon2 |

## 十八、更多 Mock 题

**Q28：如何存储 API Secret？**  
K8s Secret/Vault；环境变量注入；不进镜像层；轮换。

**Q29：HTTPS 能否防中间人公司内部？**

## 二十五、Mock 场景：JWT 泄露应急

1. 缩短所有 access exp（配置中心）
2. refresh token 全失效（删 Redis 会话）
3. 轮换 signing key（kid 切换）
4. 强制用户 re-login（清 Cookie）
5. 审计泄露范围 IP/时间
