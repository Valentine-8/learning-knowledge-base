## 一、树的基本概念

### 1.1 术语

| 术语 | 含义 |
|------|------|
| 根/叶/父/子 | 标准定义 |
| 度 | 子节点个数；二叉树度 ≤ 2 |
| 深度 | 根到节点边数（或节点数，需说明） |
| 高度 | 叶到根或树最大深度 |
| 满二叉树 | 除最后一层全满 |
| 完全二叉树 | 最后一层从左连续，堆用 |

**n 个节点二叉树形态数**：卡特兰数 C_n = (2n)! / ((n+1)! n!)。

### 1.2 存储

| 方式 | 说明 |
|------|------|
| 链式 | `left/right` 指针，面试默认 |
| 数组 | 下标 i 的左子 2i+1、右子 2i+2，适合完全二叉树/堆 |

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}
```

## 二、二叉树遍历

### 2.1 四种遍历

| 遍历 | 顺序 | 应用 |
|------|------|------|
| 前序 | 根-左-右 | 复制树、表达式树前缀 |
| 中序 | 左-根-右 | BST 得有序序列 |
| 后序 | 左-右-根 | 删树、算子树信息 |
| 层序 | 按层 BFS | 最短层、右视图 |

### 2.2 递归模板

```java
void preorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);
    preorder(node.left, res);
    preorder(node.right, res);
}
```

中序、后序同理调整 visit 位置。

### 2.3 迭代：栈模拟

**中序迭代**（左链一路入栈，弹栈访问并转右子）：

```java
List<Integer> inorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}
```

### 2.4 层序遍历（BFS）

```java
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

**变形**：锯齿层序（偶数层 reverse）、右视图（每层最后一个）、最大深度（层数）。

## 三、二叉搜索树（BST）

### 3.1 性质

- 左子树所有键 < 根 < 右子树所有键
- 中序遍历严格递增（若允许重复需约定）
- 查找/插入/删除平均 O(log n)，最坏 O(n)（退化成链）

### 3.2 验证 BST

**错误做法**：只比较父与子。应用 **上下界** 递归：

```java
boolean isValidBST(TreeNode root) {
    return validate(root, null, null);
}

boolean validate(TreeNode node, Integer min, Integer max) {
    if (node == null) return true;
    if (min != null && node.val <= min) return false;
    if (max != null && node.val >= max) return false;
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}
```

### 3.3 BST 查找与插入

```java
TreeNode search(TreeNode root, int val) {
    while (root != null && root.val != val) {
        root = val < root.val ? root.left : root.right;
    }
    return root;
}

TreeNode insert(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);
    if (val < root.val) root.left = insert(root.left, val);
    else root.right = insert(root.right, val);
    return root;
}
```

### 3.4 删除节点

三种情况：

1. 无子/一子：用子代替或删叶
2. 两子：用 **中序后继**（右子最左）或前驱替换值，再删后继

## 四、平衡二叉树与红黑树

### 4.1 AVL / 红黑树（概念）

| | AVL | 红黑树 |
|--|-----|--------|
| 平衡 | 严格，|平衡因子|≤1 | 近似，黑高平衡 |
| 旋转 | 更频繁 | 较少 |
| Java | 少用 | **TreeMap/TreeSet**、HashMap 树化 |

**红黑树五性质**：节点红/黑；根黑；叶（NIL）黑；红子必黑；任意路径黑节点数相同。

**面试**：TreeMap O(log n) 增删查；HashMap 当桶链表长度 > 8 且 table ≥ 64 转红黑树，避免 O(n) 链。

### 4.2 平衡二叉树判定（110）

```java
int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    if (left == -1) return -1;
    int right = height(node.right);
    if (right == -1) return -1;
    if (Math.abs(left - right) > 1) return -1;
    return Math.max(left, right) + 1;
}
```

### 5.3 最近公共祖先（236）

```java
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
```

## 六、堆（优先队列）

### 6.1 结构

**完全二叉树** + **堆序性质**：

- **大顶堆**：父 ≥ 子，根最大
- **小顶堆**：父 ≤ 子，根最小

**数组存储**：`parent(i)=(i-1)/2`, `left=2i+1`, `right=2i+2`。

| 操作 | 复杂度 |
|------|--------|
| peek | O(1) |
| push | O(log n) 上浮 siftUp |
| pop | O(log n) 下沉 siftDown |
| heapify 建堆 | O(n) |

### 6.2 Java PriorityQueue

```java
// 小顶堆（默认）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大顶堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());

// 自定义对象
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
```

**注意**：`PriorityQueue` 非线程安全；并发用 `PriorityBlockingQueue`。

**迭代器不保证堆顺序**，只能 peek/poll 有序。

### 6.3 TopK 问题

**第 K 大**：维护 **大小为 K 的小顶堆**，堆顶是 K 大里最小。

```java
int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int x : nums) {
        heap.offer(x);
        if (heap.size() > k) heap.poll();
    }
    return heap.peek();
}
```

**复杂度**：O(n log k)，优于全排序 O(n log n) 当 k 小。

**前 K 高频**：HashMap 频次 + 小顶堆按频次；或桶排序 O(n)。

### 6.4 堆排序

建大顶堆，反复 swap(0, end) 并 siftDown → O(n log n) 原地不稳定。

## 七、多叉树与 Trie

### 7.1 N 叉树

LeetCode 429 层序类似二叉树，子列表 `node.children`。

### 7.2 字典树 Trie

**场景**：前缀匹配、自动补全、单词搜索 II。

```java
class Trie {
    Trie[] children = new Trie[26];
    boolean isWord;

    void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) node.children[i] = new Trie();
            node = node.children[i];
        }
        node.isWord = true;
    }

    boolean search(String word) {
        Trie node = find(word);
        return node != null && node.isWord;
    }

    boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    Trie find(String s) {
        Trie node = this;
        for (char c : s.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) return null;
            node = node.children[i];
        }
        return node;
    }
}
```

## 十三、平衡树旋转（概念）
