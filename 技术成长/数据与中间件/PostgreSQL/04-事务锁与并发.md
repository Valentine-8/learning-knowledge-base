# 04 · 事务、锁与并发

> **预计阅读**：50 min · **难度**：★★★★

---

## 1. 显式事务

```sql
BEGIN;
UPDATE account SET balance = balance - 100 WHERE id = 1;
UPDATE account SET balance = balance + 100 WHERE id = 2;
COMMIT;
-- ROLLBACK;
```

Spring `@Transactional` 默认传播 REQUIRED，隔离级别默认跟 PG（RC）。

---

## 2. 锁类型

| 锁 | 场景 |
|----|------|
| Row Exclusive | UPDATE/DELETE 行 |
| Share | SELECT FOR SHARE |
| Exclusive | SELECT FOR UPDATE |
| Access Exclusive | DDL（ALTER TABLE） |

```sql
SELECT * FROM orders WHERE id = 1 FOR UPDATE;           -- 排他行锁
SELECT * FROM orders WHERE id = 1 FOR UPDATE SKIP LOCKED; -- 跳过已锁（队列抢单）
SELECT * FROM orders WHERE id = 1 FOR UPDATE NOWAIT;    -- 立即失败
```

**SKIP LOCKED**：高并发任务队列，多 worker 抢不同行，Java 定时任务常用。

---

## 3. 死锁

PG 自动检测，牺牲一个事务：

```
ERROR: deadlock detected
DETAIL: Process 123 waits for ShareLock on transaction 456; blocked by process 789...
```

**排查**：

```sql
SELECT * FROM pg_locks l
JOIN pg_stat_activity a ON l.pid = a.pid
WHERE NOT granted;
```

**预防**：固定加锁顺序、短事务、索引减少锁范围。

---

## 4. 乐观锁

```sql
UPDATE product SET stock = stock - 1, version = version + 1
WHERE id = 1 AND version = 5 AND stock > 0;
-- 检查 affected rows
```

JPA `@Version` 同样适用。

---

## 5.  advisory 锁

应用层分布式锁（非行锁）：

```sql
SELECT pg_advisory_lock(12345);   -- 阻塞
SELECT pg_try_advisory_lock(12345); -- 非阻塞
SELECT pg_advisory_unlock(12345);
```

**与 Redis 锁**：PG 锁绑定连接，连接池需注意；Redis 更常见跨服务。

---

## 6. 长事务危害

- 阻止 VACUUM 清理 → 膨胀
- 持有锁阻塞业务
- 连接占用

监控：

```sql
SELECT pid, now() - xact_start AS duration, query
FROM pg_stat_activity
WHERE state = 'active' AND xact_start IS NOT NULL
ORDER BY duration DESC;
```
