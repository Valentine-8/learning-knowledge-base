# 05 · 复制与高可用

> **预计阅读**：40 min · **难度**：★★★

---

## 1. 流复制（物理复制）

```
Primary（读写）
    │ WAL 流
    ├── Standby 1（只读）
    └── Standby 2（只读）
```

| 模式 | 说明 |
|------|------|
| 异步 | 默认，主不等待从确认 |
| 同步 | `synchronous_commit`，至少 N 从确认，RPO=0 倾向 |

**Java 读写分离**：

```yaml
# 常见：ShardingSphere / 自研路由
spring.shardingsphere.rules.readwrite-splitting...
```

或 **只读报表** 直连 Standby JDBC URL。

---

## 2. 逻辑复制

表级、跨版本、异构：

```sql
CREATE PUBLICATION mypub FOR TABLE orders, users;
-- 订阅端 CREATE SUBSCRIPTION
```

适合：部分表同步、CDC 到数仓、升级迁移。

---

## 3. 高可用方案

| 方案 | 说明 |
|------|------|
| Patroni + etcd | 自动 failover，国内常用 |
| repmgr | 相对简单 |
| 云 RDS / PolarDB PG | 托管 HA |

**failover 后**：Java 连接串指向 VIP 或 DNS，池化需 **重连**。

---

## 4. 备份

| 方式 | 说明 |
|------|------|
| pg_dump | 逻辑备份，单库 |
| pg_basebackup | 物理基备 |
| WAL 归档 | PITR 时间点恢复 |

---

## 5. 监控指标

- 复制延迟：`pg_stat_replication.replay_lag`
- 连接数：`pg_stat_activity` count
- 表膨胀：`pgstattuple` 扩展
- 慢查询：`pg_stat_statements`
