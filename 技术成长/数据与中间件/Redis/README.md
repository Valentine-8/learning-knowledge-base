# Redis 深度学习（数据结构 · 持久化 · 集群 · 缓存 · 分布式锁）

> **适用**：7 年 Java 后端面试 + 线上缓存架构 + Redis 故障排查。
> **读法**：按章顺序学一遍（约 12～18h）；复习时先看 [00-速查总览](./00-速查总览.md)，再翻薄弱章。

## 学习路径建议

```
入门速览 (00) → 数据结构 (01) → 持久化/集群 (02)
      ↓
缓存设计 (03) → 分布式锁 (04) → 生产调优 (05) → 刷题案例 (06)
```

| 阶段 | 目标 | 对应章节 |
|------|------|----------|
| 基础 | 能讲清五种基本类型 + 底层编码 | 01 |
| 架构 | 能设计主从/哨兵/Cluster 方案 | 02 |
| 业务 | 能设计缓存方案并处理三大问题 | 03 |
| 进阶 | 分布式锁选型、生产故障排查 | 04、05 |
| 面试 | 50+ 题 + 8 案例口述 | 06 |
