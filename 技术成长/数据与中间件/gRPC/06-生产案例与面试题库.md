## 1. 生产案例

### 案例 1：字段编号复用导致脏数据

| 根因 | 删字段后新字段复用旧 number，旧客户端解析错 |
| 修复 | `reserved` + 新编号 |
| 预防 | Code Review .proto；breaking change 检测 buf |

### 案例 2：CreateOrder 重试重复下单

| 根因 | UNAVAILABLE 自动重试 |
| 修复 | 客户端关重试 + 幂等键 |
| 预防 | 文档标注幂等性 |

### 案例 3：message too large

| 根因 | 导出 10MB Protobuf 超默认 4MB |
| 修复 | 改 stream 或调 maxInboundMessageSize |

### 案例 4：HTTP/2  behind 旧 Nginx

| 根因 | Nginx 未开 http2 或缓冲破坏 gRPC |
| 修复 | `grpc_pass` 或直连 Pod |
