# gRPC · 速查总览

> **gRPC 是什么**：Google 开源 RPC 框架，默认 **Protobuf** 序列化 + **HTTP/2** 传输，强类型、高性能、多语言。

---

## 2. vs REST / OpenFeign

| 维度 | REST + JSON | gRPC + Protobuf |
|------|-------------|-----------------|
| 契约 | OpenAPI（可选） | **.proto 强制** |
| 序列化 | JSON 文本 | Protobuf 二进制，小且快 |
| 传输 | HTTP/1.1 常见 | **HTTP/2** 多路复用 |
| 流式 | SSE/WebSocket | **原生四种流** |
| 浏览器 | 直接调 | 需 grpc-web |
| 调试 | curl 友好 | grpcurl、Postman |
| Java 生态 | Spring MVC/Feign 成熟 | grpc-spring-boot-starter |

**选型**：**对外 API** → REST；**服务间内部**、低延迟、多语言 → gRPC。

---

## 3. 四种通信模式

| 模式 | 说明 |
|------|------|
| Unary | 一问一答（最常见） |
| Server streaming | 客户端发 1，服务端流式回 |
| Client streaming | 客户端流式发，服务端回 1 |
| Bidirectional streaming | 双向流 |

---

## 4. .proto 最小示例

```protobuf
syntax = "proto3";
package order;

option java_package = "com.example.order.grpc";
option java_multiple_files = true;

service OrderService {
  rpc GetOrder(GetOrderRequest) returns (OrderResponse);
  rpc ListOrders(ListOrdersRequest) returns (stream OrderResponse);
}

message GetOrderRequest {
  int64 order_id = 1;
}

message OrderResponse {
  int64 order_id = 1;
  string status = 2;
  int64 amount = 3;
}
```

```xml
<dependency>
  <groupId>net.devh</groupId>

```

```java
@GrpcService
public class OrderGrpcService extends OrderServiceGrpc.OrderServiceImplBase {
    @Override
    public void getOrder(GetOrderRequest req, StreamObserver<OrderResponse> obs) {
        OrderResponse resp = ...;
        obs.onNext(resp);
        obs.onCompleted();
    }
}
```

## 6. 面试 5 分钟

| 问 | 答 |
|----|-----|
| gRPC 是什么？ | RPC 框架；Protobuf；HTTP/2 |
| 为何比 REST 快？ | 二进制小、HTTP/2 多路复用、无 JSON 解析 |
| 和 Feign 关系？ | Feign 是 HTTP；gRPC 是另一套协议，可并存 |
| 如何做版本兼容？ | proto3 字段编号不变，新字段 optional，勿删号 |
| 负载均衡？ | client-side LB、K8s headless、xDS |
