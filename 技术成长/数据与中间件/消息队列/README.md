```
入门（Day 1-2）
  00 速查 → 01 Kafka 或 02 RocketMQ（选你公司用的）
       ↓
进阶（Day 3-4）

       ↓
冲刺（Day 5+）
  05 面试题库 → 结合项目经历口述
```

**7 年工程师目标**：至少精通一种 MQ（能讲清源码级原理 + 生产踩坑），另一种能说清架构差异与选型理由。

## 快速自检清单

- [ ] 能画 Kafka 生产/消费全流程（含 ack、ISR、offset commit）
- [ ] 能讲 RocketMQ 事务消息三阶段（半消息 → 本地事务 → commit/rollback）
- [ ] 能分析消息丢失发生在哪个环节，并给出对应防护
- [ ] 能设计幂等方案（唯一键 + DB/Redis）
- [ ] 能解释 Rebalance 触发条件与优化手段
- [ ] 能对比 Kafka 与 RocketMQ 并给出选型建议
