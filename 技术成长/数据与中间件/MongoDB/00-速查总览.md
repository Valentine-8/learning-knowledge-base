# MongoDB · 速查总览

> 10 分钟复习。深入见 [01～05 章](./README.md)。

---

## 1. 是什么

**MongoDB** 文档型 NoSQL 数据库，数据以 **BSON**（类 JSON 二进制）存储，Schema 灵活，水平扩展通过 **分片** 实现。

**Java 连接**：

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://user:pass@host1:27017,host2:27017/mydb?replicaSet=rs0
```

依赖：`spring-boot-starter-data-mongodb`

---

## 2. 架构一图

```
Application (Spring Data MongoDB)
    │
    ▼
mongos（分片集群路由，可选）
    │
    ├── Primary ──► Secondary(s)     副本集
    │       └── Hidden / Arbiter
    │
    └── Config Server + Shard1/2/3   分片集群
            │
            ▼
        WiredTiger 存储引擎（默认）
```

## 3. 与 MySQL 速对比

| 维度 | MongoDB | MySQL |
|------|---------|-------|
| 模型 | 文档（嵌套 JSON） | 关系表 |
| Schema | 灵活，可演进 | 强 Schema |
| JOIN | `$lookup`（弱） | 原生 JOIN |
| 事务 | 4.0+ 多文档事务 | ACID 成熟 |
| 扩展 | 分片水平扩展 | 分库分表/中间件 |
| 典型场景 | 日志、内容、IoT、灵活属性 | 强一致 OLTP |

## 4. CRUD 速查

```javascript
// 插入
db.users.insertOne({ name: "张三", age: 28, tags: ["java"] })

// 查询
db.users.find({ age: { $gte: 18 } }).sort({ _id: -1 }).limit(10)
db.users.findOne({ _id: ObjectId("...") })

// 更新
db.users.updateOne({ name: "张三" }, { $set: { age: 29 }, $push: { tags: "go" } })

// 删除
db.users.deleteMany({ status: "inactive" })

// 聚合
db.orders.aggregate([
  { $match: { status: "paid" } },
  { $group: { _id: "$userId", total: { $sum: "$amount" } } }
])
```

## 5. 索引速查

```javascript
db.users.createIndex({ email: 1 }, { unique: true })
db.orders.createIndex({ userId: 1, createdAt: -1 })  // 复合索引
db.products.createIndex({ tags: 1 })                  // 多键索引

// 查看执行计划
db.users.find({ email: "a@b.com" }).explain("executionStats")
```

| 类型 | 用途 |
|------|------|
| 单字段 | 等值、范围 |
| 复合 | 多条件，遵循 ESR 规则 |
| 多键 | 数组字段 |
| 文本 | 全文检索 |
| TTL | 自动过期删除 |

## 6. 副本集要点

| 概念 | 说明 |
|------|------|
| Primary | 读写默认节点 |
| Secondary | 异步复制，可读（需 readPreference） |
| 选举 | 多数派存活，Raft 类协议 |
| writeConcern | `w: majority` 防丢写 |
| readConcern | `majority` / `local` / `snapshot` |

---

## 7. 分片要点

| 项 | 说明 |
|----|------|
| 分片键 | 不可改，影响数据分布与热点 |
| 范围分片 | 相邻键在同一 chunk |
| 哈希分片 | 打散热点，范围查询差 |
| chunk | 默认 128MB，自动迁移 |

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| 何时选 MongoDB？ | 文档结构多变、嵌套数据、写多读少日志、快速迭代 Schema |
| _id 是什么？ | 默认 ObjectId，12 字节含时间戳+机器+进程+计数 |
| 聚合 vs MapReduce？ | 聚合管道是主流，MapReduce 已不推荐 |
| 如何保证不丢数据？ | 副本集 + writeConcern majority + journal |
| 分片键选错会怎样？ | 热点 shard、jumbo chunk、无法高效范围查 |
