# 01 · 大数据架构概览

## 数仓分层

```
ODS（贴源）→ DWD（明细）→ DWS（汇总）→ ADS（应用）
```

## Lambda vs Kappa

| | Lambda | Kappa |
|---|--------|-------|
| 流 | Flink/Storm | Flink |
| 批 | Spark/Hive | 流 replay 代替批 |
| 复杂度 | 双链路 | 单链路，历史重放贵 |

## 与 Java 微服务

```
业务服务 → Kafka → Flink 实时 → Redis/CH 供查询
                → Spark 离线 → 报表
```
