## 一、Spring Core：IoC / DI

### Bean 生命周期（简化）

```
实例化 → 属性填充(@Autowired) → Aware 回调
→ BeanPostProcessor.before → @PostConstruct / init-method
→ BeanPostProcessor.after → 代理对象(AOP)可能在此产生
→ 使用 → @PreDestroy / destroy-method
```

### 循环依赖（仅单例 + 属性注入）

```
三级缓存：
singletonObjects          // 成品
earlySingletonObjects     // 早期引用（可能已代理）
singletonFactories        // ObjectFactory，用于提前暴露
```

**流程**：A 依赖 B，创建 A 放入工厂 → 填 B → B 依赖 A → 从早期引用拿 A → B 完成 → A 完成。

**不能解决**：构造器注入循环、prototype 循环、多例。

### @Autowired

- 默认按类型；多个实现 → `@Primary` / `@Qualifier`
- 必填：`required=false` 可空

## 二、AOP

| 方式 | 条件 | 性能 |
|------|------|------|
| JDK 动态代理 | 有接口 | 基于接口 |
| CGLIB | 无接口，子类代理 | 不能代理 final |

**术语**：切点 Pointcut、通知 Advice（Before/After/Around）、切面 Aspect。

**同类调用失效**：`this.method()` 不走代理 → 注入自己或 `AopContext.currentProxy()`。

## 三、Spring Boot 自动配置

```
@SpringBootApplication
= @Configuration + @EnableAutoConfiguration + @ComponentScan

@EnableAutoConfiguration
→ 加载 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
→ @ConditionalOnClass / OnMissingBean / OnProperty 等条件装配
```

**自定义 Starter**：
1. `xxx-spring-boot-autoconfigure` 模块写 `@Configuration` + 条件
2. `xxx-spring-boot-starter` 只依赖 autoconfigure + 传递依赖

## 四、Spring MVC 请求链路

```
DispatcherServlet
→ HandlerMapping 找 Handler
→ HandlerAdapter 执行（@RequestMapping 方法）
→ 参数解析（@RequestBody、@PathVariable…）
→ Controller 返回
→ HttpMessageConverter 写 JSON
→ 或 ViewResolver 渲染视图
```

| 组件 | 作用 |
|------|------|
| Filter | Servlet 规范，最早/最晚，链式 |
| HandlerInterceptor | Spring MVC，pre/post/afterCompletion |
| @ControllerAdvice | 全局异常、数据绑定 |

**顺序**：Filter → DispatcherServlet → Interceptor → Controller。

## 五、Spring 事务

### 传播行为（常考 3 个）

| 传播 | 含义 |
|------|------|
| REQUIRED（默认） | 有则加入，无则新建 |
| REQUIRES_NEW | 挂起当前，新建独立事务 |
| NESTED | 嵌套事务（保存点），外层回滚则全回滚 |

### 隔离级别

默认一般 **READ_COMMITTED**（取决于 DB）；MySQL InnoDB 默认 RR。

### 失效场景（必背）

1. **非 public 方法**
2. **同类内部调用**（没走代理）
3. **异常被吞**或抛 **checked 异常** 默认不回滚（需 `rollbackFor`）
4. 方法被 **final/static**
5. 数据库引擎不支持（MyISAM）

```java
@Transactional(rollbackFor = Exception.class)
```

## 六、Spring Cloud 微服务（Alibaba 栈）

| 组件 | 作用 |
|------|------|
| Nacos | 注册发现 + 配置中心 |
| OpenFeign | 声明式 HTTP RPC |
| Gateway | 路由、鉴权、限流过滤器 |
| Sentinel | 限流、熔断、降级 |
| Seata | 分布式事务（AT/TCC/Saga） |

### Feign 调用链

```
@FeignClient → 动态代理 → LoadBalancer 选实例 → HTTP 调用
→ 整合 Sentinel 做熔断
```

### Sentinel

- 滑动窗口统计 QPS/RT/异常比例
- 规则：流控、熔断（慢调用、异常比例、异常数）、热点参数

### Seata AT 模式（简述）

```
一阶段：业务 SQL + 前后镜像 undo_log
二阶段提交：删 undo_log
二阶段回滚：用 undo_log 反向补偿
```

## 七、MyBatis 要点

| 项 | 说明 |
|----|------|
| 一级缓存 | SqlSession 级别，默认开 |
| 二级缓存 | Mapper 级别，需配置，多机慎用 |
| N+1 | 循环查关联 → 用 join / 批量 `IN` |
| `#{}` vs `${}` | `#` 预编译防注入；`$` 字符串替换（排序字段） |

## 八、面试速答

| 问 | 答 |
|----|-----|
| Bean 和 @Component 区别？ | @Component 泛型；@Service/@Repository/@Controller 语义化 |
| 循环依赖怎么解？ | 三级缓存提前暴露早期引用；构造器注入不行 |
| @Transactional 失效？ | 同类调用、非 public、异常类型、自调用绕过代理 |
| Filter 和 Interceptor？ | Filter Servlet 层；Interceptor MVC 层，可拿 Handler |
| Nacos 和 Eureka？ | Nacos 还做配置；AP/CP 可切换；国内生态好 |

## 九、易错点

- [ ] `@Transactional` 对 private 无效
- [ ] 大事务：事务里调 RPC/慢查询 → 拆小事务或异步
- [ ] Feign 默认超时短，要配 `connectTimeout/readTimeout`
- [ ] Gateway 路由顺序、过滤器 Order 影响鉴权
