## 1. 生产故障案例

### 案例 1：未压测大促崩溃

| 项 | 内容 |
|----|------|
| 现象 | 大促开场 5 min 全站 503 |
| 根因 | 预估 QPS 偏低，连接池/线程池过小 |
| 修复 | 紧急扩容 + 限流 |
| 预防 | 大促前全链路压测 + 30% buffer |

### 案例 2：压测数据打穿缓存

| 项 | 内容 |
|----|------|
| 现象 | 压测 RT 正常，上线 RT 高 |
| 根因 | 压测用 100 个 ID 循环，全命中缓存 |
| 修复 | 参数化百万级 ID |
| 预防 | 场景评审 checklist |

### 案例 3：压测机成为瓶颈

| 项 | 内容 |
|----|------|
| 现象 | 加线程 QPS 不涨 |
| 根因 | 单机 JMeter 端口/CPU 耗尽 |
| 修复 | 分布式 JMeter 4 节点 |
| 预防 | 监控压测机资源 |

### 案例 4：生产误压测

| 项 | 内容 |
|----|------|
| 现象 | 生产 DB 负载飙升 |
| 根因 | 脚本 URL 指向生产 |
| 修复 | 熔断、DNS 隔离 |
| 预防 | 环境配置门禁、染色 header |

### 案例 5：浸泡测试发现内存泄漏

| 项 | 内容 |
|----|------|
| 现象 | 12h 后 Full GC 频繁 |
| 根因 | ThreadLocal 未清理 |
| 修复 | finally remove |
| 预防 | soak test 纳入发版 |
