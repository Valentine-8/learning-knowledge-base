## 三、Java 必背 10 条（每条能展开 1 分钟）

| # | 题眼 | 核心句 |
|---|------|--------|
| 1 | HashMap 1.8 | 数组+链表/红黑树；扩容 2 倍；线程不安全；ConcurrentHashMap CAS+synchronized |
| 2 | 线程池 7 参数 | core/max/keepAlive/queue/factory/handler；拒绝策略 4 种；队列选型决定吞吐 |
| 3 | synchronized vs Lock | 锁升级偏向/轻量/重量；Lock 可中断、公平、多 Condition |
| 4 | volatile | 可见性+禁重排；不保证原子；适合状态标志 |
| 5 | Spring 事务失效 | 非 public、自调用、异常被吞、错误 rollbackFor、非代理对象 |
| 6 | Bean 循环依赖 | 三级缓存；构造器注入无法解；Setter/字段可解 |
| 7 | MySQL 索引 | B+ 树；最左前缀；覆盖索引；回表；Explain type/range |
| 8 | MVCC |  undo + ReadView；RR 防不可重复读；幻读靠间隙锁/next-key |
| 9 | Redis 缓存 | 穿透布隆/空值；击穿互斥/逻辑过期；雪崩 TTL 打散 |
| 10 | 分布式幂等 | 唯一键、Token、状态机、MQ 消费去重 |

详细题解 → [面试题大全Q&A.md](./面试题大全Q&A.md)
