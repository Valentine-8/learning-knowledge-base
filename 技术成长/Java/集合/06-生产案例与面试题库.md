## 1. 生产故障案例

### 案例 1：静态 HashMap 内存泄漏

| 项 | 内容 |
|----|------|
| 现象 | 老年代持续增长，Full GC 后不掉 |
| 根因 | `static Map<SessionId, Context>` 无过期，Session 结束未 remove |
| 修复 | WeakReference / Caffeine TTL / 定时清理 |
| 预防 | 缓存必须有界 + 过期策略 |

### 案例 2：LinkedBlockingQueue 无界 OOM

| 项 | 内容 |
|----|------|
| 现象 | 堆 OOM，dump 里大量 Order 对象在队列里 |
| 根因 | `new LinkedBlockingQueue<>()` 默认近 Integer.MAX_VALUE |
| 修复 | 指定 capacity + 拒绝策略 / 降级 |
| 预防 | 线程池队列必须评估峰值与消费速度 |

### 案例 3：遍历时 remove 导致 CME

| 项 | 内容 |
|----|------|
| 现象 | 偶发 `ConcurrentModificationException` |
| 根因 | for-each 里 `list.removeIf` 嵌套修改同一 list |
| 修复 | 统一用 `removeIf` 或 Iterator |
| 预防 | Code Review 遍历+修改模式 |

### 案例 4：自定义对象作 HashMap key 找不到

| 项 | 内容 |
|----|------|
| 现象 | put 成功 get 返回 null |
| 根因 | 只重写 equals 未重写 hashCode |
| 修复 | 同时重写；或用 Lombok `@EqualsAndHashCode` |
| 预防 | IDE 生成、单元测试覆盖 |

### 案例 5：ConcurrentHashMap 复合操作丢数据

| 项 | 内容 |
|----|------|
| 现象 | 计数不准 |
| 根因 | `if (!map.containsKey(k)) map.put(k, 1)` 非原子 |
| 修复 | `map.merge(k, 1, Integer::sum)` 或 `compute` |
| 预防 | 用 CHM 原子 API |

### 案例 6：subList 引发线上异常

| 项 | 内容 |
|----|------|
| 现象 | 分页 subList 后父列表被其他线程 add |
| 根因 | subList 是视图，结构修改互相影响 |
| 修复 | `new ArrayList<>(list.subList(from, to))` 拷贝 |
| 预防 | 对外暴露不可变副本 |

## 3. 高频简答模板

**HashMap put 白板**：hash → 下标 → 空桶放 → 否则比 key/链表/树 → size++ → 超 threshold resize。

**CHM JDK8**：空桶 CAS；否则 synchronized 头节点；size 用 LongAdder 思想。

**LRU**：LinkedHashMap accessOrder=true + removeEldestEntry。
