## 1. 生产故障案例

### 案例 1：无测试重构引入回归

| 项 | 内容 |
|----|------|
| 现象 | 上线后订单金额计算错误 |
| 根因 | 重构促销逻辑无单测，边界遗漏 |
| 修复 | 回滚 + 补 characterization test |
| 预防 | 核心域单测门禁 |

### 案例 2：@Transactional 测试掩盖 bug

| 项 | 内容 |
|----|------|
| 现象 | 测试绿，生产事务不回滚 |
| 根因 | 测试类 @Transactional 自动回滚，未测传播 |
| 修复 | 关键场景去掉测试事务 |
| 预防 | 集成测试指南文档 |

### 案例 3：H2 与 MySQL 差异

| 项 | 内容 |
|----|------|
| 现象 | CI 通过，生产 JSON 查询失败 |
| 根因 | H2 不支持 MySQL JSON 函数 |
| 修复 | 改 Testcontainers MySQL |
| 预防 | 集成测试尽量真实依赖 |

### 案例 4：Flaky 测试拖垮 CI

| 项 | 内容 |
|----|------|
| 现象 | 随机失败，团队 skip 测试 |
| 根因 | 依赖系统时间 + Thread.sleep |
| 修复 | Clock 注入 + Awaitility |
| 预防 | flaky 测试 quarantine 机制 |

### 案例 5：Mock 过度

| 项 | 内容 |
|----|------|
| 现象 | 单测全绿，联调全挂 |
| 根因 | 所有依赖 Mock，接口契约不一致 |
| 修复 | 加契约测试 + 少量集成测试 |
| 预防 | 测试金字塔平衡 |
