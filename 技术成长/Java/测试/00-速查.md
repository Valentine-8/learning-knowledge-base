## 2. JUnit 5 核心

| 注解 | 作用 |
|------|------|
| `@Test` | 测试方法 |
| `@BeforeEach` / `@AfterEach` | 每测试前后 |
| `@ParameterizedTest` | 参数化 |
| `@DisplayName` | 可读名称 |

---

## 3. Mockito 核心

```java
@Mock UserRepository repo;
@InjectMocks UserService service;

when(repo.findById(1L)).thenReturn(Optional.of(user));
verify(repo, times(1)).save(any());
```

---

## 4. Spring Test

| 注解 | 用途 |
|------|------|
| `@SpringBootTest` | 全上下文 |
| `@WebMvcTest` | 只测 Controller |
| `@DataJpaTest` | 只测 JPA |
| `@MockBean` | 替换 Spring Bean |

## 5. Testcontainers

```java
@Container

```

真实 DB/Redis，CI 可重复。
