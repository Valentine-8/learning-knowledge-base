# 03 · 多模块与私服

> **预计阅读**：80 min

---

## 1. 为什么多模块

| 收益 | 说明 |
|------|------|
| 边界清晰 | api / service / web 分离 |
| 复用 | 公共模块共享 |
| 并行构建 | 多模块 CI 加速 |
| 依赖约束 | api 不依赖 web |

---

## 2. 典型结构

```
order-parent/                 packaging=pom
├── order-api/                DTO、接口定义
├── order-domain/             领域模型
├── order-infrastructure/     DB、MQ 实现
├── order-application/        用例编排
└── order-web/                Controller、启动类
```

**依赖方向**：web → application → domain ← infrastructure

---

## 3. 父 POM 配置

```xml
<project>
  <groupId>com.example</groupId>
  <artifactId>order-parent</artifactId>
  <version>1.0.0-SNAPSHOT</version>
  <packaging>pom</packaging>

  <modules>
    <module>order-api</module>
    <module>order-web</module>
  </modules>

  <dependencyManagement>
    <dependencies><!-- 统一版本 --></dependencies>
  </dependencyManagement>

  <build>
    <pluginManagement><!-- 统一插件 --></pluginManagement>
  </build>
</project>
```

---

## 4. 模块间依赖

```xml
<!-- order-web/pom.xml -->
<dependency>
  <groupId>com.example</groupId>
  <artifactId>order-application</artifactId>
  <version>${project.version}</version>
</dependency>
```

**反模式**：循环依赖、domain 依赖 web。

---

## 5. 构建顺序

```bash
cd order-parent
mvn clean install    # 按 reactor 顺序构建所有模块
mvn -pl order-web -am package   # 只构建 web 及其依赖
mvn -rf order-web install       # 从失败模块继续
```

## 6. 私服（Nexus / Artifactory）

### 6.1 为什么需要

- 缓存中央仓库，加速构建
- 托管**内部 RELEASE/SNAPSHOT**
- 代理第三方，合规审计

### 6.2 settings.xml

```xml
<servers>
  <server>
    <id>company-nexus</id>
    <username>deploy</username>
    <password>${env.NEXUS_PASSWORD}</password>
  </server>
</servers>

<mirrors>
  <mirror>
    <id>company-nexus</id>
    <url>https://nexus.example.com/repository/maven-public/</url>
    <mirrorOf>*</mirrorOf>
  </mirror>
</mirrors>
```

### 6.3 发布

```xml
<distributionManagement>
  <repository>
    <id>company-nexus</id>
    <url>https://nexus.example.com/repository/maven-releases/</url>
  </repository>
  <snapshotRepository>
    <id>company-nexus</id>
    <url>https://nexus.example.com/repository/maven-snapshots/</url>
  </snapshotRepository>
</distributionManagement>
```

```bash
mvn deploy -DskipTests
```

## 7. CI/CD 集成

```yaml
# GitHub Actions 示例
- run: mvn -B clean deploy -DskipTests
  env:
    NEXUS_PASSWORD: ${{ secrets.NEXUS_PASSWORD }}
```

- 缓存 `~/.m2/repository`
- 使用 Maven Wrapper 锁定版本
- SNAPSHOT 供开发，tag 打 RELEASE

---

## 8. 版本策略

| 策略 | 说明 |
|------|------|
| 统一版本 | 父 POM `${revision}` + flatten-maven-plugin |
| 独立版本 | 各模块 semver（少见） |
| SNAPSHOT 流程 | feature → SNAPSHOT → release 分支 → RELEASE |

---

## 9. 常见问题

| 问题 | 解决 |
|------|------|
| 找不到内部依赖 | settings mirror / 私服权限 |
| 模块版本不一致 | flatten 或 CI 检查 |
| deploy 401 | server id 与 distributionManagement 匹配 |
