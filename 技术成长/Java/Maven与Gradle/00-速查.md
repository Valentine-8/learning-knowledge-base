# Maven 与 Gradle · 速查

> 10 分钟复习。深入见 [01～05 章](./README.md)。

---

## 1. Maven 生命周期

```
clean → validate → compile → test → package → verify → install → deploy
```

| 命令 | 绑定 Phase |
|------|------------|
| `mvn compile` | compile |
| `mvn test` | test |
| `mvn package` | package |
| `mvn install` | install |

---

## 2. 依赖范围 Scope

| Scope | 编译 | 测试 | 运行 | 传递 |
|-------|:----:|:----:|:----:|:----:|
| compile | ✓ | ✓ | ✓ | ✓ |
| provided | ✓ | ✓ | ✗ | ✗ |
| runtime | ✗ | ✓ | ✓ | ✓ |
| test | ✗ | ✓ | ✗ | ✗ |

---

## 3. 依赖调解

```
最短路径优先 → 先声明优先（同级）
```

排查：`mvn dependency:tree -Dverbose`

---

## 4. 多模块结构

```
parent (packaging=pom)
├── api
├── service
└── web
```

父 POM 统一管理 `<dependencyManagement>` 和插件版本。

---

## 5. 常用命令

```bash
mvn clean package -DskipTests
mvn dependency:tree
mvn versions:display-dependency-updates
mvn enforcer:enforce
```

---

## 6. Gradle vs Maven

| | Maven | Gradle |
|---|-------|--------|
| 配置 | XML | Groovy/Kotlin DSL |
| 构建 | 较慢 | 增量、并行 |
| 生态 | 最广泛 | Android/现代项目 |

---

## 7. 面试速答

| 问 | 答 |
|----|-----|
| compile 和 provided？ | provided 如 servlet-api，容器提供 |
| 冲突怎么解？ | tree 定位 → exclude 或 BOM 统一版本 |
| SNAPSHOT 和 RELEASE？ | SNAPSHOT 可变，RELEASE 不可覆盖 |
| 如何加速构建？ | 并行、增量、私服缓存、skipTests |
