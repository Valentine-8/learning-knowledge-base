## 1. 生产案例

### 案例 1：分布式事务拖垮大促

**现象**：下单 RT 从 200ms 到 30s，Seata TC  CPU 100%。

**根因**：所有跨服务调用套 `@GlobalTransactional`，全局锁竞争 + undo_log 膨胀。

**修复**：改 **本地消息表 + RocketMQ**；仅支付环节保留 TCC；Seata 只护关键短链路。

MQ 细节 → [消息队列/03-可靠性与幂等](../../数据与中间件/消息队列/03-可靠性与幂等.md)。

---

### 案例 2：Redis 锁误删

**现象**：双扣库存。

**根因**：`SET NX` 无 UUID 校验，线程 A 超时后线程 B 加锁，A  finally `DEL` 删掉 B 的锁。

**修复**：Lua 校验 value 再删；Redisson；或缩短业务 + 看门狗。

详见 [Redis/04-分布式锁](../../数据与中间件/Redis/04-分布式锁与并发.md)。

---

### 案例 3：消费者自动 ack 丢消息

**现象**：订单已支付，积分未加。

**根因**：Kafka 自动 commit，消费逻辑异常仍 offset 前进。

**修复**：手动 ack + 幂等 + 死信队列。

---

### 案例 4：Eureka 自我保护「脏实例」

**现象**：流量打到已下线机器。

**根因**：网络抖动触发自我保护，过期实例未剔除。

**修复**：迁移 Nacos；缩短 TTL；客户端重试 + 熔断；K8s readiness 与注册联动。

---

### 案例 5：ZK session 过期丢锁

**现象**：定时任务双跑。

**根因**：Full GC 超过 sessionTimeout，临时锁节点删除，另一实例加锁。

**修复**：调大 session；Curator 心跳；任务 **幂等** 不依赖锁唯一；或换 Redis Redisson。

---

### 案例 6：无限流导致 DB 连接池打满

**现象**：促销按钮点击后全站超时。

**根因**：无 Gateway 限流，Tomcat 线程打满，each 请求占 DB 连接。

**修复**：Sentinel 热点限流 + 降级静态页 + 异步下单 MQ 削峰。

## 9. 场景设计题

**Q：下单扣库存扣款如何保证？**  
A：本地事务创建订单 + 消息表；MQ 扣库存/扣款；幂等；失败补偿关单。

**Q：接口如何防刷？**  
A：Gateway IP 限流 + 用户维度 Sentinel + 验证码 + 风控。

**Q：多机房如何部署注册中心？**  
A：Nacos 集群多 AZ；同 zone 优先 LB；配置分环境；CP 模式护配置一致性。
