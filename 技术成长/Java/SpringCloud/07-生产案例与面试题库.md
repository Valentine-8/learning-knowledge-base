## 1. 生产案例

### 案例 1：Feign 超时雪崩

| 现象 | pay-service 慢，order 线程池满 |
| 根因 | Feign readTimeout 过长，无 Sentinel |
| 修复 | 超时 3s + 熔断 + 异步化 |

### 案例 2：Nacos 配置刷新不生效

| 根因 | @Value 无 @RefreshScope |
| 修复 | 改 @ConfigurationProperties + @RefreshScope |

### 案例 3：Gateway StripPrefix 404

| 根因 | 去掉两层前缀但 Controller 仍带 /api |
| 修复 | 对齐路由与 @RequestMapping |

### 案例 4：Seata 全局锁性能差

| 根因 | 高并发下全局行锁 |
| 修复 | 改最终一致 + 本地消息表 |

### 案例 5：灰度流量到旧版本

| 根因 | LoadBalancer 未读 metadata version |
| 修复 | 自定义 GrayLoadBalancer |

## 3. 架构口述模板

**问**：描述一次用户下单的 microservice 调用？

1. Gateway 鉴权 JWT，路由 `lb://order-service`
2. order-service `@Transactional` 写订单库
3. Feign 调 inventory-service 扣库存（Sentinel 熔断）
4. Feign/MQ 调 pay-service
5. 失败则本地事务回滚或 Seata/补偿
6. Nacos 全程服务发现；配置来自 Nacos Config
