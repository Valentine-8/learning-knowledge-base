## 2. 核心注解

| 注解 | 作用 |
|------|------|
| `@Component` / `@Service` / `@Repository` / `@Controller` | 注册 Bean |
| `@Configuration` + `@Bean` | Java 配置类 |
| `@Autowired` / `@Resource` / `@Qualifier` | 注入 |
| `@Value` / `@ConfigurationProperties` | 配置 |
| `@Transactional` | 声明式事务 |
| `@Aspect` + `@Around` 等 | AOP |
| `@RestController` | MVC + JSON |
| `@SpringBootApplication` | 启动入口 |

---

## 3. Bean 生命周期（简）

```
实例化 → 属性注入 → Aware → BPP.before → @PostConstruct
→ init-method → BPP.after(可能 AOP 代理) → 使用 → @PreDestroy
```

---

## 4. 三级缓存（循环依赖）

| 缓存 | 名称 |
|------|------|
| 一级 | singletonObjects（成品） |
| 二级 | earlySingletonObjects（早期） |
| 三级 | singletonFactories（工厂） |

**仅** 单例 + 属性/setter 注入可解。

---

## 5. AOP

| 代理 | 条件 |
|------|------|
| JDK | 有接口 |
| CGLIB | 无接口 / class-based |

**同类调用不走代理** → 注入 self 或 `AopContext.currentProxy()`。

---

## 6. 事务传播（常考）

| 传播 | 含义 |
|------|------|
| REQUIRED | 有加入，无新建 |
| REQUIRES_NEW | 挂起当前，新事务 |
| NESTED | 嵌套保存点 |

**失效**：非 public、同类调用、异常被吞、checked 异常默认不回滚。

## 7. MVC 链路

```
Filter → DispatcherServlet → Interceptor → Controller
→ Service(@Transactional) → Mapper/MyBatis → DB
```

## 8. 面试 5 分钟

| 问 | 答 |
|----|-----|
| IoC/DI？ | 控制反转：对象创建交给容器；依赖注入：容器注入依赖 |
| @Autowired 过程？ | 类型匹配 → 多个则 @Primary/@Qualifier |
| 事务失效？ | 自调用、非 public、异常类型、无代理 |
| Boot 自动配置？ | `@EnableAutoConfiguration` + imports + `@Conditional*` |
| MyBatis #{} vs ${}？ | # 预编译；$ 拼接（排序字段慎用） |
