## 1. 生产故障案例

### 案例 1：N+1 拖垮 DB

| 项 | 内容 |
|----|------|
| 现象 | 列表接口 P99 3s |
| 根因 | `@OneToMany LAZY` 循环访问 items |
| 修复 | `@EntityGraph` + DTO |
| 预防 | 开发环境 Hibernate stats |

### 案例 2：LazyInitializationException

| 项 | 内容 |
|----|------|
| 现象 | 生产偶发 500 |
| 根因 | `@Transactional` 在 Controller，Service 返回后访问 lazy 字段 |
| 修复 | 事务下沉 Service；返回 DTO |
| 预防 | Open Session In View 了解但不依赖 |

### 案例 3：ddl-auto=update 删列

| 项 | 内容 |
|----|------|
| 现象 | 预发数据丢失 |
| 根因 | Hibernate 自动 alter 表 |
| 修复 | validate + Flyway |
| 预防 | 生产禁 ddl-auto |

### 案例 4：乐观锁冲突未处理

| 项 | 内容 |
|----|------|
| 现象 | 用户重复提交库存扣减异常 |
| 根因 | OptimisticLockException 未捕获 |
| 修复 | 重试或友好提示 |
| 预防 | 接口幂等 + 版本号 |

### 案例 5：全表 scan 分页

| 项 | 内容 |
|----|------|
| 现象 | 深分页超时 |
| 根因 | offset 100 万 |
| 修复 | keyset pagination |
| 预防 | 列表 API 设计规范 |
