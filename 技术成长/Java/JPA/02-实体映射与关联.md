# 02 · 实体映射与关联

> **预计阅读**：90 min

---

## 1. 基本映射

| 注解 | 用途 |
|------|------|
| `@Column` | 列名、nullable、unique |
| `@Enumerated` | 枚举（推荐 STRING） |
| `@Embedded` / `@Embeddable` | 值对象嵌入 |
| `@Convert` | 自定义类型转换 |
| `@JdbcTypeCode(SqlTypes.JSON)` | JSON 列（Hibernate 6） |

```java
@Embeddable
public record Address(String city, String street) {}

@Entity
public class User {
    @Embedded
    private Address address;
}
```

---

## 2. 关联关系

| 关系 | 注解 | 维护端 |
|------|------|--------|
| 一对一 | `@OneToOne` | 有 FK 的一方 |
| 多对一 | `@ManyToOne` | 多的一方（FK） |
| 一对多 | `@OneToMany` | 一的一方（mappedBy） |
| 多对多 | `@ManyToMany` | 中间表（少用） |

---

## 3. 双向关联示例

```java
@Entity
public class Order {
    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<OrderItem> items = new ArrayList<>();

    public void addItem(OrderItem item) {
        items.add(item);
        item.setOrder(this);
    }
}

@Entity
public class OrderItem {
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "order_id")
    private Order order;
}
```

**原则**：双向关联维护**一方**，另一方 `mappedBy`。

---

## 4. Fetch 策略

| 策略 | 行为 |
|------|------|
| LAZY | 用时再查（默认 ToMany） |
| EAGER | 立即加载（默认 ToOne，慎用） |

```java
@ManyToOne(fetch = LAZY)  // 推荐显式 LAZY
```

**EAGER 陷阱**：查 Order 自动拉 User、Items… 性能不可控。

---

## 5. Cascade 与 orphanRemoval

| Cascade | 作用 |
|---------|------|
| PERSIST | save 级联 |
| MERGE | 更新级联 |
| REMOVE | 删除级联 |
| ALL | 全部 |

`orphanRemoval=true`：从集合移除的元素自动 DELETE。

---

## 6. 继承映射

| 策略 | 说明 |
|------|------|
| SINGLE_TABLE | 单表 + discriminator |
| JOINED | 子类各表 |
| TABLE_PER_CLASS | 每类一表 |

**简单域**用 SINGLE_TABLE；规范化用 JOINED。

---

## 7. 主键策略

| Strategy | 场景 |
|----------|------|
| IDENTITY | MySQL auto_increment |
| SEQUENCE | PostgreSQL、Oracle |
| UUID | 分布式（注意索引性能） |
| 自定义 | 雪花等 `@GenericGenerator` |

---

## 8. 乐观锁

```java
@Version
private Long version;
```

更新时 `WHERE id=? AND version=?`，冲突抛 `OptimisticLockException`。

---

## 9. 常见映射错误

- [ ] `@OneToMany` 无 `mappedBy` 导致多余 FK 表
- [ ] equals/hashCode 用 id（未 persist 前全相等）
- [ ] 双向 toString 循环引用
- [ ] 集合用 ArrayList 默认值但无 cascade persist

**equals/hashCode**：业务键或只比 id（detach 注意）。
