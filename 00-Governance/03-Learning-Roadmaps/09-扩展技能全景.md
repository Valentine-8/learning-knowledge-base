## 四、P1 · 第二语言 & 工具语言（你提到的 Go、Python）

> **原则**：Java 7 年不必「样样精通」，但 **AI 时代 + 云原生** 下，至少 **熟练一门脚本/工具语言**。

### 4.1 Python —— 强烈建议学（优先级高于 Go）

| 维度 | 说明 |
|------|------|
| **为什么** | AI/数据生态事实标准；写脚本、爬虫、自动化、压测脚本、运维工具；LLM 微调/评估很多是 Python |
| **学到哪** | 语法 + 常用库（requests、pandas 了解）+ 能读 AI 示例代码 + 能写 200 行以内工具脚本 |
| **不必** | 成为 Python Web 后端（Django/FastAPI 除非岗位要） |
| **文档** | ⏳ 待补 `扩展语言/Python-入门与AI脚本.md` |
| **和 Java 关系** | Java 写业务；Python 写 AI 实验、数据处理、一次性脚本 |

### 4.2 Go —— 按岗位选修（云原生 / 中间件 / 高性能）

| 维度 | 说明 |
|------|------|
| **为什么** | K8s、Docker、Prometheus、etcd、大量云原生组件用 Go；并发模型简单；部分公司用 Go 写微服务/网关 |
| **学到哪** | 语法、goroutine/channel、常见标准库、能读懂 Go 微服务代码、能写简单 CLI/小服务 |
| **不必** | 放弃 Java 转 Go（除非你明确转岗） |
| **文档** | ⏳ 待补 `扩展语言/Go-入门与Java对比.md` |
| **和 Java 关系** | 同一套后端基础（MySQL/Redis/MQ）；换的是语言特性与运行时 |

### 4.3 其他语言（了解即可，除非岗位指向）

| 语言 | 何时值得学 | 优先级 |
|------|------------|--------|
| **Kotlin** | Android、Spring 生态、想写更简洁的 JVM 代码 | 低～中（仍是 JVM） |
| **TypeScript** | 要做 BFF、全栈、Node 中间层 | 中（你已有 [前端/vue](../../99-Archive/Frontend-Demos/Vue2-Basic/)） |
| **Rust** | 基础设施、极致性能、Wasm | 低（学习曲线陡） |
| **C++** | 嵌入式 / 性能敏感 | 你已有 [C++嵌入式/](./C++嵌入式/) |
| **Shell** | 日常运维、CI 脚本 | 中（应在 DevOps 实践中补） |
