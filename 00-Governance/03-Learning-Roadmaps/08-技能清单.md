# 7 年 Java 工程师应掌握的技能清单

> **定位说明**：工作 7 年左右，通常对应 **高级工程师 / 资深工程师（Senior）**，部分同学已走向 **技术专家 / 架构师 / Tech Lead**。本清单按「必须精通 → 应该熟练 → 需要了解」三级划分，覆盖技术深度、工程广度与软实力。

## 一、Java 语言与核心库（精通）

### 1.1 语言基础与进阶

| 技能项 | 要求等级 | 说明 |
|--------|----------|------|
| 面向对象（封装/继承/多态/抽象） | 精通 | 能讲清设计取舍，而非只会语法 |
| 泛型与类型擦除 | 精通 | 能写通用组件，理解 PECS 原则 |
| 注解与反射 | 精通 | 理解 Spring/MyBatis 等框架的底层机制 |
| Lambda、Stream API | 精通 | 函数式编程思维，Parallel Stream 风险意识 |
| Optional、时间 API（java.time） | 熟练 | 避免 NPE，正确处理时区 |
| Java 8 → 17/21 新特性 | 熟练 | Record、Sealed Class、Pattern Matching、Virtual Thread（21） |
| 异常体系与最佳实践 | 精通 | 业务异常 vs 系统异常，异常链，不吞异常 |
| 序列化（Serializable、JSON） | 熟练 | 知道安全风险与替代方案 |

### 1.2 集合框架

| 技能项 | 要求等级 | 说明 |
|--------|----------|------|
| List / Set / Queue 选型 | 精通 | 时间复杂度、线程安全、适用场景 |
| HashMap / ConcurrentHashMap 原理 | 精通 | 哈希冲突、扩容、JDK7/8 差异 |
| TreeMap / LinkedHashMap | 熟练 | 有序性、LRU 实现 |
| CopyOnWriteArrayList 等并发集合 | 熟练 | 读写分离场景 |
| fail-fast / fail-safe | 精通 | 并发修改异常根因 |

### 1.3 IO 与 NIO

| 技能项 | 要求等级 | 说明 |
|--------|----------|------|
| BIO / NIO / AIO 区别 | 熟练 | 阻塞模型、Selector、Channel |
| Netty 基础 | 熟练 | EventLoop、Pipeline、ByteBuf（高并发场景必备） |

## 十二、自我评估矩阵

用以下标准自评每项技能（1～5 分）：

| 分数 | 含义 |
|------|------|
| 1 | 听说过，未实践 |
| 2 | 用过，依赖文档 |
| 3 | 能独立完成常见任务 |
| 4 | 能排查疑难问题、做技术选型 |
| 5 | 能设计架构、指导他人、有线上大规模经验 |

**7 年工程师目标**：
- **精通项**（4～5 分）：Java 核心、JVM、并发、Spring、MySQL、Redis、至少一种 MQ、分布式基础、Linux、Git
- **熟练项**（3～4 分）：K8s、ES、分库分表、DDD、监控体系
- **了解项**（2～3 分）：加分方向中选定的 1～2 个

## 十三、与职级对照（参考）

| 职级 | 典型年限 | 核心能力 |
|------|----------|----------|
| 中级 | 2～4 年 | 独立完成功能，熟悉 Spring + MySQL |
| 高级 | 4～7 年 | 模块负责人，性能优化，分布式组件 |
| 资深/专家 | 7～10 年 | 系统架构，跨团队，技术规划 |
| 架构师 | 8 年+ | 业务架构 + 技术架构，组织影响力 |

7 年节点：**至少达到高级工程师上限，向资深/架构师过渡**。
